# mdtask

Веб-платформа для практических заданий в стиле mdBook: преподаватель публикует задания (Markdown), студенты сдают файлы решений, а также отдельный **тренажёр SQL** для практики запросов к SQLite прямо в браузере.

Это не полноценная LMS с баллами и тестами — упрощённый трекер практик с бинарным статусом сдачи (выполнено / не выполнено) плюс интерактивный SQL-тренажёр.

## Стек

- Node.js + Express 5, шаблоны EJS (серверный рендеринг, без сборки и SPA-фреймворка)
- `better-sqlite3` — единственная база данных, без ORM (сырые SQL-запросы в `src/db/index.js`)
- `express-session` — сессии, `multer` — загрузка файлов, `markdown-it` — рендер Markdown
- Тесты: `node:test` + `supertest`

## Быстрый старт

```bash
npm install
npm start        # http://localhost:3000
# или для разработки с автоперезапуском:
npm run dev
```

При первом запуске автоматически создаётся файл БД `data/mdtask.db` и наполняется тестовыми данными (см. `src/db/seed.js` и `src/db/seed-sql-exercises.js`).

## Основной функционал

### Задания (преподаватель ↔ студент)

- Преподаватель создаёт курсы → задания (групповые или индивидуальные), пишет условие в Markdown прямо в браузере (редактор с превью).
- Студент видит список заданий со статусом (не сдано / на проверке / выполнено / не выполнено), открывает задание, читает условие, загружает файл решения (`.zip`/`.rar`).
- Преподаватель просматривает сдачи по заданию (таблица всегда показывает актуальную, самую свежую сдачу студента — включая пересдачи после отклонения, а не устаревшую отклонённую версию), выставляет статус done/not_done с комментарием; при "не выполнено" студент может пересдать.
- Загруженные файлы можно скачать прямо из таблицы сдач (`/teacher/assignment/:id/submissions/:submissionId/files/:index`) — оригинальное имя файла сохраняется для скачивания, реальное имя на диске уникально и защищено от path traversal.

Ключевые файлы: `src/routes/student.js`, `src/routes/teacher.js`, `src/lib/summary-writer.js`, `src/lib/sidebar.js`, контент — `content/src/*.md` + `content/SUMMARY.md`.

### Тренажёр SQL (раздел «SQL DataBase» в сайдбаре)

- **Теоретический материал** (`/trainer/theory`) — конспект по темам CREATE TABLE, INSERT, SELECT, WHERE, UPDATE, DELETE, DROP TABLE.
- **Практический тренажёр** (`/trainer`) — 35 заданий (по 5 на каждую из 7 тем), решаются строго по порядку: следующее задание открывается только после верного решения текущего.
- У каждого студента — свой файл SQLite-песочницы на задание (`data/trainer/<studentId>/<exerciseId>.db`), пересоздаётся из схемы задания перед каждым запуском, поэтому студенты никогда не конфликтуют друг с другом.
- Перед выполнением запрос проверяется (разрешён только нужный тип оператора и один statement за раз); синтаксические и логические ошибки SQLite показываются студенту прямо в интерфейсе.
- Вся история попыток сохраняется — включая неверные решения и ошибки — и видна студенту под заданием.
- Преподаватель видит сводную таблицу результатов всех студентов: `/teacher/trainer/results`.

Ключевые файлы: `src/routes/trainer.js`, `src/lib/sql-sandbox.js`, `src/db/sql-exercises-data.js`, `src/views/trainer/*`.

## Структура проекта

```
src/
  server.js            # фабрика Express-приложения
  db/                   # better-sqlite3: schema.sql, index.js (запросы), seed*.js
  lib/                  # markdown, sidebar, summary parser/writer, sql-sandbox
  middleware/auth.js     # requireRole / requireAuth
  routes/               # auth, student, teacher, trainer
  views/                # EJS-шаблоны
content/
  SUMMARY.md            # оглавление в стиле mdBook
  src/                  # markdown-файлы заданий
public/                 # css/js без сборки
tests/                  # node:test + supertest
docs/plan.md            # исходное ТЗ проекта (RU)
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт сервера |
| `DB_PATH` | `data/mdtask.db` | путь к основной БД (`:memory:` для тестов) |
| `TRAINER_DB_DIR` | `data/trainer` | папка с песочницами SQL-тренажёра по студентам |

## Статус готовности

Реализовано и покрыто тестами (77/77 проходят): загрузка/сдача заданий, редактор Markdown для преподавателя, статусы и пересдачи (с корректным отображением актуальной версии сдачи), скачивание загруженных файлов преподавателем, тренажёр SQL с последовательной разблокировкой, историей попыток и админ-панелью результатов.

Не реализовано (за рамками текущего ТЗ): регистрация/пароли (вход только по ID), роль администратора для управления пользователями, PostgreSQL-бэкенд (см. `docs/plan.md` — упомянут как опция для продакшена).
