# Формы: поля ввода

Формы — то, через что пользователь что-то сообщает сайту: входит, регистрируется, ищет, оформляет заказ.

## Форма form

`<form>` — контейнер для полей. Два главных атрибута:

- `action` — куда отправить данные (адрес обработчика на сервере);
- `method` — как отправить: `get` (данные видны в адресе, для поиска) или `post` (скрыто, для паролей и заказов).

```example
<form action="/search" method="get">
  <input type="text" name="q">
  <button type="submit">Искать</button>
</form>
```

## Поле input и его типы

`<input>` — одиночный тег. Атрибут `type` меняет вид поля и то, что в него можно ввести:

| type | Что вводят | Особенность |
| --- | --- | --- |
| `text` | любой текст | обычное поле |
| `password` | пароль | символы скрыты точками |
| `email` | почту | браузер проверит, что есть `@` |
| `number` | число | стрелки «больше / меньше», можно `min`, `max` |
| `date` | дату | календарь |
| `tel` | телефон | на телефоне — цифровая клавиатура |
| `search` | поисковый запрос | крестик «очистить» |

```example
<input type="password">
<input type="number" min="1" max="10">
<input type="date">
```

## Имя поля и значение

- `name` — имя, под которым значение уйдёт на сервер. Без `name` поле **не отправится**.
- `value` — значение, которое уже стоит в поле.
- `placeholder` — серая подсказка внутри пустого поля; она исчезает, когда начинают печатать.

```example
<input type="text" name="city" value="Бухара">
<input type="email" name="mail" placeholder="name@example.com">
```

## Подписи label

Каждому полю нужна подпись `<label>`. Её связывают с полем: у поля — `id`, у подписи — `for` с тем же значением.
Тогда щелчок по подписи ставит курсор в поле, а программы для незрячих зачитывают подпись.

```example
<label for="nick">Никнейм</label>
<input type="text" id="nick" name="nick">
```

`placeholder` подпись не заменяет: он пропадает, как только поле заполнено.

## Обязательные поля и ограничения

| Атрибут | Что делает |
| --- | --- |
| `required` | поле обязательно, пустую форму браузер не отправит |
| `minlength`, `maxlength` | сколько символов можно ввести |
| `min`, `max` | границы числа или даты |
| `readonly` | можно прочитать, нельзя изменить |
| `disabled` | поле выключено и не отправляется |
| `autofocus` | курсор сразу в этом поле |

`required`, `readonly`, `disabled`, `autofocus` пишутся без значения.

## Кнопки

`<button>` — кнопка, текст пишут между тегами. Тип:

- `type="submit"` — отправить форму (так по умолчанию);
- `type="reset"` — очистить поля;
- `type="button"` — ничего не делает сама, для скриптов.

```example
<button type="submit">Сохранить</button>
<button type="reset">Очистить</button>
```

## Коротко

- `<form action method>` — контейнер; поле — `<input type name>`.
- Подпись — `<label for>` + `id` у поля.
- `placeholder` — подсказка, `required` — обязательное, `value` — готовое значение.
- Кнопка — `<button type="submit">`.
