# Ссылки

Ссылки — то, что делает веб «паутиной»: по ним переходят со страницы на страницу и с сайта на сайт.

## Тег a и атрибут href

Ссылка — элемент `<a>` (anchor, «якорь»). Куда она ведёт, пишут в атрибуте `href`, а между тегами — текст,
по которому нажимают.

```example
<p>Новости читайте на <a href="https://kun.uz">сайте Kun.uz</a>.</p>
```

Текст ссылки должен объяснять, куда она ведёт. «Нажмите здесь» — плохой текст: по нему непонятно, что откроется.

## Абсолютные и относительные адреса

**Абсолютный адрес** — полный, с протоколом: `https://example.com/about.html`. Им ссылаются на другие сайты.

**Относительный адрес** — путь от текущей страницы на своём сайте:

| Адрес | Куда ведёт |
| --- | --- |
| `contacts.html` | файл в той же папке |
| `blog/post.html` | файл в папке `blog` |
| `../index.html` | файл на папку выше |
| `/index.html` | файл от корня сайта |

```example
<a href="prices.html">Цены</a>
<a href="docs/rules.html">Правила</a>
```

## Открыть в новой вкладке

Атрибут `target="_blank"` открывает ссылку в новой вкладке. Так делают для ссылок на чужие сайты, чтобы
пользователь не потерял ваш.

```example
<a href="https://www.google.com" target="_blank">Поиск Google</a>
```

## Якоря: переход внутри страницы

Если у элемента есть `id`, на него можно сослаться решёткой: `href="#id"`. Браузер прокрутит страницу к этому
элементу. Так делают оглавления и кнопки «Наверх».

```example
<a href="#rules">Перейти к правилам</a>
<h2 id="rules">Правила</h2>
<p>Не опаздывайте на занятия.</p>
```

`href="#"` — пустой якорь: ссылка никуда не ведёт. Его ставят, пока настоящей страницы ещё нет.

## Почта и телефон

| Начало адреса | Что произойдёт |
| --- | --- |
| `mailto:` | откроется почтовая программа с письмом на этот адрес |
| `tel:` | на телефоне начнётся звонок |

```example
<p>Пишите: <a href="mailto:office@school.uz">office@school.uz</a></p>
<p>Звоните: <a href="tel:+998711234567">+998 71 123-45-67</a></p>
```

## Меню из ссылок

Меню сайта — это ссылки, сложенные в список: пункты меню — пункты `<li>`, в каждом по ссылке.

```example
<ul>
  <li><a href="news.html">Новости</a></li>
  <li><a href="photos.html">Фото</a></li>
</ul>
```

## Коротко

- Ссылка — `<a href="адрес">текст</a>`; текст понятен без контекста.
- Чужой сайт — полный адрес, своя страница — путь относительно текущей.
- `target="_blank"` — новая вкладка, `#id` — переход к элементу, `mailto:` и `tel:` — письмо и звонок.
