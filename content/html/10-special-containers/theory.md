# Специальные контейнеры

В прошлой теме вы раскладывали страницу по коробкам `<div>`. Но `<div>` ничего не говорит о содержимом: шапка
это, меню или статья — видно только по классу. **Специальные контейнеры** работают как `<div>`, но их имя само
объясняет, что внутри.

## Каркас страницы

| Тег | Что это | Сколько на странице |
| --- | --- | --- |
| `<header>` | шапка: логотип, название, иногда меню | обычно одна у страницы, бывает у статьи |
| `<nav>` | навигация: главное меню, оглавление | сколько нужно |
| `<main>` | главное содержимое страницы | **только один** |
| `<footer>` | подвал: контакты, автор, © | обычно один у страницы, бывает у статьи |

```scheme
<header>
  <h1>Кафе «Чайхана»</h1>
  <nav>
    <a href="#">Меню</a>
    <a href="#">Контакты</a>
  </nav>
</header>
<main>
  <p>Свежий плов каждый день.</p>
</main>
<footer>
  <p>Ежедневно с 9:00 до 22:00</p>
</footer>
```

## Содержимое: section, article, aside

- `<section>` — **раздел** страницы на одну тему, обычно со своим заголовком: «О нас», «Отзывы», «Цены».
- `<article>` — **самостоятельный** материал, который можно вырезать и опубликовать отдельно: новость, пост,
  отзыв, карточка товара.
- `<aside>` — **дополнительное**, сбоку от главного: «Читайте также», реклама, справка.

```scheme
<main>
  <article>
    <h2>Открылся новый парк</h2>
    <p>В парке есть фонтаны и велодорожки.</p>
  </article>
  <aside>
    <h3>Читайте также</h3>
    <p>Афиша выходных</p>
  </aside>
</main>
```

Разделы могут содержать статьи, а статьи — свои разделы, шапку и подвал:

```scheme
<section>
  <h2>Отзывы</h2>
  <article>
    <h3>Камола</h3>
    <p>Очень вкусно!</p>
  </article>
  <article>
    <h3>Рустам</h3>
    <p>Быстро обслужили.</p>
  </article>
</section>
```

## Отдельные блоки

| Тег | Что это |
| --- | --- |
| `<figure>` + `<figcaption>` | иллюстрация (картинка, схема, код) с подписью |
| `<details>` + `<summary>` | раскрывающийся блок: `summary` видно всегда, остальное — по щелчку |
| `<address>` | контакты автора или владельца сайта |
| `<blockquote>` | длинная цитата |

```example
<details>
  <summary>Как оплатить заказ?</summary>
  <p>Картой на сайте или наличными курьеру.</p>
</details>
<address>
  Ташкент, ул. Навои, 1<br>
  <a href="tel:+998712000000">+998 71 200-00-00</a>
</address>
```

`<details>` закрыт, пока по нему не щёлкнут (в окне «Как должно выглядеть» его содержимого не видно — оно
написано в условии). Атрибут `open` раскрывает его заранее.

## Как выбрать контейнер

| Если это… | то |
| --- | --- |
| верх страницы с логотипом | `<header>` |
| набор ссылок по сайту | `<nav>` |
| всё главное содержимое страницы | `<main>` |
| часть страницы со своим заголовком | `<section>` |
| материал, понятный сам по себе | `<article>` |
| дополнение сбоку | `<aside>` |
| низ страницы с контактами | `<footer>` |
| коробка только для оформления, без смысла | `<div>` |

## Зачем это нужно

- **Людям**: код читается как план страницы.
- **Поисковикам**: Google понимает, где главное содержимое, а где меню и реклама.
- **Незрячим**: программа чтения с экрана умеет «перепрыгнуть к главному» или «к меню».

`<div>` никуда не исчезает: он нужен, когда коробка — просто обёртка для оформления. Специальные контейнеры можно
вкладывать в `<div>` и друг в друга.

## Как устроены задания

Как в прошлой теме: переключатель «Схема» покажет каждую коробку своим цветом — так видно, какой контейнер где стоит.
