# Таблицы

Таблица — для данных, которые удобно читать по строкам и столбцам: расписание, цены, оценки. Для раскладки
страницы по колонкам таблицы не используют — для этого есть контейнеры и CSS.

## Строки и ячейки

- `<table>` — вся таблица;
- `<tr>` (table row) — строка;
- `<td>` (table data) — ячейка с данными;
- `<th>` (table header) — ячейка-заголовок: браузер делает её жирной и ставит по центру.

Таблица строится **по строкам**: сначала строка, внутри неё ячейки слева направо.

```example
<table>
  <tr>
    <th>Город</th>
    <th>Жители</th>
  </tr>
  <tr>
    <td>Наманган</td>
    <td>650 тыс.</td>
  </tr>
</table>
```

Рамок у таблицы по умолчанию нет — их добавляют стилями. В примерах тренажёра таблица тоже без рамок.

## Название таблицы: caption

`<caption>` — подпись над таблицей. Ставится **сразу после** открывающего `<table>`.

```example
<table>
  <caption>Курс валют</caption>
  <tr><td>USD</td><td>12 700</td></tr>
</table>
```

## Части таблицы: thead, tbody, tfoot

Большую таблицу делят на части:

- `<thead>` — шапка (строка с заголовками столбцов);
- `<tbody>` — основные данные;
- `<tfoot>` — итог (сумма, среднее).

```example
<table>
  <thead>
    <tr><th>Месяц</th><th>Расход</th></tr>
  </thead>
  <tbody>
    <tr><td>Март</td><td>300</td></tr>
    <tr><td>Апрель</td><td>250</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Всего</td><td>550</td></tr>
  </tfoot>
</table>
```

Если частей не писать, браузер сам положит строки в `<tbody>`. Поэтому `<table><tr>…</tr></table>` и та же таблица
с явным `<tbody>` для проверки одинаковы.

## Объединение ячеек

- `colspan="2"` — ячейка шириной в два столбца (объединяет по горизонтали);
- `rowspan="2"` — ячейка высотой в две строки (объединяет по вертикали).

В строке, где ячейка растянута, ячеек пишут **меньше**: место уже занято.

```example
<table>
  <tr><th colspan="2">Результаты забега</th></tr>
  <tr><td rowspan="2">Финал</td><td>Азиз</td></tr>
  <tr><td>Шахзод</td></tr>
</table>
```

Во второй строке две ячейки, в третьей — одна: её первый столбец занят ячейкой «Финал» с `rowspan="2"`.

## Коротко

- `<table>` → строки `<tr>` → ячейки `<td>`, заголовки — `<th>`.
- Подпись — `<caption>` сразу после `<table>`; части — `<thead>`, `<tbody>`, `<tfoot>`.
- `colspan` — шире, `rowspan` — выше; в таких строках ячеек меньше.
