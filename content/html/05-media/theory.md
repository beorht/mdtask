# Изображения и медиа

Картинки, видео и звук делают страницу живой. В HTML для них свои теги; сами файлы лежат рядом со страницей,
а в коде указывают путь к ним.

## Картинка img

`<img>` — одиночный тег. Обязательные атрибуты:

- `src` — путь к файлу картинки (как у ссылок: имя файла, папка, полный адрес);
- `alt` — текстовое описание. Его показывает браузер, если картинка не загрузилась, и зачитывают программы для
  незрячих людей.

```example
<img src="images/samarkand.jpg" alt="Площадь Регистан вечером">
```

В тренажёре настоящих файлов нет, поэтому вместо картинки виден её `alt`. Так выглядит и любая страница, у которой
не нашёлся файл.

Хороший `alt` описывает, **что** на картинке, а не пишет «картинка» или «фото». Если картинка чисто украшение,
`alt` оставляют пустым: `alt=""`.

### Размеры

`width` и `height` — ширина и высота в пикселях (единицы не пишут). Браузер заранее оставит место под картинку,
и страница не будет «прыгать» при загрузке.

```example
<img src="logo.png" alt="Логотип колледжа" width="120" height="120">
```

### Форматы

| Формат | Для чего |
| --- | --- |
| `.jpg` | фотографии |
| `.png` | рисунки, логотипы, прозрачный фон |
| `.svg` | значки и схемы, не теряют чёткость при увеличении |
| `.webp` | фото и рисунки, файлы меньше по размеру |

## Картинка с подписью: figure и figcaption

`<figure>` — блок «иллюстрация», `<figcaption>` — подпись к ней. Подпись связана с картинкой по смыслу, а не просто
стоит рядом.

```example
<figure>
  <img src="map.png" alt="Карта Узбекистана">
  <figcaption>Рис. 1. Карта страны</figcaption>
</figure>
```

## Видео и звук

`<video>` и `<audio>` — проигрыватели прямо на странице. Атрибут `controls` показывает кнопки: старт, пауза,
громкость. Без него проигрыватель не управляется.

```example
<audio src="anthem.mp3" controls></audio>
```

Полезные атрибуты:

| Атрибут | Что делает |
| --- | --- |
| `controls` | кнопки управления |
| `autoplay` | запуск сразу (браузеры разрешают только без звука) |
| `muted` | без звука |
| `loop` | повторять по кругу |
| `poster` | картинка до запуска видео (`<video>`) |

`controls`, `autoplay`, `muted`, `loop` пишутся без значения.

### Несколько форматов: source

Разные браузеры понимают разные форматы. Внутрь `<video>` или `<audio>` кладут несколько `<source>`: браузер
возьмёт первый, который умеет играть. `type` подсказывает формат файла.

```example
<video controls width="320">
  <source src="lesson.webm" type="video/webm">
  <source src="lesson.mp4" type="video/mp4">
</video>
```

## Коротко

- `<img src alt>` — всегда с `alt`; размеры — `width` и `height` без единиц.
- Картинка с подписью — `<figure>` + `<figcaption>`.
- `<video>`/`<audio>` с `controls`; несколько форматов — `<source src type>`.
