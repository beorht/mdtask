# Как устроена веб-страница

Каждая страница в интернете — это текстовый файл на языке **HTML** (HyperText Markup Language, «язык разметки
гипертекста»). Браузер читает этот файл и рисует по нему страницу: заголовки, абзацы, картинки, ссылки.

HTML — не язык программирования. Он ничего не вычисляет, а **размечает** текст: говорит браузеру, где заголовок,
где абзац, где картинка.

## Тег и элемент

Разметка состоит из **тегов** — слов в угловых скобках. Большинство тегов парные:

- открывающий тег `<p>` — «здесь начинается абзац»;
- закрывающий тег `</p>` — с косой чертой, «здесь абзац заканчивается».

Открывающий тег, содержимое и закрывающий тег вместе называются **элементом**.

```example
<p>Привет! Это мой первый абзац.</p>
```

Слева — код, справа — как его покажет браузер. Сами теги на странице не видны: видно только то, что между ними.

Несколько тегов, которые понадобятся с самого начала:

| Тег | Что означает |
| --- | --- |
| `<h1>` | главный заголовок страницы |
| `<p>` | абзац текста |
| `<a>` | ссылка |
| `<img>` | картинка |
| `<br>` | перенос строки |
| `<hr>` | горизонтальная линия-разделитель |

```example
<h1>Погода</h1>
<p>Завтра будет солнечно.</p>
```

## Атрибуты

Тегу можно дать дополнительные сведения — **атрибуты**. Они пишутся внутри открывающего тега после его имени:
`имя="значение"`.

```example
<a href="https://www.gov.uz">Портал государственных услуг</a>
```

Здесь `href` — атрибут ссылки, он хранит адрес, куда она ведёт. В браузере адрес не виден: видно только текст
ссылки.

Атрибутов может быть несколько, они разделяются пробелом. Порядок атрибутов не важен, значения пишут в кавычках.

```example
<img src="tree.jpg" alt="Дерево у дома" width="200">
```

У картинки `src` — имя файла, `alt` — описание: его показывает браузер, если файл не загрузился, и зачитывают
программы для незрячих. `width` — ширина в пикселях.

## Одиночные теги

Некоторые теги ничего не обрамляют, поэтому у них нет закрывающей пары: `<br>`, `<hr>`, `<img>`, `<input>`.

```example
<p>Первая строка<br>Вторая строка</p>
<hr>
<p>Текст после линии</p>
```

## Вложенность

Элементы можно класть внутрь других элементов — как коробку в коробку. Например, ссылка может стоять внутри абзаца.

```example
<p>Расписание смотрите на <a href="schedule.html">странице расписания</a>.</p>
```

Главное правило: **что открылось позже — закрывается раньше**.

```html
<!-- Правильно: ссылка открылась внутри абзаца и закрылась внутри него -->
<p>Текст <a href="page.html">ссылка</a></p>

<!-- Неправильно: теги перекрещиваются -->
<p>Текст <a href="page.html">ссылка</p></a>
```

Чтобы видеть вложенность, внутренние элементы пишут с **отступом** — двумя пробелами. Браузеру отступы не важны,
они нужны людям.

## Пробелы и переносы

Браузер склеивает несколько пробелов и переносов строк в один пробел. Поэтому текст можно переносить в коде как
удобно — на странице он всё равно будет одним абзацем. Новую строку внутри абзаца даёт только `<br>`.

```example
<p>Этот     текст
   записан    в коде
   на трёх строках.</p>
```

## Каркас документа

Полная страница всегда устроена одинаково:

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="utf-8">
    <title>Мой сайт</title>
  </head>
  <body>
    <h1>Мой сайт</h1>
    <p>Здесь всё, что видно на странице.</p>
  </body>
</html>
```

- `<!doctype html>` — первая строка: «это современный HTML».
- `<html lang="ru">` — корень документа, `lang` — язык страницы.
- `<head>` — «голова»: служебные сведения, на странице их не видно. `<meta charset="utf-8">` — кодировка (чтобы
  русские буквы не превратились в «кракозябры»), `<title>` — название на вкладке браузера.
- `<body>` — «тело»: всё, что видно на странице.

В практических работах вы будете писать только содержимое `<body>` — остальное тренажёр добавит сам.

## Комментарии

Текст между `<!--` и `-->` браузер не показывает. В комментариях пишут пояснения для себя и коллег.

```html
<!-- Здесь будет меню -->
```

## Как устроены практические работы

- Справа — редактор: пишите HTML руками или через **Emmet** (сокращение отдельной строкой и `Tab`).
- Слева сверху — как ваш код выглядит в браузере, он обновляется, пока вы печатаете. Снизу — как должно получиться.
- Атрибуты вроде `href` и `src` в браузере не видны — их значения написаны в условии задания.
- Когда всё совпадёт, нажмите «Проверить» или `Ctrl`+`Enter`. Важны теги, их вложенность,
  атрибуты и текст; отступы и порядок атрибутов не важны.
