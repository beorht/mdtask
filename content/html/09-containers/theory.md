# id, class и обычные контейнеры

Как давать элементам имена и раскладывать страницу по «коробкам». Прочитайте — дальше 10 заданий по этой теме.

## id и class — имена для элементов

На странице десятки элементов. Чтобы найти нужный и потом оформить его, ему дают имя — **id** или **class**. Имя
пишется внутри открывающего тега.

- **`id` — как номер паспорта.** У каждого свой. Два одинаковых id на одной странице быть не может.
- **`class` — как форма команды.** Одинаковую форму носят многие игроки, и все они выглядят одинаково.

### id — уникальное имя

```scheme
<h1 id="logo">Мой сайт</h1>
<p>Привет!</p>
```

### class — общее имя для группы

```scheme
<p class="card">Яблоко</p>
<p class="card">Груша</p>
<p class="card">Слива</p>
```

### id и class на одном элементе

```scheme
<button class="btn">Назад</button>
<button class="btn" id="buy">Купить</button>
<button class="btn">Далее</button>
```

class даёт всем кнопкам одинаковую форму, а id выделяет одну — главную. Классов у элемента может быть несколько:
`class="card big"`.

| | id | class |
| --- | --- | --- |
| Как пишется в HTML | `id="logo"` | `class="card"` |
| Как найти в CSS | `#logo` — решётка | `.card` — точка |
| Сколько на странице | Только один элемент | Сколько угодно |
| Сколько у элемента | Один id | Несколько классов |

> **Совет:** для оформления почти всегда берите class, а id — когда элемент действительно один.

## div — универсальная коробка

Контейнер — это коробка для элементов. Сам по себе `<div>` ничего не означает и в браузере не виден. Его работа —
**держать вместе** то, что связано.

```scheme Пунктир — граница div, в браузере её не видно
<div class="card">
  <h2>Котик Барсик</h2>
  <p>Любит спать и есть.</p>
  <button>Погладить</button>
</div>
```

- **Сгруппировать.** Связанные элементы лежат вместе, как вещи в одной коробке при переезде.
- **Оформить разом.** Фон, рамку и отступы потом задают один раз — для всей коробки.
- **Расположить.** Коробки можно ставить в ряд, в колонки или по центру страницы.

### Коробки внутри коробок

```scheme
<div class="page">
  <div class="card">
    <h2>Новости</h2>
  </div>
  <div class="card">
    <h2>Погода</h2>
  </div>
</div>
```

Как матрёшка: внешняя коробка держит внутренние. **Отступы в коде** показывают, кто внутри кого.

### span — коробка внутри строки

`<div>` занимает целую строку, а `<span>` — только своё слово внутри текста. Его берут, чтобы дать имя части фразы.

```scheme
<p>Цена: <span class="price">25 000 сум</span></p>
```

## Специальные контейнеры

Работают как div, но их **имя сразу говорит**, что лежит внутри:

| Тег | Что это | Где обычно |
| --- | --- | --- |
| `<header>` | Шапка: логотип и название сайта | В самом верху |
| `<nav>` | Навигация: меню со ссылками на разделы | В шапке или сбоку |
| `<main>` | Главное содержимое, только один на странице | В середине |
| `<footer>` | Подвал: контакты и подпись | В самом низу |

### Собираем страницу

```scheme Как это выглядит по коробкам
<header>
  <h1>Мой блог</h1>
  <nav>
    <a href="#">Главная</a>
    <a href="#">Статьи</a>
  </nav>
</header>
<main>
  <h2>Новая статья</h2>
  <p>Текст статьи</p>
</main>
<footer>
  <p>2026 Мой блог</p>
</footer>
```

### Почему не просто div?

`<div class="header">` тоже работает, но `<header>` лучше:

- **Понятнее людям.** Код читается как план страницы.
- **Понятнее поисковикам.** Google видит, где на странице главное.
- **Доступнее.** Программы чтения с экрана помогают незрячим людям.

## Как устроены задания

- Справа вы пишете HTML — руками или через Emmet: сокращение отдельной строкой и `Tab`.
- Слева сверху — как ваш HTML выглядит в браузере, он обновляется, пока вы печатаете. Снизу — как он должен выглядеть.
- В браузере div, id и class не видны. Переключатель «Схема» покажет обе страницы коробками: `div.card` — коробка
  div с классом card, `h1#logo` — заголовок с id logo, серая метка — просто тег без имени.
- Когда всё совпадёт, нажмите `Ctrl`+`Enter` или «Проверить». CSS не нужен — только HTML.
