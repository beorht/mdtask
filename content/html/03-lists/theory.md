# Списки

Списки встречаются на каждом втором сайте: меню, шаги инструкции, характеристики товара, оглавление.
В HTML три вида списков.

## Маркированный список ul

`<ul>` (unordered list) — список, где порядок не важен. Каждый пункт — элемент `<li>` (list item). Браузер
ставит перед пунктами точки-маркеры.

```example
<ul>
  <li>Тетрадь</li>
  <li>Ручка</li>
  <li>Линейка</li>
</ul>
```

Внутри `<ul>` могут стоять **только** `<li>`. Текст, заголовки и картинки кладут внутрь пунктов.

## Нумерованный список ol

`<ol>` (ordered list) — список, где важен порядок: шаги, места в рейтинге. Номера браузер ставит сам — писать
«1.», «2.» в тексте не нужно.

```example
<ol>
  <li>Открыть браузер</li>
  <li>Ввести адрес сайта</li>
  <li>Нажать Enter</li>
</ol>
```

Атрибуты нумерованного списка:

| Атрибут | Что делает | Пример |
| --- | --- | --- |
| `start` | с какого числа начинать | `start="5"` — 5, 6, 7… |
| `reversed` | считать в обратную сторону | 3, 2, 1 |
| `type` | вид номеров: `1`, `A`, `a`, `I`, `i` | `type="I"` — I, II, III |

```example
<ol type="A">
  <li>Москва</li>
  <li>Ташкент</li>
</ol>
<ol start="10" reversed>
  <li>Старт</li>
  <li>Полёт</li>
</ol>
```

`reversed` — атрибут без значения: достаточно написать его имя.

## Вложенные списки

Пункт списка может содержать другой список — так делают оглавления и многоуровневые меню. Вложенный список
кладут **внутрь** `<li>`, после текста пункта.

```example
<ul>
  <li>Фрукты
    <ul>
      <li>Яблоки</li>
      <li>Груши</li>
    </ul>
  </li>
  <li>Овощи</li>
</ul>
```

Частая ошибка — поставить вложенный `<ul>` между пунктами, а не внутрь пункта. Внутри `<ul>` и `<ol>` разрешены
только `<li>`.

## Список определений dl

`<dl>` (description list) — пары «термин — пояснение»: словарь, характеристики, вопросы и ответы.
`<dt>` — термин, `<dd>` — его описание.

```example
<dl>
  <dt>Процессор</dt>
  <dd>Мозг компьютера, выполняет команды.</dd>
  <dt>Оперативная память</dt>
  <dd>Хранит данные, пока компьютер включён.</dd>
</dl>
```

## Коротко

- Порядок не важен — `<ul>`, важен — `<ol>`, пары «термин — описание» — `<dl>`.
- Пункт `<ul>`/`<ol>` — всегда `<li>`; вложенный список — внутри `<li>`.
- У `<ol>` есть `start`, `reversed` и `type`.
