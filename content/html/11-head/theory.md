# Голова документа и спецсимволы

В этой теме — то, что не видно на странице, но важно для браузера, поисковиков и пользователей, и символы,
которые нельзя набрать в HTML как есть.

## Голова документа head

Вспомните каркас из первой темы. В `<head>` лежат служебные сведения:

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <meta name="description" content="Курсы английского в Андижане">
    <title>Курсы английского — Андижан</title>
    <link rel="icon" href="favicon.png">
    <link rel="stylesheet" href="style.css">
  </head>
  <body>…</body>
</html>
```

| Строка | Зачем |
| --- | --- |
| `<meta charset="utf-8">` | кодировка: без неё русские буквы могут превратиться в «кракозябры» |
| `<meta name="viewport" …>` | страница подстраивается под ширину телефона, а не показывается уменьшенной копией |
| `<meta name="description" …>` | описание страницы — его показывают поисковики под ссылкой |
| `<title>` | название на вкладке браузера и в результатах поиска |
| `<link rel="icon">` | значок на вкладке |
| `<link rel="stylesheet">` | подключение файла стилей CSS |

`<meta>` и `<link>` — одиночные теги. В практических работах голову добавляет тренажёр, поэтому задания этой темы —
про видимую часть страницы.

## Глобальные атрибуты

Есть атрибуты, которые можно поставить **любому** элементу:

| Атрибут | Что делает |
| --- | --- |
| `id`, `class` | имена элемента (вы их уже знаете) |
| `title` | всплывающая подсказка при наведении мыши |
| `lang` | язык текста внутри элемента |
| `hidden` | элемент скрыт и не показывается |
| `data-*` | свои данные для скриптов: `data-price="100"` |

```example
<p title="Сокращение от HyperText Markup Language">HTML</p>
<p lang="en">Hello, world!</p>
<p hidden>Этот абзац не виден.</p>
<button data-product="42">В корзину</button>
```

`data-` атрибуты на вид не влияют — их читает JavaScript. Имя после `data-` придумывают сами.

## Спецсимволы

Символы `<` и `>` браузер принимает за начало и конец тега, `&` — за начало спецсимвола. Чтобы показать их как
текст, пишут **мнемоники** — коды, которые начинаются с `&` и заканчиваются `;`.

| Пишем | Видим | Название |
| --- | --- | --- |
| `&lt;` | < | меньше (less than) |
| `&gt;` | > | больше (greater than) |
| `&amp;` | & | амперсанд |
| `&quot;` | " | кавычка |
| `&nbsp;` | (пробел) | неразрывный пробел |
| `&copy;` | © | копирайт |
| `&times;` | × | знак умножения |
| `&mdash;` | — | длинное тире |

```example
<p>Тег абзаца пишется так: &lt;p&gt;</p>
<p>Том &amp; Джерри</p>
<p>2 &times; 2 = 4</p>
```

**Неразрывный пробел** `&nbsp;` не даёт переносить строку в этом месте: «10&nbsp;кг», «г.&nbsp;Ташкент» — число и
слово всегда останутся на одной строке.

Символ можно вставить и как есть (©, —, ×) — страница в кодировке utf-8 их покажет. Мнемоники нужны обязательно
только для `<`, `>` и `&`.

## Коротко

- `<head>`: `meta charset`, `meta viewport`, `meta description`, `title`, `link`.
- Любому элементу: `title`, `lang`, `hidden`, `data-*`.
- `<` → `&lt;`, `>` → `&gt;`, `&` → `&amp;`; неразрывный пробел — `&nbsp;`.
