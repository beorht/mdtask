# Текст

Большая часть любой страницы — текст. HTML размечает его так, чтобы было понятно, где заголовок, где абзац, какое
слово важное, а какое — цитата.

## Заголовки h1–h6

Заголовков шесть уровней: от `<h1>` (самый главный) до `<h6>`. Уровень — это не размер шрифта, а **место в плане
страницы**: как главы, параграфы и пункты в учебнике.

```example
<h1>Путеводитель по Самарканду</h1>
<h2>Что посмотреть</h2>
<h3>Регистан</h3>
<h3>Шахи-Зинда</h3>
<h2>Где поесть</h2>
```

Правила:

- `<h1>` на странице обычно один — это её название;
- уровни не перепрыгивают: после `<h2>` идёт `<h3>`, а не сразу `<h5>`;
- заголовок выбирают по смыслу, а не потому что «нужен крупный шрифт» — размер потом задаёт CSS.

## Абзацы

Каждый абзац — отдельный элемент `<p>`. Между абзацами браузер сам делает отступ.

```example
<p>Самарканд — один из древнейших городов мира.</p>
<p>Ему больше 2700 лет.</p>
```

Перенос строки внутри абзаца — `<br>`, линия-разделитель между частями текста — `<hr>` (оба — одиночные теги).

## Важное и выделенное

| Тег | Смысл | Как обычно выглядит |
| --- | --- | --- |
| `<strong>` | важно, обратите внимание | **жирный** |
| `<em>` | смысловое ударение, интонация | *курсив* |
| `<mark>` | пометка маркером, «найдено» | жёлтый фон |
| `<small>` | мелкий шрифт: примечания, условия | маленький текст |

```example
<p>Музей открыт <strong>до 18:00</strong>, а по понедельникам <em>закрыт</em>.</p>
<p>В поиске найдено: <mark>Регистан</mark>.</p>
<p><small>Цены указаны без учёта скидок.</small></p>
```

Есть и теги `<b>` и `<i>` — просто жирный и курсив без особого смысла. Если слово действительно важное, берите
`<strong>`, если на нём ударение — `<em>`.

## Верхний и нижний индекс

`<sup>` поднимает текст вверх (степени, сноски), `<sub>` опускает вниз (химические формулы).

```example
<p>Объём куба: V = a<sup>3</sup></p>
<p>Углекислый газ: CO<sub>2</sub></p>
```

## Цитаты

Длинная цитата отдельным блоком — `<blockquote>`, внутри неё обычные абзацы. Короткая цитата внутри фразы — `<q>`:
браузер сам добавит кавычки. Название источника — `<cite>`.

```example
<blockquote>
  <p>Кто хочет — ищет возможности, кто не хочет — ищет причины.</p>
</blockquote>
<p><cite>Сократ</cite></p>
<p>Мама всегда говорит: <q>Сначала уроки, потом игры</q>.</p>
```

## Код в тексте

Название команды или кусок программы внутри фразы оформляют `<code>` — он показывается моноширинным шрифтом.
Если код занимает несколько строк и важно сохранить пробелы и переносы, его кладут в `<pre>`: внутри него браузер
ничего не склеивает.

```example
<p>Чтобы узнать длину строки, вызовите <code>len()</code>.</p>
<pre>  *
 ***
*****</pre>
```

## Коротко

- Заголовки — по плану страницы, `<h1>` один.
- Каждый абзац — свой `<p>`.
- Смысл важнее вида: `<strong>`, `<em>`, `<mark>`, `<small>`.
- Формулы — `<sup>` и `<sub>`, цитаты — `<blockquote>`, `<q>`, `<cite>`, код — `<code>` и `<pre>`.
