# Итоговая работа: страница целиком

Вы знаете всё, чтобы сверстать настоящую страницу: текст, списки, ссылки, картинки, таблицы, формы и контейнеры.
В итоговой работе вы соберёте сайт-визитку языковой школы «Lingvo» по частям, а последним заданием — целиком.

## Как разложить страницу из макета

Перед тем как писать код, посмотрите на макет и разбейте его на коробки сверху вниз:

1. **Шапка** — логотип, название, меню → `<header>` с `<nav>`.
2. **Главное** → `<main>`, внутри — разделы `<section>`, у каждого свой заголовок `<h2>`.
3. **Материалы, понятные сами по себе** (карточки курсов, отзывы) → `<article>`.
4. **Подвал** — контакты, © → `<footer>` с `<address>`.

Затем внутри каждой коробки — обычные теги: заголовки, абзацы, списки, таблицы, формы.

```scheme
<header>
  <h1>Пекарня «Нон»</h1>
  <nav>
    <a href="#bread">Хлеб</a>
    <a href="#order">Заказ</a>
  </nav>
</header>
<main>
  <section id="bread">
    <h2>Наш хлеб</h2>
    <ul>
      <li>Лепёшка</li>
      <li>Самса</li>
    </ul>
  </section>
</main>
<footer>
  <p>© 2026 Пекарня «Нон»</p>
</footer>
```

## Порядок работы

- **Сначала каркас**, потом содержимое: напишите пустые `header`, `main`, `footer` и заполняйте их по очереди.
- **Отступы** — два пробела на каждый уровень вложенности: так видно, что внутри чего.
- **Закрывайте теги сразу**: открыли `<section>` — сразу напишите `</section>` и вставляйте содержимое между ними.
- **Проверяйте по схеме**: переключатель «Схема» показывает, совпадают ли коробки.
- **Emmet** сокращает работу: `header>h1+nav>a*3` и `Tab`.

## Чек-лист перед сдачей

- `<h1>` на странице один, уровни заголовков идут по порядку.
- У каждой картинки есть `alt`.
- У каждого поля формы есть `<label>` и `name`.
- Якорные ссылки ведут на существующие `id`.
- Все теги закрыты, вложенность не перекрещивается.

## Как устроены задания

Задания 1–7 — части сайта «Lingvo» по отдельности, задание 8 — вся страница сразу. Тексты, адреса и имена
полей — в условиях.
