# Практика: сортировка и поиск

Ещё несколько классических алгоритмов. Каждый из них — пример идеи, которая пригодится далеко за пределами сортировки.

## Сортировка выбором (Selection Sort)

На каждом шаге находим наименьший элемент в неотсортированной части и ставим его на её первое место:

```text
для i от 0 до n − 2:
    m ← индекс наименьшего среди a[i..n−1]
    поменять a[i] и a[m]
```

Обменов не больше `n − 1` — меньше, чем у пузырька.

## Сортировка вставками (Insertion Sort)

Как раскладывают карты в руке: берём очередной элемент и сдвигаем его влево, пока слева стоит больший.

```text
для i от 1 до n − 1:
    x ← a[i]; j ← i − 1
    пока j ≥ 0 и a[j] > x:
        a[j + 1] ← a[j]; j ← j − 1
    a[j + 1] ← x
```

На почти отсортированных данных вставки работают очень быстро.

## Двоичный (бинарный) поиск

Работает только на **отсортированном** списке. Смотрим на середину: если искомое больше — ищем в правой половине,
меньше — в левой. Каждый шаг отбрасывает половину, поэтому в списке из миллиона элементов хватает 20 шагов —
сложность **O(log n)**.

```text
лево ← 0, право ← n − 1
пока лево ≤ право:
    середина ← (лево + право) // 2
    если a[середина] == x: найдено
    если a[середина] < x: лево ← середина + 1
    иначе: право ← середина − 1
```

Чтобы найти **первое** вхождение среди повторов, при совпадении не останавливаемся: запоминаем позицию и продолжаем
искать **левее** (`право ← середина − 1`).

## Слияние отсортированных списков

Два отсортированных списка объединяют за один проход двумя «указателями»: сравниваем текущие элементы, меньший
переносим в результат и сдвигаем его указатель. Это основа сортировки слиянием (Merge Sort).

В задачах `sorted`, `.sort()`, `min`, `max`, `.index()`, `in` для списков и модуль `bisect` запрещены.
