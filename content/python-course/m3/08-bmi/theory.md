# Мини-проект «ИМТ-калькулятор»

**Индекс массы тела** (ИМТ) — простая оценка соответствия веса росту: `ИМТ = вес (кг) / рост (м)²`.

| ИМТ | Категория |
| --- | --- |
| меньше 18.5 | Недостаток веса |
| от 18.5 до 25 (не включая) | Норма |
| от 25 до 30 | Избыточный вес |
| 30 и больше | Ожирение |

Рост обычно вводят в сантиметрах — не забудьте перевести в метры. ИМТ — только ориентир: у спортсменов с большой
мышечной массой он завышен.

## Структура программы

Хорошо разбить проект на функции:

- `bmi(weight, height_cm)` — вычислить индекс;
- `category(value)` — категория по таблице;
- ввод с проверкой (`try/except` + проверка диапазона);
- вывод отчёта.

```python run
def to_meters(cm):
    return cm / 100

print(to_meters(172))
```

## Обратная задача

Из формулы можно выразить вес: `вес = ИМТ × рост²`. Подставив границы нормы (18.5 и 24.9), получим диапазон
нормального веса для данного роста.

## Отчёт по группе
