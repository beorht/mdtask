# Пузырьковая сортировка и линейный поиск

`sorted` и `in` удобны, но важно понимать, **как** они работают. В этом уроке — два базовых алгоритма, которые пишут
вручную.

## Линейный поиск

Идём по списку слева направо и сравниваем каждый элемент с искомым. Нашли — возвращаем позицию; дошли до конца —
элемента нет (по соглашению возвращают `-1`).

```text
для i от 0 до длина − 1:
    если a[i] == x: вернуть i
вернуть −1
```

Худший случай — элемента нет или он последний: нужно `n` сравнений. Говорят, что сложность линейного поиска —
**O(n)**: время растёт пропорционально размеру списка.

## Пузырьковая сортировка (Bubble Sort)

Идём по списку и сравниваем **соседей**; если левый больше правого — меняем их местами. После первого прохода
наибольший элемент «всплывает» в конец, как пузырёк. Повторяем проходы для оставшейся части.

```text
для прохода от 1 до n − 1:
    для i от 0 до n − 1 − проход:
        если a[i] > a[i + 1]: поменять a[i] и a[i + 1]
```

Пример: `[5, 1, 4, 2]` → после 1-го прохода `[1, 4, 2, 5]` → после 2-го `[1, 2, 4, 5]` → готово.

```python run
a = [5, 1, 4, 2]
a[0], a[1] = a[1], a[0]
print(a)
```

Обмен соседей в Python — одна строка: `nums[k], nums[k + 1] = nums[k + 1], nums[k]`.

## Ранний выход

Если за весь проход не было ни одной перестановки, список уже отсортирован — дальше проходить незачем. Для этого
заводят флаг `swapped`.

## Сколько это стоит

Пузырьку нужно до `n·(n−1)/2` сравнений — сложность **O(n²)**: для 1000 элементов около полумиллиона сравнений.
Встроенный `sorted` использует гораздо более быстрый алгоритм (Timsort, O(n·log n)). Пузырёк учат, потому что на нём
лучше всего видно, как сортировка устроена.

## Своё условие сравнения

Отсортировать по убыванию — сменить `>` на `<`. Слова по длине — сравнивать `len(a[i]) > len(a[i + 1])`. При равной
длине можно сравнивать сами слова: кортежи сравниваются поэлементно, поэтому удобно сравнивать
`(len(x), x)` с `(len(y), y)`.

В задачах этого урока `sorted`, `.sort()`, `min`, `max`, `.index()` и `in` для списков запрещены.
