# Цикл while, break и continue

Цикл `for` хорош, когда заранее известно, сколько раз повторять. Цикл `while` повторяет тело, **пока условие
истинно**, — например, пока пользователь не введёт ноль или пока число не станет равно нулю.

```python run
n = 5
while n > 0:
    print(n)
    n -= 1
print("Старт!")
```

Внутри цикла что-то обязательно должно менять условие, иначе получится **бесконечный цикл** (на сайте программа
остановится через несколько секунд).

## Цифры числа без строк

Пока число не ноль: последняя цифра — `n % 10`, «отрезать» её — `n //= 10`.

```python run input=4096
n = int(input())
while n > 0:
    print(n % 10)
    n //= 10
```

## break — выйти из цикла

`break` немедленно завершает цикл. Частый шаблон — «бесконечный» цикл `while True` с выходом по условию:

```python run input=3|5|-1|8
total = 0
while True:
    x = int(input())
    if x < 0:
        break
    total += x
print("сумма:", total)
```

## continue — к следующему шагу

`continue` пропускает остаток тела и переходит к следующей проверке условия:

```python run
i = 0
while i < 10:
    i += 1
    if i % 3 != 0:
        continue
    print(i, "делится на 3")
```

## Алгоритм Евклида

Наибольший общий делитель двух чисел: пока второе число не ноль, заменяем пару `(a, b)` на `(b, a % b)`. Когда
`b` станет нулём, `a` — ответ. Это один из древнейших алгоритмов — ему больше 2000 лет.

```text
пока b ≠ 0:
    a, b ← b, a mod b
ответ: a
```

## for или while?

| Знаем, сколько повторений или по чему пройти | `for` |
| --- | --- |
| Повторяем, пока выполняется условие | `while` |
