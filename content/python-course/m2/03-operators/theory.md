# Операторы и выражения

**Выражение** — комбинация значений, переменных и операторов, которая вычисляется в одно значение:
`price * count + 500`.

## Арифметические операторы

| Оператор | Действие | Пример | Результат |
| --- | --- | --- | --- |
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление (всегда `float`) | `7 / 2` | `3.5` |
| `//` | целочисленное деление | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | возведение в степень | `7 ** 2` | `49` |

Порядок как в математике: сначала `**`, потом `*`, `/`, `//`, `%`, потом `+` и `-`. Скобки меняют порядок.

```python run
print(2 + 3 * 4, (2 + 3) * 4)
print(2 ** 10, 16 ** 0.5)
print(-7 // 2, -7 % 2)
```

`x ** 0.5` — квадратный корень. Обратите внимание: у отрицательных чисел `//` округляет **вниз**.

Сокращённое присваивание: `x += 5` то же, что `x = x + 5`; так же работают `-=`, `*=`, `//=`, `%=`.

## Сравнения

Сравнения дают `True` или `False`:

| Оператор | Смысл |
| --- | --- |
| `==` | равно (два знака! один `=` — это присваивание) |
| `!=` | не равно |
| `<`, `>` | меньше, больше |
| `<=`, `>=` | меньше или равно, больше или равно |

```python run
x = 15
print(x > 10, x == 15, x != 15)
print(10 < x < 20)
```

В Python сравнения можно писать цепочкой: `10 < x < 20`.

## Логические операторы

| Оператор | Результат `True`, если… |
| --- | --- |
| `a and b` | истинны **оба** условия |
| `a or b` | истинно **хотя бы одно** |
| `not a` | `a` ложно |

```python run
age = 16
has_ticket = True
print(age >= 18 and has_ticket)
print(age >= 18 or has_ticket)
print(not has_ticket)
```

## Делимость

Число `n` делится на `k` без остатка, если `n % k == 0`. Так проверяют чётность (`n % 2 == 0`), кратность и т. п.

```python run
n = 45
print(n % 3 == 0, n % 2 == 0)
```
