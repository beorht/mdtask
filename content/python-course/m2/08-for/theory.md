# Цикл for и range

**Цикл** повторяет блок кода. Цикл `for` проходит по элементам последовательности — списка, строки, диапазона — и
для каждого выполняет тело цикла:

```python run
for city in ["Ташкент", "Самарканд", "Бухара"]:
    print("Привет,", city)
```

Переменная цикла (`city`) по очереди получает каждый элемент. Тело цикла — строки с отступом.

## range — диапазон чисел

| Запись | Числа |
| --- | --- |
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 (конец не включается) |
| `range(10, 0, -2)` | 10, 8, 6, 4, 2 |

```python run
for i in range(1, 6):
    print(i, i * i)
```

## Накопление: сумма, произведение, счётчик

Главный приём в алгоритмах с циклом — **аккумулятор**: переменная, которую задают **до** цикла и обновляют на каждом
шаге.

```python run
total = 0
for x in [3, 8, 1]:
    total += x
print("сумма:", total)
```

- сумма начинается с `0`, произведение — с `1`;
- **счётчик**: `count = 0`, и `count += 1`, когда элемент подходит под условие.

## Поиск наибольшего в цикле

Считаем наибольшим первый элемент и сравниваем с ним остальные:

```python run
temps = [12, 18, 9, 21, 17]
best = temps[0]
for t in temps:
    if t > best:
        best = t
print(best)
```

## Цикл по строке

Строка — тоже последовательность: цикл проходит по её символам.

```python run input=2026
s = input()
for ch in s:
    print(ch)
```

## Проверка «нашёлся ли» — флаг

Чтобы узнать, есть ли среди элементов подходящий, заводят **флаг** — логическую переменную:

```python run
found = False
for x in [1, 3, 6, 7]:
    if x % 2 == 0:
        found = True
print("чётное есть" if found else "чётных нет")
```

## Вывод в одну строку

`print(x, end=" ")` выводит без перевода строки. Но удобнее собрать результат в список и вывести через `join`.

С этого урока в задачах встроенные `sum`, `max`, `min`, `sorted` часто запрещены: алгоритм нужно написать самому —
именно так он и работает внутри этих функций.
