# Мини-проект «Угадай число»

Соберём игру из всего, что уже знаем: ввод, условия, цикл `while`, счётчик, обработка ошибок. Компьютер загадывает
число от 1 до 100, игрок угадывает, программа подсказывает «больше» или «меньше».

## Случайное число

Модуль `random` даёт случайные числа: `random.randint(1, 100)` — целое от 1 до 100 включительно.

```python run
import random
print(random.randint(1, 100))
print(random.randint(1, 6), random.randint(1, 6))
```

Каждый запуск даёт другой результат — поэтому **проверить** такую программу тестами трудно. В задачах этого проекта
загаданное число приходит **первой строкой ввода** (как будто его загадал второй игрок), а в конце вы сами замените эту
строку на `random.randint` — и игра готова.

## Каркас игры

```text
секрет ← загаданное число
попытки ← 0
повторять:
    ввести число
    попытки ← попытки + 1
    если число < секрет: сказать «Больше»
    иначе если число > секрет: сказать «Меньше»
    иначе: сказать «Угадал!», выйти из цикла
```

## Защита от неправильного ввода

Игрок может ввести не число. Такую попытку не засчитываем: ловим `ValueError` и переходим к следующей итерации
через `continue`.

## Компьютер угадывает: двоичный поиск

Теперь наоборот: число загадывает человек, а компьютер угадывает. Лучшая стратегия — называть **середину** диапазона,
где может быть число. Ответ «больше» отбрасывает левую половину, «меньше» — правую. Так любое число от 1 до 100
угадывается не больше чем за 7 попыток: каждый шаг делит диапазон пополам. Этот алгоритм называется
**двоичным (бинарным) поиском**, и он встретится вам ещё много раз.

```text
низ ← 1, верх ← 100
повторять:
    середина ← (низ + верх) // 2
    назвать середину
    если ответ «больше»: низ ← середина + 1
    если ответ «меньше»: верх ← середина − 1
    если ответ «да»: конец
```
