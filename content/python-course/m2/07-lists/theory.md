# Списки

**Список** (`list`) хранит несколько значений по порядку. Его пишут в квадратных скобках через запятую:

```python run
fruits = ["яблоко", "груша", "слива"]
marks = [5, 4, 5, 3]
print(fruits)
print(len(marks))
```

Индексы и срезы работают как у строк: `fruits[0]` — первый элемент, `fruits[-1]` — последний, `marks[1:3]` — часть
списка. В отличие от строк, список **изменяемый**: элемент можно заменить, добавить, удалить.

```python run
cities = ["Ташкент", "Бухара", "Хива"]
cities[1] = "Самарканд"
print(cities)
```

## Методы списка

| Метод | Что делает |
| --- | --- |
| `append(x)` | добавить `x` в конец |
| `insert(i, x)` | вставить `x` на позицию `i` |
| `remove(x)` | удалить первое `x` (если нет — ошибка `ValueError`) |
| `pop()` / `pop(i)` | удалить и вернуть последний / `i`-й элемент |
| `index(x)` | номер первого `x` (если нет — `ValueError`) |
| `count(x)` | сколько раз встречается `x` |
| `sort()` / `reverse()` | отсортировать / развернуть список на месте |

```python run
queue = ["Ali", "Vali"]
queue.append("Gani")
queue.insert(0, "Bek")
queue.remove("Vali")
print(queue, queue.index("Gani"))
```

## Проверка «есть ли в списке»

`x in spisok` даёт `True` или `False`. Так проверяют, прежде чем вызвать `remove` или `index`:

```python run
colors = ["красный", "зелёный"]
print("синий" in colors)
```

## Список из строки ввода

Часто данные приходят одной строкой через пробел. `split()` делает из неё список **строк**, а чтобы получить список
**чисел**, каждую строку превращают в число — проще всего записью `list(map(int, ...))`: `map` применяет `int` к каждому
элементу.

```python run input=4 8 15 16 23 42
nums = list(map(int, input().split()))
print(nums, sum(nums), len(nums))
```

Обратно из списка строк в одну строку — метод `join`: `" ".join(words)`, `", ".join(words)`.

```python run
words = ["Python", "это", "просто"]
print(" ".join(words))
print("-".join(words))
```

## Встроенные функции для списков

`len(a)` — длина, `sum(a)` — сумма чисел, `min(a)` и `max(a)` — наименьший и наибольший элемент,
`sorted(a)` — новый отсортированный список. В следующих уроках вы научитесь находить сумму и максимум **сами**,
циклом — и тогда эти функции в задачах будут запрещены.
