# Переменные, типы данных, ввод

**Переменная** — имя, под которым программа хранит значение. Значение кладут в переменную знаком `=`
(присваивание): справа — что положить, слева — куда.

```python run
price = 15000
count = 3
total = price * count
print(total)
```

Имена переменных пишут латиницей, маленькими буквами, слова соединяют `_`: `total_price`, `user_name`. Имя не может
начинаться с цифры и совпадать со словами языка (`if`, `for`, `print` лучше тоже не занимать).

## Основные типы

| Тип | Что хранит | Пример |
| --- | --- | --- |
| `int` | целое число | `17`, `-3`, `0` |
| `float` | дробное число (с точкой!) | `3.14`, `-0.5`, `2.0` |
| `str` | строку — текст в кавычках | `"Ташкент"`, `'42'` |
| `bool` | логическое значение | `True`, `False` |

Тип значения показывает функция `type`:

```python run
print(type(17), type(3.5), type("17"), type(False))
```

Python сам определяет тип по значению — это называется **динамической типизацией**. Одна и та же переменная может
сначала хранить число, потом строку, но так делать не стоит: код становится запутанным.

## Приведение типов

`input()` всегда возвращает строку. Чтобы считать, строку **приводят** к числу:

| Функция | Что делает | Пример |
| --- | --- | --- |
| `int(x)` | в целое число | `int("42")` → `42`, `int(3.9)` → `3` (дробная часть отбрасывается) |
| `float(x)` | в дробное число | `float("2.5")` → `2.5` |
| `str(x)` | в строку | `str(15) + " лет"` → `"15 лет"` |
| `bool(x)` | в True / False | `bool(0)` → `False`, `bool("a")` → `True` |

```python run input=2.5|4
width = float(input())
height = int(input())
print("площадь:", width * height)
```

Если строку нельзя превратить в число (`int("abc")`), программа остановится с ошибкой `ValueError` — как с ней
справиться, будет в уроке об исключениях.

## Вывод: print и f-строки

`print` выводит несколько значений через пробел. Параметр `sep` меняет разделитель, `end` — то, что выводится в
конце (по умолчанию — перевод строки):

```python run
print(1, 2, 3, sep=" - ")
print("без перевода строки", end="!")
print()
```

Удобнее всего собирать текст **f-строкой**: перед кавычкой ставят `f`, а значения подставляют в фигурных скобках.

```python run input=Нигора|19
name = input()
age = int(input())
print(f"{name}, через 5 лет вам будет {age + 5}")
```

## Округление

`round(x, n)` — округлить до `n` знаков после точки, `round(x)` — до целого.

```python run
print(round(2.71828, 2), round(9.5), round(1 / 3, 3))
```
