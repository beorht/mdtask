# Исключения try / except

Когда что-то идёт не так — пользователь ввёл буквы вместо числа, делят на ноль, индекс вышел за границы строки, —
Python создаёт **исключение** и останавливает программу:

```python run input=двадцать
age = int(input())
print("Через год:", age + 1)
```

## Основные исключения

| Исключение | Когда возникает |
| --- | --- |
| `ValueError` | неподходящее значение: `int("abc")` |
| `ZeroDivisionError` | деление на ноль |
| `IndexError` | индекс за пределами строки или списка |
| `KeyError` | нет такого ключа в словаре |
| `TypeError` | операция с неподходящим типом: `"5" + 5` |
| `NameError` | переменная не определена |

## try / except

Код, в котором может возникнуть ошибка, кладут в блок `try`. Если ошибка случилась, Python не останавливается, а
переходит в подходящий блок `except`:

```python run input=двадцать
try:
    age = int(input())
    print("Через год:", age + 1)
except ValueError:
    print("Нужно ввести число")
```

Можно перехватывать несколько видов ошибок разными блоками:

```python run input=10|0
try:
    a = int(input())
    b = int(input())
    print(a / b)
except ValueError:
    print("Это не число")
except ZeroDivisionError:
    print("На ноль делить нельзя")
```

## else и finally

- `else` — выполняется, если в `try` ошибки **не было**;
- `finally` — выполняется **всегда** (например, чтобы закрыть файл).

```python run input=8
try:
    n = int(input())
except ValueError:
    print("Ошибка ввода")
else:
    print("Квадрат:", n * n)
finally:
    print("Готово")
```

## Свои проверки

Не всё неправильное — исключение для Python: отрицательный возраст — корректное число. Такие случаи проверяют
обычным `if`. Хорошая программа сначала ловит ошибки **формата** (`try`), затем проверяет **смысл** (`if`).

## Не перехватывайте всё подряд

`except:` без названия ошибки ловит вообще всё — даже опечатки в коде, и найти их потом трудно. Указывайте конкретное
исключение.
