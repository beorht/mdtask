# Условия if / elif / else

До сих пор программы выполнялись строка за строкой. **Условие** позволяет выбрать, какой код выполнить, в
зависимости от данных — это **ветвление** (ромб на блок-схеме).

## if

```python run input=-5
t = int(input())
if t < 0:
    print("Мороз")
print("Конец программы")
```

После условия ставится двоеточие, а код, который выполняется при истинном условии, пишется **с отступом** в 4 пробела.
Отступ в Python — часть синтаксиса: по нему Python понимает, где кончается блок.

## if / else

`else` — что делать, если условие ложно:

```python run input=12
hour = int(input())
if hour < 12:
    print("До полудня")
else:
    print("После полудня")
```

## elif — несколько вариантов

`elif` («else if») проверяется, только если все условия выше оказались ложными. Выполнится **первая** подходящая
ветка, остальные пропускаются.

```python run input=37
t = int(input())
if t >= 38:
    print("Высокая температура")
elif t >= 37:
    print("Повышенная температура")
elif t >= 36:
    print("Норма")
else:
    print("Пониженная температура")
```

Порядок проверок важен: если поставить `t >= 36` первым, до проверки на 38 программа уже не дойдёт.

## Сложные условия и вложенность

Условия соединяют `and`, `or`, `not`. Внутри ветки можно написать ещё одно условие — это **вложенное ветвление**:

```python run input=20|да
age = int(input())
student = input()
if age >= 18:
    if student == "да":
        print("Билет со скидкой")
    else:
        print("Полный билет")
else:
    print("Детский билет")
```

Часто вложенность можно заменить одним условием с `and`.

## Поиск наибольшего

Классический алгоритм: считаем первое значение наибольшим, а затем сравниваем с ним остальные и, если нашли больше,
запоминаем новое.

```text
best ← a
если b > best: best ← b
```

## Частые ошибки

- `if x = 5:` — нужно `==`;
- забытое двоеточие после условия;
- разный отступ в одном блоке;
- `else` с условием (`else x > 0:`) — у `else` условия нет.
