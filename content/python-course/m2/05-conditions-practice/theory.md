# Практика: условия

В этом уроке — прикладные задачи на ветвления. Перед кодом выпишите все случаи из условия и решите, в каком
**порядке** их проверять: от частного к общему, от самого строгого условия к мягкому.

## Повторим

```python run input=4200
total = int(input())
if total >= 5000:
    percent = 10
elif total >= 3000:
    percent = 7
else:
    percent = 0
print("Скидка:", percent, "%")
```

Переменная, заданная в одной из веток, существует дальше в программе — главное, чтобы она получила значение в
**каждой** ветке, иначе при каком-то вводе будет ошибка `NameError`.

## Сравнение строк

Строки сравнивают так же, как числа: `op == "+"`. Сравнение учитывает регистр: `"Да" == "да"` — `False`, поэтому ответы
пользователя часто приводят к одному регистру: `answer.lower() == "да"`.

## Квадратное уравнение

Уравнение `a·x² + b·x + c = 0` при `a ≠ 0` решается через **дискриминант** `D = b² − 4ac`:

- `D > 0` — два корня: `(−b − √D) / (2a)` и `(−b + √D) / (2a)`;
- `D = 0` — один корень `−b / (2a)`;
- `D < 0` — действительных корней нет.

## Упорядочивание без sorted

Расставить три числа по возрастанию можно цепочкой обменов, как в сортировке: если первое больше второго — меняем
их местами, затем то же для второго и третьего, и ещё раз для первого и второго. В Python обмен пишется в одну строку:
`a, b = b, a`.

```python run
x, y = 9, 4
if x > y:
    x, y = y, x
print(x, y)
```
