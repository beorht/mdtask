# Строки: срезы и методы

**Строка** — последовательность символов. У каждого символа есть номер — **индекс**. Нумерация начинается с нуля;
отрицательные индексы считают с конца: `-1` — последний символ.

```text
 s =  П  и  т  о  н
      0  1  2  3  4
     -5 -4 -3 -2 -1
```

```python run
s = "Питон"
print(s[0], s[4], s[-1], s[-2])
print(len(s))
```

`len(s)` — длина строки. Индекс за пределами строки — ошибка `IndexError`.

## Срезы

Срез `s[start:stop:step]` берёт часть строки: от `start` **включительно** до `stop` **не включая**, с шагом `step`.
Любую часть можно пропустить.

```python run
s = "программирование"
print(s[0:5])    # первые 5 символов
print(s[5:])     # с пятого до конца
print(s[-4:])    # последние 4
print(s[::3])    # каждый третий
print(s[::-1])   # вся строка задом наперёд
```

Строки **неизменяемы**: `s[0] = "П"` — ошибка. Методы и срезы не меняют строку, а возвращают **новую**.

## Методы строк

| Метод | Что делает | Пример |
| --- | --- | --- |
| `strip()` | убирает пробелы по краям | `"  да  ".strip()` → `"да"` |
| `lower()` / `upper()` | все буквы маленькие / большие | `"Ок".upper()` → `"ОК"` |
| `capitalize()` | первая буква большая, остальные маленькие | `"пИТОН".capitalize()` → `"Питон"` |
| `title()` | каждое слово с большой буквы | `"иван петров".title()` |
| `replace(a, b)` | заменить все `a` на `b` | `"a-b-c".replace("-", "+")` |
| `count(x)` | сколько раз встречается `x` | `"банан".count("а")` → `2` |
| `find(x)` | индекс первого `x` или `-1` | `"банан".find("н")` → `2` |
| `split()` | разбить на список слов | `"а б в".split()` → `['а', 'б', 'в']` |
| `startswith(x)` / `endswith(x)` | начинается / заканчивается ли на `x` | `"file.py".endswith(".py")` |

```python run
msg = "  Учу PYTHON каждый день  "
clean = msg.strip()
print(clean.lower())
print(clean.replace(" ", "_"))
print(clean.split())
```

## Слова из строки

`split()` разбивает строку по пробелам и возвращает **список** слов; к словам обращаются по индексу:

```python run input=Ташкент Самарканд Бухара
words = input().split()
print(words[0])
print(words[-1])
```

Склеить строку с собой несколько раз можно умножением: `"-" * 10`.
