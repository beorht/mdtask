# Кортежи и множества

## Кортеж (tuple)

**Кортеж** — как список, но **неизменяемый**. Пишется в круглых скобках:

```python run
point = (3, 4)
date = (26, 10, 2026)
print(point[0], date[-1], len(date))
```

Зачем, если есть списки? Кортеж подходит для данных, которые не должны меняться: координаты, дата, пара «имя — балл».
Кортежи можно делать ключами словаря (списки — нельзя).

**Распаковка**: значения кортежа раскладываются по переменным — этим вы уже пользовались при обмене `a, b = b, a`.

```python run
name, score = ("Али", 95)
print(name, score)
pairs = [("Аня", 5), ("Бек", 4)]
for name, mark in pairs:
    print(f"{name} — {mark}")
```

## Множество (set)

**Множество** хранит **уникальные** значения без порядка. Повторы исчезают автоматически, а проверка `x in s`
работает мгновенно даже для миллиона элементов.

```python run
s = {3, 1, 3, 2, 1}
print(s, len(s))
words = set("мама мыла раму".split())
print(words)
```

Пустое множество — `set()` (а `{}` — пустой словарь). Добавить — `s.add(x)`, удалить — `s.discard(x)`.

## Операции над множествами

| Операция | Запись | Смысл |
| --- | --- | --- |
| пересечение | `a & b` | что есть в обоих |
| объединение | `a \| b` | что есть хотя бы в одном |
| разность | `a - b` | что есть в `a`, но нет в `b` |
| симметрическая разность | `a ^ b` | что есть ровно в одном |

```python run
a = {1, 2, 3, 4}
b = {3, 4, 5}
print(a & b, a | b, a - b, a ^ b)
```

Множество не помнит порядок, поэтому для вывода его обычно сортируют: `sorted(s)` — отсортированный **список**.

## Быстрый поиск пары

Задача: есть ли в списке два числа с суммой `t`? Перебор всех пар — долго. С множеством — один проход: для каждого `x`
проверяем, видели ли уже `t − x`.

```text
видели ← пустое множество
для x в числах:
    если t − x в видели: пара найдена
    добавить x в видели
```
