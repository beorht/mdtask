В этом уроке — задачи, где главное не синтаксис, а **идея алгоритма**. Прежде чем писать код, решите задачу на бумаге:
возьмите пример из условия и проделайте шаги руками.

## Что понадобится: целочисленное деление и остаток

| Операция | Что даёт | Пример |
| --- | --- | --- |
| `a // b` | целую часть от деления | `17 // 5` → `3` |
| `a % b` | остаток от деления | `17 % 5` → `2` |

```python run
print(17 // 5, 17 % 5)
print(100 // 7, 100 % 7)
```

Эти две операции — главный инструмент для работы с **цифрами числа** и **единицами измерения**:

- `n % 10` — последняя цифра числа, `n // 10` — число без последней цифры;
- `n // 100 % 10` — цифра сотен;
- секунды в минуты и секунды: `t // 60` минут и `t % 60` секунд.

```python run input=4096
n = int(input())
print("последняя цифра:", n % 10)
print("без последней цифры:", n // 10)
```

## Жадный алгоритм

Как выдать сумму наименьшим числом монет? Берём сначала как можно больше **самых крупных** монет, остаток
выдаём монетами поменьше — и так до самой мелкой. Такой подход называется **жадным**: на каждом шаге делаем лучший
выбор «прямо сейчас».

```text
монет по 50 ← сумма // 50
остаток ← сумма % 50
монет по 20 ← остаток // 20
…
```

## Как не ошибиться

1. Сначала посчитайте ответ для примера на бумаге.
2. Запишите шаги (псевдокод).
3. Проверьте крайние случаи: ноль, единица, число из одних нулей на конце.
