# Знакомство с Python

**Программирование** — это составление инструкций для компьютера. Инструкции пишут на языке программирования, а
готовый набор инструкций называется **программой**.

**Python** — один из самых популярных языков в мире: на нём пишут сайты, анализируют данные, обучают нейросети,
автоматизируют рутину. Его выбирают для первого знакомства с программированием, потому что код на Python короткий и
читается почти как английский текст.

## Как выполняется программа

Программа на Python — это текстовый файл с расширением `.py`. Интерпретатор Python читает его **сверху вниз, строку за
строкой** и выполняет каждую команду. На этом сайте Python работает прямо в браузере: нажмите «▶ Запустить» под
примером.

## Вывод на экран: print

`print(...)` выводит на экран то, что указано в скобках. Текст пишут в кавычках — двойных `"…"` или одинарных `'…'`.

```python run
print("Привет!")
print("Я учу Python.")
```

Каждый `print` начинает новую строку. Если передать несколько значений через запятую, `print` выведет их через пробел:

```python run
print("Сегодня", "хорошая", "погода")
print(2026, "год")
```

## Ввод с клавиатуры: input

`input()` ждёт, пока пользователь введёт строку и нажмёт Enter, и возвращает введённый текст. Чтобы потом
использовать этот текст, его сохраняют в **переменную** — имя, под которым программа помнит значение:

```python run input=Бобур
city = input()
print("Вы ввели:", city)
```

В скобках `input` можно написать подсказку: `input("Ваш город: ")`. Подсказка видна только при обычном запуске; при
проверке задач её не выводят, поэтому в решениях задач подсказки можно не писать.

## Склеивание строк

Строки можно склеить знаком `+`. Пробелы при этом не добавляются — их пишут сами:

```python run input=Ташкент
city = input()
print("Добро пожаловать в " + city + "!")
```

## Комментарии

Текст после `#` Python не выполняет — это **комментарий**, пояснение для людей:

```python run
# эта строка ничего не делает
print("Комментарии не мешают программе")  # и в конце строки тоже
```

## Частые ошибки

| Ошибка | Что не так |
| --- | --- |
| `Print("Привет")` | имена в Python чувствительны к регистру: нужно `print` |
| `print(Привет)` | текст без кавычек Python считает именем переменной |
| `print("Привет)` | кавычка открыта, но не закрыта |
| лишний пробел в начале строки | отступы в Python имеют смысл, без нужды их не ставят |

## Как устроена практика

Справа от условия — редактор. **«▶ Запустить»** выполняет программу с вашим вводом (поле под редактором),
**«✓ Проверить»** — запускает её на нескольких тестах и сравнивает вывод с ожидаемым. Важен каждый символ вывода:
буквы, пробелы, знаки препинания.
