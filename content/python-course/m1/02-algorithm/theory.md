# Алгоритм: свойства, блок-схемы, псевдокод

**Алгоритм** — это точная последовательность шагов, которая приводит к результату. Рецепт блюда, инструкция к
стиральной машине, маршрут «как дойти до колледжа» — всё это алгоритмы. Программа — это алгоритм, записанный на
языке, понятном компьютеру.

## Свойства алгоритма

| Свойство | Что значит | Пример нарушения |
| --- | --- | --- |
| **Дискретность** | алгоритм разбит на отдельные шаги | «приготовьте обед» — это не шаг, а целая задача |
| **Детерминированность** (определённость) | каждый шаг понятен однозначно, при одних и тех же данных результат один и тот же | «посолите по вкусу» |
| **Конечность** | алгоритм заканчивается за конечное число шагов | «мешайте, пока не надоест» |
| **Результативность** | алгоритм даёт результат | инструкция, после которой ничего не меняется |

## Блок-схема

Алгоритм удобно нарисовать **блок-схемой**: каждый шаг — фигура, стрелки показывают порядок.

| Фигура | Что означает |
| --- | --- |
| овал | начало и конец |
| параллелограмм | ввод или вывод данных |
| прямоугольник | действие (вычисление) |
| ромб | проверка условия: дальше две стрелки «да» и «нет» |

Блок-схема «сумма двух чисел»: **Начало → ввести a → ввести b → s = a + b → вывести s → Конец**.

## Псевдокод

**Псевдокод** — запись алгоритма обычными словами, но так же строго, как в программе:

```text
начало
  ввести a
  ввести b
  s ← a + b
  вывести s
конец
```

Из псевдокода программу на Python получить совсем просто — каждая строка становится строкой кода.

## Числа в Python

`input()` всегда возвращает **строку**. Если нужно число, строку превращают в целое число функцией `int(...)`:

```python run input=7|5
a = int(input())
b = int(input())
print(a * b)
```

Без `int` Python склеил бы строки: `"7" + "5"` даёт `"75"`, а не `12`.

Арифметика: `+` сложение, `-` вычитание, `*` умножение, `/` деление (результат — дробное число).
Функция `round(x, 2)` округляет число `x` до двух знаков после точки:

```python run
print(10 / 4)
print(round(10 / 3, 2))
```

## Переменные как «ячейки»

Переменная хранит одно значение. Новое присваивание **стирает** старое. Поэтому, чтобы поменять значения двух
переменных местами, нужна третья, временная, — как при обмене содержимого двух стаканов нужен третий:

```text
temp ← x
x ← y
y ← temp
```

3. Переведите каждый шаг в строку кода.
