# CSS-переменные и порядок в стилях

## Переменные (пользовательские свойства)

Цвет бренда встречается на сайте в двадцати местах. Чтобы поменять его одной строкой, его кладут в **переменную**:

```css
:root {
  --accent: #CA2851;      /* объявление: имя начинается с двух дефисов */
  --radius: 12px;
}
.btn  { background: var(--accent); border-radius: var(--radius); }
.link { color: var(--accent); }
```

- `:root` — корень документа (`html`); объявленные там переменные видны **везде**;
- `var(--имя)` — подставить значение; `var(--имя, запасное)` — если переменная не объявлена;
- переменные **наследуются**: объявленная у блока — действует внутри него и может «перекрыть» значение из `:root`;
- с числами работает `calc()`: `padding: calc(var(--space) * 2);`.

```example Одна переменная — все места сразу
:root { --accent: #2E7D4F; }
h3 { color: var(--accent); }
.btn { background: var(--accent); color: white; border: 0; padding: 8px 14px; border-radius: 8px; }
.box { border-left: 6px solid var(--accent); padding-left: 10px; }
---
<h3>Заголовок</h3>
<p class="box">Блок с полоской</p>
<button class="btn">Кнопка</button>
```

## Тема оформления на переменных

Компоненты используют только переменные, а **тема** — это набор их значений. Тёмная часть страницы просто
переопределяет переменные:

```example Светлая и тёмная секции — одни и те же правила
:root { --bg: #FFFFFF; --text: #1C1A1B; --accent: #CA2851; }
.dark { --bg: #1C1A1B; --text: #FFE3B3; --accent: #FFB173; }
.card { background: var(--bg); color: var(--text); border: 2px solid var(--accent); padding: 12px; margin: 8px 0; }
.card b { color: var(--accent); }
---
<div class="card"><b>Светлая</b> карточка</div>
<div class="dark"><div class="card"><b>Тёмная</b> карточка — правила те же</div></div>
```

Так устроены светлая и тёмная темы и этого сайта.

## Порядок в стилях

**Сброс** в начале файла снимает неудобные значения браузера:

```css
*, *::before, *::after { box-sizing: border-box; }
body { margin: 0; }
img { display: block; max-width: 100%; }
button, input { font: inherit; }
```

**Имена классов** — по смыслу, а не по виду: `.price`, а не `.red-bold`. Популярное соглашение **БЭМ**
(блок — элемент — модификатор):

| Запись | Что это | Пример |
| --- | --- | --- |
| `.card` | блок — самостоятельный компонент | карточка товара |
| `.card__title` | элемент блока (два подчёркивания) | заголовок карточки |
| `.card--accent` | модификатор — вариант блока (два дефиса) | выделенная карточка |

Плюсы: селекторы короткие и одного веса (один класс), нет войн специфичности из темы 3, по имени сразу видно, где
элемент живёт.

Ещё правила: один класс — одна задача; не стилизовать по `id`; группировать правила по компонентам; общие значения —
в переменные.
