# Селекторы

Селектор говорит браузеру, **каким элементам** применить правило. Чем точнее селектор, тем меньше лишних классов
нужно в разметке.

## Простые селекторы

| Селектор | Кого выбирает | Пример |
| --- | --- | --- |
| `p` | все элементы с этим тегом | все абзацы |
| `.note` | все элементы с классом `note` | `<p class="note">` |
| `#top` | один элемент с `id="top"` | `<header id="top">` |
| `*` | все элементы | сброс отступов |

У элемента может быть **несколько классов** через пробел: `<p class="note big">`. Селектор `.note.big` (без пробела)
выберет элементы, у которых есть оба класса сразу.

```example Тег, класс и id
p { color: #555; }
.note { background: #FFE3B3; }
#top { color: #CA2851; }
---
<h2 id="top">Новости</h2>
<p>Обычный абзац.</p>
<p class="note">Абзац с классом note.</p>
```

## Группа селекторов

Если нескольким элементам нужен одинаковый стиль, селекторы перечисляют **через запятую**:

```css
h1, h2, .title { color: #1F3F66; }
```

## Комбинаторы: отношения между элементами

| Запись | Значение |
| --- | --- |
| `nav a` (пробел) | `a` **где угодно внутри** `nav` — потомок любой глубины |
| `ul > li` | `li`, **непосредственно** вложенный в `ul` — ребёнок |
| `h2 + p` | `p`, стоящий **сразу после** `h2` — соседний |
| `h2 ~ p` | **все** `p` после `h2` с тем же родителем |

```example Потомок и ребёнок
.menu a { color: #CA2851; }
article > p { font-weight: bold; }
---
<nav class="menu"><a href="#">Главная</a> <a href="#">Контакты</a></nav>
<article>
  <p>Абзац — ребёнок article (жирный).</p>
  <div><p>Абзац внутри div — не ребёнок article.</p></div>
  <a href="#">Ссылка вне меню</a>
</article>
```

```example Соседи
h2 + p { color: #CA2851; }
h2 ~ p { font-style: italic; }
---
<h2>Заголовок</h2>
<p>Сразу после заголовка — и красный, и курсив.</p>
<p>Дальше — только курсив.</p>
<p>И этот — курсив.</p>
```

## Селекторы по атрибутам

| Запись | Кого выбирает |
| --- | --- |
| `[disabled]` | у кого есть атрибут |
| `input[type="email"]` | атрибут равен значению |
| `a[href^="https"]` | значение **начинается** с |
| `a[href$=".pdf"]` | значение **заканчивается** на |
| `[class*="btn"]` | значение **содержит** |

```example Атрибуты
input[type="email"] { border: 3px dashed #1F3F66; }
a[href$=".pdf"] { color: #2E7D4F; font-weight: bold; }
---
<p><input type="text" placeholder="Имя"> <input type="email" placeholder="Почта"></p>
<p><a href="price.pdf">Прайс-лист (PDF)</a> · <a href="about.html">О нас</a></p>
```

## Как выбрать селектор

- Класс — основной инструмент: его можно дать любому числу элементов и использовать повторно.
- `id` уникален на странице — для стилей он слишком «сильный» (см. тему 3), обычно его оставляют для якорей и JS.
- Длинные цепочки вроде `body div.main ul li a` хрупкие: стоит поменять разметку — и стиль пропадёт. Достаточно
  `.menu a`.
