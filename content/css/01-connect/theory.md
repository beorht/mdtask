# Как CSS подключается к странице

HTML отвечает за **содержание и структуру** страницы: заголовки, абзацы, списки, ссылки. **CSS** (Cascading Style
Sheets, «каскадные таблицы стилей») — за **внешний вид**: цвета, шрифты, отступы, расположение блоков. Одна и та же
разметка может выглядеть совершенно по-разному — достаточно поменять CSS.

## Правило CSS

Стили записываются **правилами**. Правило состоит из **селектора** (кого оформляем) и **блока объявлений** в фигурных
скобках. Каждое объявление — пара «**свойство**: **значение**», в конце ставится точка с запятой.

```css
h1 {
  color: crimson;      /* свойство color, значение crimson */
  font-size: 32px;
}
```

- `h1` — селектор: правило действует на все заголовки `h1`;
- `color: crimson;` — объявление: цвет текста — малиновый;
- `/* … */` — комментарий, браузер его пропускает.

```example Одно правило — все заголовки h1
h1 {
  color: crimson;
  font-size: 32px;
}
---
<h1>Кафе «Ромашка»</h1>
<p>Обычный абзац остаётся как был.</p>
<h1>Наше меню</h1>
```

## Три способа подключить CSS

**1. Атрибут `style`** — стили прямо в теге. Действует только на этот элемент; удобно для проверки, но для сайта
неудобно: стили перемешаны с содержанием.

```html
<p style="color: green; font-size: 20px;">Зелёный абзац</p>
```

**2. Тег `<style>`** в `<head>` — стили для одной страницы.

```html
<head>
  <style>
    p { color: green; }
  </style>
</head>
```

**3. Отдельный файл** `style.css`, подключённый тегом `<link>`. Так делают на настоящих сайтах: один файл стилей
подключается ко всем страницам, и чтобы поменять цвет на всём сайте, достаточно исправить одну строку.

```html
<head>
  <link rel="stylesheet" href="style.css">
</head>
```

В практической работе разметка уже готова, а ваш CSS попадает на страницу так же, как из файла стилей.

## Несколько правил и несколько свойств

В одном правиле может быть сколько угодно объявлений, а правил на странице — сколько угодно. Если два правила
задают одно и то же свойство одному элементу, побеждает **последнее** (подробнее — в теме 3).

```example Два правила, у каждого по два свойства
body {
  background-color: #FFF8EE;
  color: #333333;
}
p {
  font-size: 18px;
  color: #8A4B2A;
}
---
<h2>О нас</h2>
<p>Мы варим кофе с 2010 года.</p>
<p>Ждём вас каждый день.</p>
```

## Частые ошибки

| Ошибка | Что будет |
| --- | --- |
| забыта `;` между объявлениями | следующее свойство не сработает |
| `colour` вместо `color` | браузер не знает такого свойства и пропустит его |
| `color: red` для `<h1>`, а в разметке `<h2>` | селектор не нашёл элемент — ничего не изменится |
| пропущена `}` | «съедается» следующее правило |

Браузер не показывает ошибок CSS — если стиль «не работает», проверьте написание свойства, двоеточие, точку с запятой
и селектор.
