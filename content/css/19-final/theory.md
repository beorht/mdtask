# Итоговая работа: страница по макету

В итоговой работе — одна страница кафе (лендинг). Сначала оформляете её **по частям**: шапка, первый экран, преимущества,
меню, отзыв, форма заказа, подвал. Последнее задание — **вся страница сразу**, и на телефоне, и на компьютере.

## Как разобрать макет

1. **Найдите блоки сверху вниз** — у каждого своя полоса: шапка, первый экран, разделы, подвал. Каждому блоку
   соответствует тег или класс в разметке (откройте вкладку «Разметка»).
2. **Внутри блока — раскладка.** Элементы в ряд → flex; сетка карточек → grid; одна колонка → обычный поток.
3. **Общие значения** — цвета, скругления, отступы — повторяются. Вынесите их в переменные (тема 18).
4. **Сначала крупное, потом мелкое**: раскладка блоков → отступы → шрифты и цвета → состояния (`:hover`) →
   адаптивность.

## Пример: от раскладки к деталям

Сначала только раскладка — блоки встали на места:

```example Шаг 1. Раскладка
.bar { display: flex; justify-content: space-between; align-items: center; }
.links { display: flex; gap: 12px; }
---
<div class="bar"><b>Кафе</b><nav class="links"><a href="#">Меню</a><a href="#">Контакты</a></nav><a href="#">Позвонить</a></div>
```

Потом отступы, цвета и шрифты — та же разметка:

```example Шаг 2. Отступы и цвета
.bar { display: flex; justify-content: space-between; align-items: center; padding: 10px 18px; background: #1F3F66; border-radius: 12px; }
.bar b { color: #FFE3B3; }
.links { display: flex; gap: 12px; }
.bar a { color: white; text-decoration: none; }
.bar > a { background: #FF6766; padding: 6px 12px; border-radius: 999px; }
---
<div class="bar"><b>Кафе</b><nav class="links"><a href="#">Меню</a><a href="#">Контакты</a></nav><a href="#">Позвонить</a></div>
```

## Самопроверка

- ничего не вылезает за край на ширине 375px;
- текст читается: размер не меньше 16px, контраст достаточный;
- ссылки и кнопки выглядят нажимаемыми, у них заметный фокус;
- одинаковые вещи выглядят одинаково (все кнопки, все карточки);
- в стилях нет `!important` и стилей по `id`.

В каждом задании описано, что должно получиться, а образец показывает, как это выглядит. Сравнивайте не только
«на глаз»: «Проверить» назовёт элемент и свойство, которые отличаются.
