# Цвета и единицы измерения

## Цвета

| Запись | Пример | Что значит |
| --- | --- | --- |
| имя | `crimson`, `white` | 148 готовых имён |
| `#RRGGBB` | `#CA2851` | красный, зелёный, синий — по два шестнадцатеричных знака (00…FF) |
| `#RGB` | `#F80` | короткая запись `#FF8800` |
| `rgb()` | `rgb(202, 40, 81)` | те же три канала числами 0…255 |
| `rgba()` / `rgb(… / a)` | `rgba(0, 0, 0, 0.5)` | четвёртое число — непрозрачность 0…1 |
| `hsl()` | `hsl(345, 67%, 47%)` | оттенок 0…360°, насыщенность, светлота |
| `transparent` | | полностью прозрачный |

`hsl` удобен для палитр: меняя только светлоту, получаем светлый и тёмный вариант одного цвета.

```example Один оттенок — разная светлота
.c1 { background: hsl(20, 90%, 85%); }
.c2 { background: hsl(20, 90%, 65%); }
.c3 { background: hsl(20, 90%, 45%); color: white; }
div { padding: 10px; }
---
<div class="c1">hsl(20, 90%, 85%)</div>
<div class="c2">hsl(20, 90%, 65%)</div>
<div class="c3">hsl(20, 90%, 45%)</div>
```

## Прозрачность: rgba и opacity

- `rgba()` / прозрачный `hsl()` делает прозрачным **только этот цвет** (например, фон);
- `opacity: 0.5` делает полупрозрачным **весь элемент** вместе с текстом и детьми.

```example rgba против opacity
.page { background: #FFB173; padding: 12px; }
.a { background: rgba(28, 26, 27, 0.6); color: white; padding: 8px; }
.b { background: #1C1A1B; color: white; padding: 8px; opacity: 0.6; }
---
<div class="page">
  <p class="a">rgba: прозрачен только фон, текст чёткий</p>
  <p class="b">opacity: прозрачно всё, и текст тоже</p>
</div>
```

## Единицы длины

| Единица | От чего считается | Когда удобна |
| --- | --- | --- |
| `px` | пиксель | рамки, тени, точные размеры |
| `%` | от размера **родителя** (ширина — от ширины родителя) | резиновые колонки |
| `em` | от размера шрифта **самого элемента** (для `font-size` — родителя) | отступы, которые растут вместе с текстом |
| `rem` | от размера шрифта **корня** `html` (обычно 16px) | размеры шрифтов на всём сайте |
| `vw` / `vh` | 1% ширины / высоты окна | экран-заставка во всю высоту |

```example em считается от родителя, rem — от html
.box { font-size: 20px; }
.em { font-size: 0.8em; }   /* 0.8 × 20 = 16px */
.rem { font-size: 1.5rem; } /* 1.5 × 16 = 24px */
---
<div class="box">
  Текст 20px
  <p class="em">0.8em = 16px</p>
  <p class="rem">1.5rem = 24px</p>
</div>
```

```example Проценты от ширины родителя
.track { background: #EEE; }
.bar { width: 60%; background: #CA2851; color: white; padding: 4px; }
---
<div class="track"><div class="bar">60% ширины родителя</div></div>
```

Совет: размеры шрифтов — в `rem`, внутренние отступы кнопок — в `em`, ширины колонок — в `%`, рамки — в `px`.
