# Каскад, наследование, специфичность

Часто на один элемент действует **несколько правил**. Браузер решает, какое из них победит, по трём признакам —
это и есть «каскад» в названии CSS.

## 1. Важность и источник

Стили браузера (по умолчанию) слабее ваших. Объявление с `!important` сильнее обычных — но им почти не пользуются:
такой стиль потом очень трудно переопределить. В заданиях темы `!important` запрещён.

## 2. Специфичность — «вес» селектора

Вес считают тремя числами **(id, классы, теги)**:

| Селектор | id | классы, атрибуты, псевдоклассы | теги, псевдоэлементы | Вес |
| --- | --- | --- | --- | --- |
| `p` | 0 | 0 | 1 | 0-0-1 |
| `.note` | 0 | 1 | 0 | 0-1-0 |
| `article p.note` | 0 | 1 | 2 | 0-1-2 |
| `#main .note` | 1 | 1 | 0 | 1-1-0 |
| атрибут `style="…"` | — | — | — | сильнее любого селектора |

Сравнивают слева направо: один id весит больше любого числа классов, один класс — больше любого числа тегов.

```example Класс сильнее тега, id сильнее класса
#special { color: #2E7D4F; }
.note { color: #CA2851; }
p { color: #888888; }
---
<p>Просто абзац — серый.</p>
<p class="note">С классом — красный, хоть правило p и ниже.</p>
<p class="note" id="special">С id — зелёный.</p>
```

## 3. Порядок

Если вес одинаковый, побеждает правило, **записанное позже**.

```example Одинаковый вес — побеждает последнее
p { color: #CA2851; }
p { color: #1F3F66; }
---
<p>Я синий: второе правило ниже.</p>
```

## Наследование

Часть свойств **передаётся** вложенным элементам: всё, что касается текста, — `color`, `font-*`, `line-height`,
`text-align`, `letter-spacing`, `visibility`, `cursor`. Поэтому цвет и шрифт удобно задать один раз у `body`.

Свойства «коробки» **не наследуются**: `margin`, `padding`, `border`, `background`, `width`, `height`, `display`.

```example Цвет и шрифт наследуются, рамка — нет
.card { color: #1F3F66; font-size: 18px; border: 2px solid #FFB173; padding: 8px; }
---
<div class="card">
  <h3>Заголовок карточки</h3>
  <p>Текст получил цвет и размер от .card, а своей рамки у него нет.</p>
</div>
```

Особые значения:

- `inherit` — взять значение у родителя (например, кнопки и поля **не** наследуют шрифт: `button { font: inherit; }`);
- `initial` — значение по умолчанию из спецификации;
- `unset` — `inherit` для наследуемых свойств, `initial` для остальных.

## Как побеждать чужие стили

В заданиях этой темы в разметке уже есть свой `<style>` — он подключён **после** вашего CSS, поэтому при равном весе
победит он. Значит, ваш селектор должен быть **точнее** (специфичнее): добавьте класс родителя, тег или второй класс.

| Чужое правило | Ваше, которое победит |
| --- | --- |
| `p { … }` | `.post p { … }` |
| `.text { … }` | `.post .text { … }` или `p.text { … }` |
| `#main .text { … }` | `#main p.text { … }` |
