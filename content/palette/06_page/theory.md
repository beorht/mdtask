# Соберите страницу целиком

Вы прошли все кирпичики: контраст, поверхности, гармонию, акцент и настроение. Последняя тема — собрать из них
**целую страницу**, где всё работает вместе.

## Порядок сборки

Удобно идти сверху вниз, от больших областей к мелким:

1. **Фон и настроение.** Выберите гамму (тёплую или холодную) и задайте фон страницы — это 60% площади.
2. **Поверхности.** Сделайте герой и карточки отделёнными от фона (светлее/темнее). Это «30%».
3. **Текст.** Проверьте контраст каждого текста на **его** фоне: заголовок и описание героя — на фоне героя,
   названия и цены — на фоне карточки.
4. **Акцент.** Один яркий цвет для кнопки (и повторите его на важных деталях). Это «10%», и он должен
   выделяться на фоне.

## Сколько цветов брать

Достаточно трёх-четырёх: фон, цвет поверхностей, тёмный цвет текста и один акцент. Больше — и палитра начинает
«шуметь». Один акцентный оттенок на всю страницу выглядит собраннее, чем пять разных.

```css
.site { background: #efe7db; }      /* фон (60%) */
.feat__card { background: #ffffff; } /* поверхности (30%) */
.hero2__title { color: #241f1b; }    /* текст */
.hero2__btn { background: #b5471f; } /* акцент (10%) */
```

## Проверьте целиком

Отойдите взглядом: читается ли всё, видно ли карточки, бросается ли в глаза кнопка, держится ли гамма одного
настроения. Тренажёр проверит каждый из этих пунктов. Одна и та же страница может быть и тёплой, и холодной —
попробуйте оба варианта и почувствуйте разницу.
