# Акцент и правило 60-30-10

Хорошая палитра почти никогда не состоит из равных по силе цветов. Обычно есть **спокойная основа** и
**один яркий акцент**, который ведёт взгляд к главному — к кнопке, цене, важной ссылке.

## Правило 60-30-10

Простой рецепт сбалансированной палитры — делить площадь цвета так:

- **60%** — основной, фоновый цвет (фон страницы, крупные области);
- **30%** — вторичный (поверхности, блоки, второй по заметности);
- **10%** — **акцент** (кнопки, важные детали) — его мало, поэтому он и выделяется.

Если акцента много, он перестаёт быть акцентом: когда всё яркое — ничего не выделяется.

## Один акцент, а не пять

Типичная ошибка новичка — раскрасить каждую деталь в свой цвет. Лучше выбрать **один** акцентный оттенок и
применять его ко всем «зовущим к действию» элементам: кнопка, точки у пунктов, подпись-рубрика — одного цвета.

```css
.promo__cta { background: #c6502a; }        /* акцент */
.promo__feature-dot { background: #c6502a; } /* тот же акцент */
.promo__eyebrow { color: #b5471f; }          /* он же, чуть темнее */
```

## Акцент должен выделяться

Акцент работает, только если он **заметно отличается от фона**. Тёплый акцент (оранжевый, коралловый) особенно
бросается в глаза на спокойной холодной или нейтральной основе. Проверьте: видно ли кнопку сразу, не
вглядываясь? Тренажёр подскажет, если акцент сливается с фоном или если акцентов получилось несколько разных.
