# Настроение: тёплое и холодное

Цвет вызывает чувство ещё до того, как прочитан текст. Один и тот же макет можно сделать уютным или строгим,
бодрым или спокойным — одной лишь **гаммой**. Главный рычаг здесь — **температура** цвета.

## Тёплые и холодные цвета

Круг делится пополам:

- **Тёплые** — красный, оранжевый, жёлтый, тёплый розовый. Ощущение: уют, энергия, аппетит, осень.
- **Холодные** — зелёный, голубой, синий, фиолетовый. Ощущение: спокойствие, свежесть, технологичность, зима.

Выбирая, какое настроение нужно макету, вы выбираете половину круга, из которой берёте цвета.

```css
/* тёплое, уютное */
.mood__art { background: #f1b98a; }
.mood__btn { background: #c25a2b; }

/* холодное, спокойное */
.mood__art { background: #9fc4d8; }
.mood__btn { background: #2f6f9e; }
```

## Насыщенность задаёт громкость

Тёплое бывает и кричащим (чистый `#ff5a00`), и мягким, припылённым (`#d9a583`). Для нежного, спокойного
настроения берут **менее насыщенные** оттенки; для яркого, энергичного — насыщенные.

## Температура и читаемость — не спорят

Настроение задают крупные цветные области (иллюстрации, кнопки, панели). А текст по-прежнему должен читаться:
на светлой тёплой гамме — тёмный текст, на тёмной — светлый. Сначала выберите настроение, затем проверьте
контраст текста. Можно объединять с прошлой темой: собрать тёплую гамму **из соседних оттенков** — тогда она и
по настроению цельная, и гармоничная.
