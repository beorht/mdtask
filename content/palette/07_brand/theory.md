# По образцу: фирменный стиль

На реальной работе цвета чаще не выбирают с нуля, а **берут из фирменного стиля** (бренд-гайда). У компании
есть своя палитра — несколько точных цветов с кодами, — и задача дизайнера-верстальщика: **аккуратно применить
её**, не перепутав, какой цвет куда идёт.

## Что такое бренд-гайд

Бренд-гайд — это список фирменных цветов с их **точными кодами** и назначением:

- **основной фон** — спокойный, занимает большую площадь;
- **цвет текста** — тёмный, читаемый;
- **акцент** — фирменный яркий цвет (кнопки, важные детали);
- иногда — цвет поверхностей, второй акцент.

В этих заданиях бренд-гайд показан слева от макета. **Нажмите на образец — его код скопируется**, останется
вставить его в CSS или набрать в пипетке.

## Задача — воспроизвести точно

Здесь важно не «красиво вообще», а **попасть в фирменный цвет**. Для каждого элемента возьмите из гайда
нужный код и примените его к правильному классу:

```css
.product-card { background: #fff8f0; } /* фон из гайда */
.product-card__title { color: #2a1e16; } /* заголовок из гайда */
.product-card__btn { background: #b5471f; } /* акцент из гайда */
```

Тренажёр сверяет ваш цвет с фирменным по **цветовому расстоянию** — небольшое отклонение допустимо, грубая
ошибка (перепутанный или заметно другой цвет) — нет.

## Читаемость — всё ещё на вас

Бренд задаёт цвета фона и акцента, но подобрать **читаемый цвет текста на кнопке** (обычно белый или тёмный) —
по-прежнему ваша работа. Применили фирменный акцент на кнопку — проверьте, что надпись на ней читается.
