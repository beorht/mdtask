# Поверхности и глубина

На сайте редко всё лежит на одном фоне. Обычно есть **фон страницы** и **поверхности** на нём — карточки,
панели, шапки. Чтобы интерфейс читался, поверхности должны быть **видимо отделены** от фона.

## Фон и поверхность — разные

Если карточка того же цвета, что и страница, она «растворяется» — непонятно, где её край. Делают так:

- **светлая страница — ещё более светлые (белые) карточки**, или слегка затенённый фон и белые карточки;
- либо наоборот: **тёмная страница — светлые карточки**.

Разница не обязана быть огромной: достаточно, чтобы глаз видел границу. В тренажёре это проверяет правило
«различимости» — фон карточки и фон страницы не должны почти совпадать.

```css
body { background: #eceef4; }   /* чуть затенённый фон */
.card { background: #ffffff; }  /* белые карточки «всплывают» */
```

## Глубину дают три приёма

1. **Разные заливки** фона и поверхности (главное).
2. **Тень** — мягкая тень снизу приподнимает карточку (в этих заданиях тень уже задана).
3. **Граница** — тонкая линия по краю, если фон и карточка близки.

## Текст всё ещё должен читаться

Сменили фон карточки — проверьте контраст текста на **новом** фоне. На белой карточке тёмный текст читается;
на тёмной странице заголовок должен стать светлым. Правило простое: контраст считаем относительно того фона,
**на котором реально лежит** текст.
