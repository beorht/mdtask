# Цветовой круг и гармония

Контраст делает текст читаемым. Теперь — как сделать, чтобы цвета **сочетались**, а не спорили. Для этого есть
**цветовой круг**: все оттенки (тон, hue) расставлены по кругу от красного через жёлтый, зелёный, синий и обратно.

## Схемы сочетаний

Красивые палитры почти всегда построены по одной из схем — это выбранные **положения на круге**:

- **Монохромная** — один тон, разная светлота и насыщенность. Спокойно и надёжно.
- **Аналоговая** — 2–3 **соседних** оттенка (красный + оранжевый + жёлтый). Мягко, естественно.
- **Комплементарная** — два **противоположных** оттенка (синий ↔ оранжевый). Сильный, живой контраст.
- **Триада** — три оттенка на равном расстоянии (через 120°). Ярко и сбалансированно.

## Насыщенность и светлота

У цвета три параметра (модель HSL): **тон** (hue, положение на круге), **насыщенность** (saturation, от серого
до яркого) и **светлота** (lightness, от чёрного до белого). Схема задаёт тон; насыщенностью и светлотой вы
настраиваете, насколько цвет кричащий или приглушённый.

```css
.hero__sun { background: #e24d3c; }   /* красный */
.hero__panel { background: #e8963f; } /* оранжевый — рядом на круге */
.hero__btn { background: #d23f6a; }   /* розово-красный — тоже рядом */
```

## Правило

Берите **один** принцип на палитру: соседние оттенки (аналоговая) или противоположные (комплементарная). Если
намешать случайные тона со всего круга, палитра «распадётся». В заданиях тренажёр подскажет, сложилась ли
выбранная схема.
