# Map, Set и JSON

## Set — множество

`Set` хранит значения **без повторов**. Проверка `has` работает мгновенно даже на больших наборах (у массива
`includes` перебирает всё).

```js run
const tags = new Set(['js', 'css', 'js']);
tags.add('html');
console.log(tags.size, tags.has('css'), [...tags]);
```

Пересечение двух наборов: оставить элементы первого, которые `has` во втором.

## Map — словарь с любыми ключами

`Map` похож на объект, но ключом может быть что угодно (число, массив, объект), он помнит порядок добавления и
знает свой размер.

```js run
const visits = new Map();
for (const page of ['/', '/news', '/']) visits.set(page, (visits.get(page) || 0) + 1);
console.log(visits, visits.size);
for (const [page, n] of visits) console.log(page, n);
```

| Объект | Map |
| --- | --- |
| ключи — только строки | ключи любые |
| числовые ключи «перескакивают» вперёд | порядок всегда как добавляли |
| `Object.keys(o).length` | `m.size` |
| удобен для записей с известными полями | удобен как словарь для подсчётов и поиска |

## JSON

**JSON** — текстовый формат данных: так их передают по сети и хранят в файлах. Он похож на объекты JavaScript, но
ключи и строки — только в двойных кавычках, а функций и `undefined` нет.

```js run
const text = '{"name":"Аня","marks":[5,4]}';
const data = JSON.parse(text);            // строка → объект
data.marks.push(5);
console.log(JSON.stringify(data));        // объект → строка
console.log(JSON.stringify({ a: 1 }, null, 2));
```

`JSON.parse` бросает ошибку, если строка — не JSON (как с ней справиться — в уроке 5.1). `Map` и `Set` в JSON
напрямую не превращаются — их сначала делают массивами: `[...set]`, `[...map]`.

## Быстрый поиск пары

«Есть ли в массиве два числа с суммой X?» — двойной цикл делает ~n² шагов. С `Map` хватает одного прохода: для
каждого числа проверяем, встречалось ли уже `X − число`.
