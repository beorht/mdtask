# Сортировка и поиск

## Встроенный sort и его ловушка

`arr.sort()` сортирует **на месте** и по умолчанию сравнивает элементы **как строки**:

```js run
console.log([10, 9, 1, 100].sort());
console.log([10, 9, 1, 100].sort((a, b) => a - b));
```

Функция сравнения `(a, b) => …` возвращает отрицательное число, если `a` раньше, положительное — если `b` раньше,
`0` — если порядок не важен. `a - b` — по возрастанию, `b - a` — по убыванию. Сортировка в JavaScript **устойчивая**:
равные элементы сохраняют исходный порядок.

## Сортировка по нескольким полям

Сравниваем по первому полю; если равны — по второму:

```js run
const people = [{ n: 'Бек', age: 17 }, { n: 'Аня', age: 17 }, { n: 'Ира', age: 16 }];
people.sort((x, y) => x.age - y.age || (x.n < y.n ? -1 : 1));
console.log(people.map((p) => p.n).join(' '));
```

## Алгоритмы сортировки вручную

| Алгоритм | Идея | Сравнений |
| --- | --- | --- |
| пузырёк | соседи меняются местами, пока есть беспорядок; большие «всплывают» в конец | ~n² |
| выбор | найти минимум оставшейся части и поставить его на место | ~n² |
| вставки | брать элементы по одному и вставлять в уже отсортированную часть | ~n² (быстро на почти отсортированных) |
| слияние | разделить пополам, отсортировать половины (рекурсией), слить | ~n·log n |
| подсчёт | для небольших целых значений: посчитать, сколько раз встречается каждое | ~n |

## Двоичный поиск

В **отсортированном** массиве элемент ищут, каждый раз сравнивая с серединой и отбрасывая половину: из миллиона
элементов — не больше 20 сравнений.

```js run
const sorted = [2, 5, 8, 12, 16, 23, 38];
let lo = 0;
let hi = sorted.length - 1;
let steps = 0;
while (lo <= hi) {
  const m = Math.floor((lo + hi) / 2);
  steps++;
  if (sorted[m] === 23) { console.log('нашли на позиции', m, 'за', steps); break; }
  if (sorted[m] < 23) lo = m + 1; else hi = m - 1;
}
```
