# Массивы

**Массив** — упорядоченный список значений. Номера (индексы) начинаются с **нуля**.

```js run
const fruits = ['яблоко', 'груша', 'слива'];
console.log(fruits[0], fruits.length, fruits.at(-1));
fruits[1] = 'персик';
console.log(fruits);
```

## Добавить и убрать

| Метод | Что делает |
| --- | --- |
| `push(x)` / `pop()` | добавить в конец / забрать последний |
| `unshift(x)` / `shift()` | добавить в начало / забрать первый |
| `splice(i, k)` | удалить k элементов с позиции i (и вернуть их) |
| `splice(i, 0, x)` | вставить x на позицию i |
| `slice(a, b)` | **копия** части массива с a до b (исходный не меняется) |

```js run
const queue = ['Аня', 'Бек'];
queue.push('Лола');
const first = queue.shift();
console.log(first, queue);
queue.splice(1, 0, 'Дима');
console.log(queue, queue.slice(0, 2));
```

## Найти

`indexOf(x)` — позиция или `-1`, `includes(x)` — есть ли. `join(sep)` — склеить в строку.

## Массив из ввода

```js run input=5 2 9
const nums = input().split(' ').map(Number);
console.log(nums, nums.length);
```

`split(' ')` даёт массив строк, `.map(Number)` превращает каждую в число (как это работает — в уроке 4.3).

## Ссылки, а не копии

Переменная хранит **ссылку** на массив. `const b = a` не копирует — обе переменные смотрят на один массив. Копия —
`a.slice()` или `[...a]`.

```js run
const a = [1, 2];
const b = a;
b.push(3);
console.log(a);
```

## Два указателя

Многие задачи на массивы решаются **двумя индексами**, которые идут навстречу друг другу или по двум массивам сразу —
без вложенных циклов. Так, например, сливают два отсортированных массива в один.
