# Мини-проект «Каталог товаров»

Соберём небольшое приложение из всего, что было в модуле: массив объектов, функции, методы массивов, `Map`, JSON.
Каталог — это **данные** плюс **функции**, которые с ними работают, плюс **команды**, которые выбирают функцию.

## Структура программы

```js run
const products = [
  { id: 1, title: 'Тетрадь', category: 'канцелярия', price: 15 },
  { id: 2, title: 'Мяч', category: 'спорт', price: 300 },
];
const cheaperThan = (list, max) => list.filter((p) => p.price < max);
const show = (p) => '#' + p.id + ' ' + p.title + ' — ' + p.price;
cheaperThan(products, 100).forEach((p) => console.log(show(p)));
```

1. **Данные** — массив объектов. В задачах каталог приходит строкой JSON.
2. **Функции-запросы** — каждая делает одно: найти, отфильтровать, отсортировать, посчитать. Они **не печатают**, а
   возвращают результат — так их легко комбинировать.
3. **Вывод** — одна функция форматирует товар, чтобы все строки выглядели одинаково.
4. **Команды** — объект «имя команды → обработчик», как калькулятор из урока 3.2.
