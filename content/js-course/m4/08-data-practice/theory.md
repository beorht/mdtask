# Практика: обработка данных

Настоящие программы чаще всего делают одно и то же: **получить список записей → сгруппировать → посчитать →
отсортировать → показать**. В этом уроке — задачи такого вида. Порядок работы:

1. **Разобрать ввод** в массив объектов `{ поле: значение }` — дальше работать только с ним.
2. **Сгруппировать**: объект или `Map` «ключ группы → массив записей».
3. **Посчитать** по каждой группе: сумма, среднее, лучший.
4. **Вывести** в нужном порядке — если порядок важен, отсортируйте копию.

```js run
const sales = [
  { city: 'Ташкент', sum: 300 },
  { city: 'Бухара', sum: 120 },
  { city: 'Ташкент', sum: 80 },
];
const byCity = new Map();
for (const s of sales) {
  if (!byCity.has(s.city)) byCity.set(s.city, []);
  byCity.get(s.city).push(s);
}
for (const [city, list] of byCity) {
  const total = list.reduce((acc, s) => acc + s.sum, 0);
  console.log(city, list.length, total);
}
```

## Топ-N

Отсортировать копию по нужному полю и взять `slice(0, n)`. При равенстве задайте второе правило сравнения — иначе
порядок «случайно» зависит от входа.

## Текст как данные

Текст разбивают на слова: всё к нижнему регистру, знаки препинания убрать, разрезать по пробелам и выбросить пустые
строки. Для «убрать знаки» подойдёт перебор символов с проверкой «буква ли это»: у буквы `toLowerCase()` и
`toUpperCase()` различаются.

## Аккуратный вывод

- деньги и средние — `toFixed`;
- проценты считают от **целого**, а не от суммы округлённых частей;
- проверяйте пустые группы: деление на 0 даёт `NaN`.
