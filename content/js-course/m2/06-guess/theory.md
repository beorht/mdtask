# Мини-проект «Угадай число»

Соберём игру из того, что уже знаем: ввод, условия, циклы, счётчики, проверка ввода. В настоящей игре число
загадывает `Math.random()`, а в задачах курса загаданное число — **первая строка ввода**, чтобы проверка была
одинаковой у всех.

## План программы

1. Прочитать загаданное число.
2. Повторять: прочитать попытку → сравнить → подсказать «больше» или «меньше».
3. Остановиться, когда угадали (или кончились попытки), — сообщить результат.

Сначала — словами, потом — код. Каждый следующий шаг проекта добавляет одно правило.

## Состояние игры

Игра помнит: загаданное число, номер попытки, сколько попыток осталось. Это переменные **до** цикла.

```js run input=42|50|30|42
const secret = Number(input());
let tries = 0;
while (true) {
  const guess = Number(input());
  tries++;
  if (guess === secret) break;
  console.log(guess < secret ? 'больше' : 'меньше');
}
console.log('угадано за', tries);
```

## Компьютер угадывает

Если число от 1 до 100, его можно угадать не больше чем за 7 попыток: называем **середину** промежутка и по ответу
отбрасываем половину. Это **двоичный поиск** — один из главных алгоритмов в программировании.
