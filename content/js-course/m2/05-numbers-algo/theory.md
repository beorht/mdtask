# Практика: алгоритмы на числах

В этом уроке — классические алгоритмы, которые встречаются на собеседованиях и олимпиадах. Все они построены из
трёх приёмов: **перебор**, **счётчик / накопитель** и **флаг**.

## Флаг: «нашли — не нашли»

Флаг — логическая переменная, которая меняется, если встретилось что-то важное. Проверка простоты числа: перебираем
делители, нашли хоть один — число составное.

```js run input=91
const n = Number(input());
let prime = n > 1;
for (let d = 2; d * d <= n; d++) {
  if (n % d === 0) {
    prime = false;
    break;
  }
}
console.log(n, prime ? 'простое' : 'составное');
```

Делители достаточно искать до **корня** из n: если n = a × b, один из множителей не больше √n. Это ускоряет
проверку в тысячи раз для больших чисел.

## Вложенный перебор

«Все простые до N» — для каждого числа своя проверка (цикл в цикле).

## Разложение на множители

Делим число на 2, пока делится, потом на 3, на 4… Каждый раз, когда делится, — нашли множитель:

```js run input=360
let n = Number(input());
let d = 2;
const parts = [];
while (n > 1) {
  while (n % d === 0) {
    parts.push(d);
    n /= d;
  }
  d++;
}
console.log(parts.join(' * '));
```

## Как подходить к задаче

1. Решите пример на бумаге и запишите шаги словами.
2. Найдите, что повторяется, — это тело цикла; что накапливается — переменная до цикла.
3. Проверьте крайние случаи: 0, 1, одно число, самое большое.
