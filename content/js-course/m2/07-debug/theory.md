# Отладка: ищем ошибки

Ошибки бывают трёх видов:

| Вид | Как проявляется | Пример |
| --- | --- | --- |
| **синтаксическая** | программа не запускается: `SyntaxError` | забыта скобка или кавычка |
| **во время работы** | программа падает: `ReferenceError`, `TypeError` | опечатка в имени, `null.length` |
| **логическая** | работает, но ответ неверный | `'2' + '3'` вместо 5, `<` вместо `<=` |

```js run
const price = '100';
const count = 3;
console.log(price + count);   // '1003' — логическая ошибка: строка + число
console.log(Number(price) * count);
```

## Как искать

1. **Прочитайте сообщение об ошибке** — в нём тип ошибки и что не так.
2. **Выведите промежуточные значения** `console.log` в подозрительных местах — где значение впервые не то, там и ошибка.
3. **Проверьте крайние случаи**: 0, 1, пустая строка, первая и последняя итерация цикла (ошибки «на единицу»).

## Ловушки JavaScript

```js run
console.log(0.1 + 0.2 === 0.3);        // false — двоичные дроби
console.log('10' > '9');               // false — строки сравниваются по символам
console.log(-7 % 3, Math.floor(-7 / 3), Math.trunc(-7 / 3));
console.log((1.005).toFixed(2));       // '1.00' — тоже из-за двоичных дробей
console.log(typeof NaN, NaN === NaN);  // 'number', false
```

Задачи урока — программы, в которых новички чаще всего ошибаются. Напишите каждую так, чтобы ловушка не сработала.
