# Переменные и типы

**Переменная** — именованная «коробка» для значения. Её создают словом `let` (значение можно менять) или
`const` (значение задаётся один раз).

```js run
let score = 10;
score = score + 5;   // меняем значение
const city = 'Ташкент';
console.log(score, city);
```

- имя — латинские буквы, цифры, `_` и `$`, не с цифры; регистр важен (`age` и `Age` — разные);
- имена пишут «верблюдом»: `userName`, `totalPrice`;
- по умолчанию пишите `const`, а `let` — когда значение будет меняться;
- старое слово `var` в новом коде не используют.

## Типы значений

| Тип | Примеры | `typeof` |
| --- | --- | --- |
| число | `42`, `3.14`, `-7` | `'number'` |
| строка | `'текст'`, `"да"` | `'string'` |
| логическое | `true`, `false` | `'boolean'` |
| «ничего» | `null` | `'object'` (историческая ошибка языка) |
| «не задано» | `undefined` | `'undefined'` |

```js run
console.log(typeof 7, typeof 'семь', typeof false);
let x;
console.log(x);
```

## Числа из ввода

`input()` всегда возвращает **строку**. `'2' + '3'` — это `'23'` (строки склеиваются)! Чтобы считать, строку
превращают в число: `Number(input())` (подробно — в уроке 1.4).

```js run input=2|3
const a = input();
const b = input();
console.log(a + b);                  // склейка строк
console.log(Number(a) + Number(b));  // сумма чисел
```

## Обмен значений

Чтобы поменять значения двух переменных, нужна третья, временная:

```js run
let left = 'кот';
let right = 'пёс';
const keep = left;
left = right;
right = keep;
console.log(left, right);
```
