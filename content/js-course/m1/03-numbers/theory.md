# Числа и операторы

| Оператор | Что делает | Пример | Результат |
| --- | --- | --- | --- |
| `+ - *` | сложение, вычитание, умножение | `7 * 3` | 21 |
| `/` | деление (всегда «как есть», с дробью) | `7 / 2` | 3.5 |
| `%` | **остаток** от деления | `17 % 5` | 2 |
| `**` | степень | `2 ** 10` | 1024 |

Целой части деления в JavaScript нет как отдельного оператора — её получают через `Math.floor(a / b)` (для
отрицательных — `Math.trunc`).

```js run
console.log(17 / 5, Math.floor(17 / 5), 17 % 5);
console.log(2 ** 8, (2 + 3) * 4, 2 + 3 * 4);
```

## Разряды числа

`% 10` даёт последнюю цифру, `Math.floor(n / 10)` «отрезает» её:

```js run
const n = 4096;
console.log(n % 10);                    // 6
console.log(Math.floor(n / 10) % 10);   // 9
console.log(Math.floor(n / 1000));      // 4
```

## Math

`Math.round` (до целого), `Math.floor` (вниз), `Math.ceil` (вверх), `Math.abs` (модуль),
`Math.sqrt` (корень), `Math.max/min`, `Math.PI`.

Округлить до двух знаков: `Math.round(x * 100) / 100`.

## Сокращённые записи

`x += 5` — то же, что `x = x + 5`; `x++` — увеличить на 1. Так же `-=`, `*=`, `/=`, `%=`.

## Особые числа

`NaN` («не число») получается из бессмысленных операций (`'abc' * 2`), `Infinity` — при делении на ноль.

## Точность

Дроби хранятся в двоичном виде, поэтому `0.1 + 0.2` даёт `0.30000000000000004`. Деньги удобно считать в копейках
(целыми числами).
