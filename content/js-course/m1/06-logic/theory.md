# Сравнение и логика

Сравнение даёт **логическое** значение — `true` или `false`.

| Оператор | Значит |
| --- | --- |
| `===` / `!==` | равно / не равно **с учётом типа** |
| `==` / `!=` | равно с приведением типов (`'5' == 5` — true) — **не используйте** |
| `> < >= <=` | больше, меньше… |

```js run
console.log(5 === 5, '5' === 5, '5' == 5);
console.log('10' < '9');          // строки сравниваются по символам!
console.log(Number('10') < Number('9'));
```

## Логические операторы

- `a && b` — «и»: true, если оба true;
- `a || b` — «или»: true, если хотя бы одно true;
- `!a` — «не».

```js run
const age = 17;
console.log(age >= 14 && age <= 18);   // подросток?
console.log(age < 6 || age > 65);      // льгота?
console.log(!(age > 18));
```

## Истинное и ложное

В условиях любое значение превращается в логическое. **Ложные**: `false`, `0`, `''`, `null`, `undefined`, `NaN`.
Всё остальное — истинное (даже `'0'` и `' '`).

`a || b` возвращает первое истинное значение, `a ?? b` — первое, которое не `null`/`undefined`:

```js run input=
const name = input() || 'гость';
console.log('Привет, ' + name);
```

## Високосный год

Год високосный, если делится на 4, но не на 100, — или делится на 400:

```js run
const year = 2100;
console.log((year % 4 === 0 && year % 100 !== 0) || year % 400 === 0);
```
