# JavaScript и где он работает

**JavaScript** — язык, на котором «оживают» веб-страницы: кнопки реагируют на нажатия, формы проверяют поля, данные
подгружаются без перезагрузки. Он встроен в каждый браузер, а с помощью Node.js работает и на сервере.

## Первая программа

Программа — это последовательность **инструкций**, которые выполняются сверху вниз. Чтобы что-то показать, используют
`console.log(…)` — он печатает значение в **консоль**.

```js run
console.log('Привет!');
console.log('Сегодня первый урок');
console.log(2 + 3);
```

- текст пишут в кавычках: `'…'` или `"…"`;
- числа — без кавычек, с ними можно считать;
- в конце инструкции ставят точку с запятой `;` (не обязательно, но так принято).

Несколько значений через запятую выводятся в одну строку через пробел:

```js run
console.log('Сумма:', 7 + 8);
```

## Комментарии

Всё после `//` до конца строки и между `/* … */` — комментарий: браузер его не выполняет. Комментарии пишут для людей.

## Ввод в учебных задачах

На настоящей странице данные приходят из полей формы или из окна `prompt()`. В задачах курса для этого есть
функция сайта `input()`: каждый вызов возвращает **следующую строку** ввода теста — всегда как **текст**.

```js run input=Аня
const name = input();
console.log('Здравствуй,', name);
```

## Консоль разработчика

В любом браузере есть консоль: клавиша F12 → вкладка «Console». В ней можно сразу набрать `2 + 2` и нажать Enter —
так удобно проверять маленькие кусочки кода.
