# Ввод и преобразование типов

Всё, что вводит пользователь, — **строка**. Перед вычислениями её нужно превратить в число.

| Функция | Что делает | Пример |
| --- | --- | --- |
| `Number(s)` | вся строка → число; не получилось → `NaN` | `Number('3.5')` → 3.5, `Number('3px')` → NaN |
| `parseInt(s)` | целое число **с начала** строки | `parseInt('42px')` → 42 |
| `parseFloat(s)` | дробное число с начала строки | `parseFloat('9.5 кг')` → 9.5 |
| `String(x)` | значение → строка | `String(10)` → '10' |

```js run input=12|7.5|45px
const a = Number(input());
const b = Number(input());
const c = parseInt(input());
console.log(a + b, c * 2);
```

## Проверка, число ли это

`NaN` не равен даже самому себе, поэтому проверяют функцией `Number.isNaN(x)`:

```js run input=сорок
const value = Number(input());
console.log(Number.isNaN(value));
```

## Неявные преобразования

JavaScript сам меняет типы в выражениях — это частый источник ошибок:

```js run
console.log('5' + 1);   // '51' — с плюсом строка «побеждает»
console.log('5' - 1);   // 4 — минус работает только с числами
console.log('5' * '2'); // 10
```

Правило: приводите типы **явно** сразу при вводе.

## Красивый вывод дробей

`x.toFixed(2)` — строка с ровно двумя знаками после точки: `(2.5).toFixed(2)` → `'2.50'`.
