# Функции высшего порядка

**Функция высшего порядка** принимает функцию как аргумент или возвращает функцию. Переданную функцию называют
**колбэком** (callback) — «позови меня, когда понадобится».

```js run
function twice(fn, x) {
  return fn(fn(x));
}
console.log(twice((n) => n + 10, 1));
console.log(twice((s) => s + '!', 'ура'));
```

## Свой «перебор с действием»

Функция может отвечать за **как перебирать**, а колбэк — за **что делать** с каждым элементом:

```js run
function eachDigit(n, action) {
  while (n > 0) {
    action(n % 10);
    n = Math.floor(n / 10);
  }
}
eachDigit(507, (d) => console.log('цифра', d));
```

Так устроены встроенные методы массивов `map`, `filter`, `reduce` (модуль 4). В этом уроке мы пишем такие функции
сами — чтобы понимать, что происходит внутри.

## Функция, которая делает функцию

```js run
function adder(k) {
  return (x) => x + k;
}
const plus5 = adder(5);
console.log(plus5(1), adder(-1)(10));
```

## Композиция

Из маленьких функций собирают «конвейер»: результат одной — вход следующей.

## Колбэк и время

`setTimeout(колбэк, мс)` — тоже функция высшего порядка: колбэк вызывается позже. В задачах курса время
«виртуальное»: ждать по-настоящему не нужно, но порядок срабатываний — как в браузере.

```js run
setTimeout(() => console.log('через 200 мс'), 200);
setTimeout(() => console.log('через 100 мс'), 100);
console.log('сразу');
```

## Сравнение через функцию

Алгоритм сортировки может не знать, **как** сравнивать элементы: он получает функцию `compare(a, b)`, которая
возвращает отрицательное число, если `a` должен стоять раньше, положительное — если позже, и 0 — если всё равно.
