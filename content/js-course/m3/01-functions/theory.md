# Объявление функций

**Функция** — именованный кусок кода, который можно вызывать много раз. Функции делят большую задачу на маленькие
понятные шаги и избавляют от повторов.

```js run
function greet(name) {
  return 'Привет, ' + name + '!';
}
console.log(greet('Аня'));
console.log(greet('Бек'));
```

- `name` — **параметр**: переменная, которая получает значение при вызове;
- `'Аня'` — **аргумент**: то, что передали при вызове;
- `return` возвращает результат и **сразу завершает** функцию;
- функция без `return` возвращает `undefined`.

## Возвращать или печатать?

Функция, которая **возвращает** значение, полезнее той, что печатает: результат можно сравнить, сложить, передать
в другую функцию. Печатайте снаружи.

```js run
function square(x) {
  return x * x;
}
const hyp = Math.sqrt(square(3) + square(4));
console.log(hyp);
```

## Функция-проверка

Функции, которые отвечают «да/нет», называют с `is…`/`has…` и возвращают `true`/`false`. Внутри удобно
возвращаться **досрочно**, как только ответ известен:

```js run
function hasZero(n) {
  while (n > 0) {
    if (n % 10 === 0) return true;
    n = Math.floor(n / 10);
  }
  return false;
}
console.log(hasZero(1205), hasZero(777));
```

## Функции вызывают функции

Маленькие функции складываются в большие — так решения читаются как текст:

```js run
function isEven(n) {
  return n % 2 === 0;
}
function describe(n) {
  return n + (isEven(n) ? ' — чётное' : ' — нечётное');
}
console.log(describe(7));
```

## Где объявлять

Функцию, объявленную словом `function`, можно вызывать даже **выше** по тексту, чем она записана (она «поднимается»).
Но удобнее сначала объявить все функции, а внизу писать основную программу.
