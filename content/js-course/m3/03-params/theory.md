# Параметры: по умолчанию и rest

## Значения по умолчанию

Если аргумент не передали, параметр равен `undefined`. Значение по умолчанию задают прямо в объявлении:

```js run
function label(text, color = 'серый') {
  return text + ' (' + color + ')';
}
console.log(label('Кнопка'));
console.log(label('Ссылка', 'синий'));
```

Значение по умолчанию подставляется только для `undefined` — `0`, `''` и `null` считаются переданными.

## Сколько угодно аргументов: rest

`...имя` в **конце** списка параметров собирает все оставшиеся аргументы в массив:

```js run
function logAll(title, ...items) {
  console.log(title + ':', items.length, 'шт.');
  for (const item of items) console.log(' -', item);
}
logAll('Покупки', 'хлеб', 'сыр');
```

## Spread при вызове

Обратная операция: `...массив` при вызове раскладывает массив в отдельные аргументы.

```js run
const nums = [4, 9, 2];
console.log(Math.min(...nums));
```

## Ввод «числа через пробел»

Частый формат ввода — числа одной строкой. Строку режут на части методом `split(' ')`, а каждую часть превращают в
число (подробно про массивы — в модуле 4):

```js run input=3 8 1
const parts = input().split(' ');
const values = [];
for (const p of parts) values.push(Number(p));
console.log(values);
```

## arguments

В старом коде внутри функции встречается `arguments` — «псевдомассив» всех аргументов. В новом коде вместо него
пишут rest-параметр: он настоящий массив и виден в объявлении.
