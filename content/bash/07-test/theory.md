# Тема 7. Условия и команда test

Команда `test` проверяет условие и возвращает код `0` (истина) или `1` (ложь), ничего не выводя. Вместо `test`
чаще пишут `[ … ]` — это та же команда. **Пробелы внутри скобок обязательны.**

```bash run
[ 5 -gt 3 ] && echo "5 больше 3"
```

## Проверки файлов

| Ключ | Истина, если |
|---|---|
| `-e` | путь существует |
| `-f` | обычный файл |
| `-d` | каталог |
| `-s` | файл не пустой |
| `-r`, `-w` | доступен для чтения / записи |

## Сравнение чисел

`-eq` (равно), `-ne` (не равно), `-gt` (больше), `-lt` (меньше), `-ge` (≥), `-le` (≤). **Только целые числа.**

## Сравнение строк

| Проверка | Истина, если |
|---|---|
| `-z "$s"` | строка пуста |
| `-n "$s"` | строка не пуста |
| `"$a" = "$b"` | строки равны |
| `"$a" != "$b"` | строки различны |

Символ `!` меняет результат на противоположный: `[ ! -d backup ]` — «каталога backup нет».

## Расширенная версия `[[ … ]]`

В bash есть `[[ … ]]`: поддерживает шаблоны с `==`, регулярные выражения `=~` и `&&`/`||` внутри.

```bash run
name=Alice
[[ $name == A* ]] && echo "Имя начинается с A"
```

## Частые ошибки

- `[$a=$b]` без пробелов — ошибка: `[` должна быть отдельным словом.
- Для чисел используйте `-eq`, для строк `=`. `[ "05" = "5" ]` ложно, а `[ 05 -eq 5 ]` истинно.
- `-eq` работает только с целыми: `[ 5 -eq 5.0 ]` даст ошибку.
