# Тема 6. Математические операции

Bash считает только **целые** числа. Основной способ — `$(( ))`.

## Арифметика `$(( ))`

Операторы: `+`, `-`, `*`, `/` (целочисленное деление), `%` (остаток).

```bash run
a=9
b=4
echo "Сумма: $((a + b))"
echo "Частное: $((a / b))"
echo "Остаток: $((a % b))"
```

Внутри `$(( ))` переменные можно писать без `$`. Результат можно сохранить: `r=$((5 * 3))`.

## expr и let

```bash
expr 5 + 2        # 7 — операнды и оператор через пробелы
expr 5 \* 2       # 10 — звёздочку экранируют
let "r = 5 + 2"   # то же через let
```

## Инкремент и сравнение

```bash run
count=0
((count++))
((count++))
echo "count = $count"
```

## Дробные числа

Ни `$(( ))`, ни `expr`, ни `let` не работают с дробями — для них есть `bc`:

```bash
echo "scale=2; 10 / 3" | bc    # 3.33
```

## Частые ошибки

- `echo $a + $b` выведет текст `9 + 4`: арифметика работает только внутри `$(( ))`.
- В `expr` пробелы обязательны: `expr 5+2` вернёт строку `5+2`.
- `$((9 / 4))` равно `2` — дробная часть отбрасывается.
