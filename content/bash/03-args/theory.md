# Тема 3. Аргументы скрипта

Аргументы делают скрипт универсальным: один и тот же файл работает с разными данными. Аргументы, переданные
при запуске (`bash script.sh Том 39`), доступны по номеру.

## Позиционные параметры

| Параметр | Значение |
|---|---|
| `$0` | имя скрипта |
| `$1`, `$2`, … `$9` | первый, второй … девятый аргумент |
| `${10}` | десятый и дальше — только в фигурных скобках |

```bash run args=Том|39
echo "Скрипт: $0"
echo "Имя: $1, возраст: $2"
```

## Служебные параметры

| Параметр | Что возвращает |
|---|---|
| `$#` | количество аргументов |
| `$@` | все аргументы как отдельные слова |
| `$*` | все аргументы одной строкой |

```bash run args=яблоко|груша|слива
echo "Сколько: $#"
for fruit in "$@"; do
    echo "- $fruit"
done
```

**Всегда пишите `"$@"` в кавычках** — иначе аргументы с пробелами разобьются на части.

## Значение по умолчанию и shift

```bash run
who="${1:-гость}"
echo "Здравствуйте, $who"
```

`shift` сдвигает список на одну позицию: `$2` становится `$1`, `$#` уменьшается на 1.

```bash run args=первый|второй|третий
shift
echo "Теперь первый: $1"
```

## Частые ошибки

- `$10` читается как `$1` и символ `0`. Десятый аргумент — только `${10}`.
- Без кавычек `for x in $@` аргумент с пробелом разобьётся на несколько.
