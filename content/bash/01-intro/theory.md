# Тема 1. Введение в bash-скрипты

Bash-скрипт — это обычный текстовый файл со списком команд. Интерпретатор выполняет их сверху вниз.

## Первый скрипт

В начало файла принято ставить **shebang** — строку, которая говорит, каким интерпретатором запускать файл:

```bash run
#!/bin/bash
# строки, начинающиеся с #, — это комментарии
echo "Привет, мир!"
```

- `#!/bin/bash` пишут первой строкой, без пробела перед `#`.
- `echo` печатает текст. Кавычки вокруг текста в вывод не попадают.

## Как запускают скрипт

| Способ | Команда | Что происходит |
|---|---|---|
| Сделать исполняемым и запустить | `chmod +x hello` затем `./hello` | запуск в новом процессе shell |
| Передать интерпретатору | `bash hello` | запуск в новом процессе, `chmod` не нужен |
| Выполнить в текущем shell | `. hello` или `source hello` | переменные и `exit` влияют на текущую сессию |

Разница важна: при `source` команда `exit` закроет **ваш терминал**, а переменные скрипта останутся в сессии.

## Код возврата и exit

Каждая команда сообщает результат числом: `0` — успех, любое другое — ошибка. Этот код задаёт `exit`:

```bash run
echo "Работаю"
exit 0
```

Код последней команды хранится в переменной `$?`:

```bash run
echo "Код: $?"
```

В самом начале скрипта `$?` равен `0`. После успешной команды — `0`, после неуспешной — не `0`.

## Два потока вывода

У программы два потока: обычный (stdout) и поток ошибок (stderr). Сообщения об ошибках направляют в stderr значком `>&2`:

```bash run
echo "Это обычный вывод"
echo "Это сообщение об ошибке" >&2
```

## Управляющие символы

`echo -e` включает перевод строки `\n` и табуляцию `\t` внутри строки:

```bash run
echo -e "Первая строка\nВторая строка"
```

## Частые ошибки

- Пробел перед `#!/bin/bash` — shebang перестаёт работать.
- Забыли `chmod +x` — при `./hello` будет `Permission denied`.
- `exit` в скрипте, запущенном через `source`, закроет терминал.
