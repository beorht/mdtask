# Задача 10. Форма регистрации с проверкой

## Средний уровень

Сделайте форму `<form>` с полями: **Имя**, **Email**, **Пароль**, **Повтор пароля**, флажок **«Согласен с правилами»** и кнопкой **«Зарегистрироваться»**.

При отправке (событие `submit`, обязательно `event.preventDefault()`) проверьте:

| Поле | Правило | Текст ошибки |
|---|---|---|
| Имя | не пустое, не короче 2 символов | «Введите имя (минимум 2 символа)» |
| Email | есть `@` и точка после неё | «Неверный email» |
| Пароль | не короче 8 символов, есть хотя бы одна цифра | «Пароль: минимум 8 символов и хотя бы одна цифра» |
| Повтор | совпадает с паролем | «Пароли не совпадают» |
| Флажок | отмечен (`checkbox.checked`) | «Нужно согласие с правилами» |

- Ошибка выводится **под своим полем** (заранее подготовленный `<small class="error">`), поле с ошибкой получает класс `invalid` (красная рамка).
- Когда пользователь исправляет поле (событие `input`), его ошибка исчезает.
- Если всё верно — форма скрывается, а вместо неё появляется сообщение «Добро пожаловать, Имя!» (имя — через `textContent`).

Встроенную проверку браузера (`required`, `type="email"`) **не** используйте — вся проверка в JS (можно добавить атрибут `novalidate` форме).

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
