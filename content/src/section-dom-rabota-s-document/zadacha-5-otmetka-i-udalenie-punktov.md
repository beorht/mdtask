# Задача 5. Отметка и удаление пунктов

## Средний уровень

Доработайте список покупок из задачи 4 (новая страница, код можно взять из своей задачи 4).

- У каждого пункта есть кнопка **«✕»** — удаляет этот пункт.
- Клик по тексту пункта отмечает его как купленный — класс `done` (зачёркнутый серый текст), повторный клик снимает отметку.
- Над списком: «Всего: 5, куплено: 2».
- Кнопка **«Удалить купленные»** удаляет все отмеченные пункты.

**Обязательно:** один обработчик `click` на `<ul>` (делегирование, `event.target.closest(...)`), а не отдельный обработчик на каждый пункт — пункты добавляются позже, чем запускается скрипт.

**Пример:** Хлеб, Молоко, Сыр → клик по «Молоко» → «Всего: 3, куплено: 1» → «✕» у «Сыр» → «Всего: 2, куплено: 1».

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
