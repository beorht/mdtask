# Задача 1. Приветствие

## Лёгкий уровень

Сделайте страницу с пустым заголовком `<h1 id="greeting">` и абзацем `<p id="date">`. При загрузке страницы скрипт должен:

1. записать в заголовок приветствие по времени суток и имени из переменной `const name = "Ваше имя"`:
   - 5:00–11:59 — «Доброе утро, …!»
   - 12:00–17:59 — «Добрый день, …!»
   - 18:00–22:59 — «Добрый вечер, …!»
   - иначе — «Доброй ночи, …!»
2. записать в абзац сегодняшнюю дату в виде «Сегодня 13.10.2026, вторник».

Час берётся из `new Date().getHours()`, день недели — из `getDay()` и массива названий дней.

**Пример:** в 14:30 для имени «Аня» → заголовок «Добрый день, Аня!», ниже «Сегодня 13.10.2026, вторник».

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
