# Задача 9. Сортировка таблицы

## Средний уровень

Добавьте к таблице студентов (задачи 7–8) сортировку по клику на заголовок столбца.

- Заголовки «Имя», «Группа», «Балл» кликабельны; столбец, по которому сортировать, задаётся data-атрибутом: `<th data-sort="name">`.
- Первый клик — по возрастанию, повторный клик по тому же столбцу — по убыванию. Клик по другому столбцу — снова по возрастанию.
- В заголовке текущего столбца показывается стрелка ▲ или ▼, у остальных стрелки нет.
- Имена сравнивайте через `localeCompare` (правильный порядок русских букв), баллы — как числа.
- Сортировка работает вместе с поиском из задачи 8 (если вы делали задачу 8).

Обработчик — один на `<thead>` (делегирование), направление сортировки храните в переменных JS.

**Пример:** клик «Балл» → 58, 67, 75, 81, 92 и «Балл ▲»; ещё клик → 92, 81, 75, 67, 58 и «Балл ▼».

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
