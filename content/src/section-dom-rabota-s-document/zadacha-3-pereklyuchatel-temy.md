# Задача 3. Переключатель темы

## Лёгкий уровень

Сделайте страницу с текстом и кнопкой **«Тёмная тема»**.

- По клику на `<body>` переключается класс `dark` (`classList.toggle`). В CSS для `body.dark` задайте тёмный фон и светлый текст.
- Текст кнопки меняется: в светлой теме — «Тёмная тема», в тёмной — «Светлая тема».
- Выбранная тема сохраняется в `localStorage` и восстанавливается при перезагрузке страницы.

**Пример:** открыть страницу → светлая тема → клик → тёмная, кнопка «Светлая тема» → обновить страницу (F5) → тема осталась тёмной.

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
