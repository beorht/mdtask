# Задача 8. Поиск по таблице

## Средний уровень

Возьмите таблицу студентов из задачи 7 и добавьте над ней поле **«Поиск по имени»** и выпадающий список групп (`<select>`: «Все группы», WEB-21, WEB-22).

- При вводе в поле (событие `input`) в таблице остаются только студенты, в имени которых есть введённый текст — без учёта регистра (`toLowerCase()`).
- Выбор группы в `<select>` (событие `change`) дополнительно фильтрует по группе; оба фильтра работают вместе.
- Если никто не подходит — вместо строк показывается одна строка «Ничего не найдено».
- Под таблицей: «Показано 2 из 8».
- Итоговая строка (средний балл) считается только по показанным студентам.

Не перезагружайте страницу и не трогайте исходный массив: фильтруйте копию (`filter`) и перерисовывайте таблицу функцией `renderTable`.

**Пример:** ввести «ка» → Лола Каримова (и другие, в чьём имени есть «ка»); выбрать WEB-22 + пустой поиск → только студенты WEB-22.

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
