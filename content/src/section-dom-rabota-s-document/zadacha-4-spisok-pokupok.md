# Задача 4. Список покупок

## Лёгкий уровень

На странице поле ввода, кнопка **«Добавить»** и пустой список `<ul>`.

- По клику на «Добавить» (и по нажатию **Enter** в поле) текст из поля добавляется в конец списка новым `<li>` (`createElement` + `append`), поле очищается, курсор возвращается в поле (`input.focus()`).
- Пустую строку или строку из одних пробелов добавлять нельзя (`trim()`).
- Над списком показывается количество покупок: «Покупок: 3». Если список пуст — «Список пуст».

**Пример:** ввести «Хлеб» → «Добавить» → в списке «Хлеб», над ним «Покупок: 1»; ввести «   » → ничего не добавляется.

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
