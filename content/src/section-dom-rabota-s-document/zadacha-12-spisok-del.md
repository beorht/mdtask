# Задача 12. Список дел

## Сложный уровень

Соберите всё вместе: мини-приложение **«Список дел»** (todo).

1. **Добавление:** поле + кнопка «Добавить» (и Enter). Пустые задачи не добавляются.
2. **Отметка:** у каждой задачи флажок «выполнено» — выполненная задача зачёркнута.
3. **Удаление:** кнопка «✕» у каждой задачи.
4. **Редактирование:** двойной клик (`dblclick`) по тексту задачи превращает его в поле ввода; Enter сохраняет, Escape отменяет.
5. **Фильтр:** кнопки «Все», «Активные», «Выполненные» (активная кнопка подсвечена).
6. **Счётчик:** «Осталось задач: 3» и кнопка «Очистить выполненные».
7. **Сохранение:** список хранится в `localStorage` и восстанавливается после перезагрузки страницы.

**Требования к коду:**

- данные — массив объектов `{ id, text, done }`; страница перерисовывается из массива одной функцией `render()` после каждого изменения;
- функции `save()` / `load()` для `localStorage` (с `JSON.stringify` / `JSON.parse`); если сохранённых данных нет — пустой список, а не ошибка;
- события пунктов — через делегирование на список;
- текст задач — только через `textContent` (проверьте: задача с текстом `<b>жирный</b>` должна показаться как есть, с угловыми скобками).

**Пример:** добавить 3 задачи → отметить одну → «Осталось задач: 2» → фильтр «Выполненные» → видна одна → F5 → всё на месте.

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
