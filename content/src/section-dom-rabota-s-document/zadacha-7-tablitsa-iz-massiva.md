# Задача 7. Таблица из массива

## Средний уровень

В `script.js` задан массив объектов:

```js
const students = [
  { name: "Аня Ким", group: "WEB-21", score: 92 },
  { name: "Тимур Рахимов", group: "WEB-22", score: 75 },
  { name: "Лола Каримова", group: "WEB-21", score: 58 },
  { name: "Денис Орлов", group: "WEB-22", score: 81 },
  { name: "Вали Юсупов", group: "WEB-21", score: 67 },
];
```

В HTML есть только пустая таблица с заголовком (`<thead>`: №, Имя, Группа, Балл) и пустым `<tbody>`. Скрипт должен:

1. построить строки таблицы из массива (`createElement("tr")` / `("td")`), номер — по порядку;
2. ячейке балла добавить класс: `high` при 85 и выше, `low` ниже 60 (раскрасьте в CSS);
3. добавить в `<tfoot>` итоговую строку: «Средний балл: 74.6» (с одним знаком после запятой, `toFixed(1)`) и «Лучший: Аня Ким».

Таблица должна строиться функцией `renderTable(list)`, которая принимает массив, — она пригодится в задачах 8 и 9. Добавьте в массив ещё 3 студента — таблица и итог должны пересчитаться без правки HTML.

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
