# Задача 11. Вкладки и аккордеон

## Средний уровень

Сделайте страницу «О курсе» с двумя компонентами.

**Вкладки (табы).** Три кнопки — «Описание», «Программа», «Преподаватели» — и три блока содержимого. Видна только одна вкладка; у активной кнопки класс `active`. Кнопка связана со своим блоком через data-атрибут: `<button data-tab="program">` ↔ `<div id="program">`. Один обработчик на контейнер с кнопками (делегирование).

**Аккордеон «Частые вопросы».** Не меньше 4 вопросов; клик по вопросу раскрывает ответ под ним, повторный — скрывает. Одновременно открыт только один ответ: при открытии нового предыдущий закрывается. У открытого вопроса значок «−», у закрытых — «+».

Без `<details>`/`<summary>` — переключение должно быть сделано на JavaScript через классы или `hidden`.

**Пример:** клик «Программа» → видна только «Программа», кнопка подсвечена; в FAQ клик по вопросу 2 → открыт ответ 2; клик по вопросу 3 → ответ 2 закрылся, открыт 3.

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
