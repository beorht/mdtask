# Задача 2. Счётчик кликов

## Лёгкий уровень

На странице число (сначала `0`) и три кнопки: **«−»**, **«+»** и **«Сброс»**.

- «+» увеличивает число на 1, «−» уменьшает на 1, «Сброс» возвращает к 0.
- Число не может стать меньше 0: когда оно равно 0, кнопка «−» неактивна (`button.disabled = true`).
- Когда число достигает 10 и больше, оно подсвечивается — добавьте ему класс `big` (например, зелёный цвет в CSS); при уменьшении ниже 10 класс убирается.

Значение храните в переменной JS, а на страницу выводите через `textContent`.

**Пример:** 0 («−» неактивна) → «+» ×3 → 3 → «−» → 2 → «Сброс» → 0.

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
