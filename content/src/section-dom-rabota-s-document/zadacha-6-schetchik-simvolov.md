# Задача 6. Счётчик символов

## Лёгкий уровень

Сделайте поле для отзыва `<textarea>` и под ним строку «Символов: 0 / 200».

- При каждом изменении текста (событие `input`) счётчик обновляется.
- Если введено больше 200 символов — счётчик становится красным (класс `over`), появляется надпись «Слишком длинный отзыв на N символов», а кнопка **«Отправить»** неактивна.
- Дополнительно выводите количество слов: «Слов: 12» (слова разделены пробелами, лишние пробелы не считаются).
- По клику на «Отправить» текст отзыва появляется ниже в блоке «Ваш отзыв:» (через `textContent`), поле очищается, счётчики обнуляются.

**Пример:** ввести «Отличный курс» → «Символов: 13 / 200», «Слов: 2».

---

*Тема: DOM и объект `document` (см. страницу «Теория: DOM и объект document»). Только «чистый» JavaScript — без библиотек и фреймворков (jQuery, React и т. п.). Скрипт — в отдельном файле `script.js`, подключённом с `defer`; обработчики — через `addEventListener`, без атрибутов `onclick` в HTML. Текст, введённый пользователем, выводите через `textContent`. Сдайте архив (`.zip` или `.rar`) с файлами `index.html`, `script.js` (и `style.css`, если он есть).*
