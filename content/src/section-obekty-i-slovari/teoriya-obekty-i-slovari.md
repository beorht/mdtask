# Теория: объекты и словари

Тема общая для всех групп. **JS-группы** работают с *объектами* (`object`), **Python-группы** — со *словарями* (`dict`). Идея одна и та же: хранить данные в виде пар «ключ → значение» и быстро находить значение по ключу (в отличие от массива/списка, где ищут по номеру позиции).

## 1. Зачем нужен объект/словарь

Массив/список хорош, когда важен порядок и данные однородны. Но если нужно быстро находить значение по «имени» (например, цену товара по названию, телефон по имени контакта), перебирать весь массив на каждый запрос — медленно и неудобно. Объект/словарь даёт прямой доступ по ключу.

## 2. Создание

**JavaScript (объект):**
```js
const student = { name: "Аня", score: 90 };
const empty = {};
```

**Python (словарь):**
```python
student = {"name": "Аня", "score": 90}
empty = {}
```

## 3. Доступ, добавление, изменение, удаление

| Действие | JavaScript | Python |
|---|---|---|
| Чтение по ключу | `student["name"]` или `student.name` | `student["name"]` |
| Чтение с запасным значением | `student.age ?? "нет данных"` | `student.get("age", "нет данных")` |
| Проверка наличия ключа | `"name" in student` | `"name" in student` |
| Добавление / изменение | `student.age = 20` | `student["age"] = 20` |
| Удаление ключа | `delete student.age` | `del student["age"]` |

Важно: обращение к несуществующему ключу в JS вернёт `undefined` (без ошибки), а в Python — вызовет `KeyError`, если не использовать `.get()`.

## 4. Перебор всех пар «ключ — значение»

**JavaScript:**
```js
for (const key in student) {
  console.log(key, student[key]);
}
// или
for (const [key, value] of Object.entries(student)) {
  console.log(key, value);
}

Object.keys(student);   // ["name", "score"]
Object.values(student); // ["Аня", 90]
```

**Python:**
```python
for key in student:
    print(key, student[key])

for key, value in student.items():
    print(key, value)

student.keys()    # dict_keys(["name", "score"])
student.values()  # dict_values(["Аня", 90])
```

## 5. Объект/словарь как счётчик

Частая задача — подсчитать, сколько раз встречается каждый элемент массива/списка. Приём: если ключа ещё нет — завести его с 0 (или сразу с 1), иначе — увеличить значение на 1.

**JavaScript:**
```js
const counts = {};
for (const word of words) {
  counts[word] = (counts[word] || 0) + 1;
}
```

**Python:**
```python
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
```

## 6. Вложенные структуры

Значением может быть не только число/строка, но и другой объект/словарь или массив/список — так получаются вложенные («древовидные») структуры данных: список товаров с характеристиками, каталог папок и файлов, группы со списком студентов внутри.

```js
const catalog = { a: { b: { c: 5 }, d: 7 } };
console.log(catalog.a.b.c); // 5
```
```python
catalog = {"a": {"b": {"c": 5}, "d": 7}}
print(catalog["a"]["b"]["c"])  # 5
```

## 7. На что обратить внимание при решении задач ниже

- Ключи объекта/словаря по сути уникальны: если записать значение по уже существующему ключу — старое значение перезапишется, а не добавится второе.
- Порядок обхода `for...in` / обычного перебора словаря — это порядок добавления ключей (в современных JS и Python 3.7+), но алгоритм решения задачи не должен на него полагаться, если явно не требуется.
- Группировка (задачи «по категориям», «по группам») — это всегда один и тот же приём: если ключа (категории) ещё нет — создать для него пустой список, затем добавить туда элемент.
- Разрешено использовать только то, что уже проходили: переменные, условия, циклы, массивы/списки, объекты/словари и операторы сравнения. Готовые методы, которые решают всю задачу за одну строку без объектов/словарей (например, библиотеки подсчёта частот), использовать нельзя — если это не оговорено отдельно в конкретной задаче.

## 8. Формат вывода

Условия задач описывают *что* нужно вывести и в каком виде (например, «элемент — N раз(а)»), но не привязаны к конкретному языку — оформляйте вывод любым удобным способом (`console.log` в JS, `print` в Python), сохраняя смысл и порядок информации из примера.
