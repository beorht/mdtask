# Задача 12. Путь во вложенной структуре

Дан вложенный объект/словарь каталога, где значениями могут быть другие объекты/словари либо числа (например, размер файла). Дан путь вида "папка/подпапка/файл". «Спуститесь» по пути и выведите итоговое значение. Если на любом шаге ключа нет — выведите «не найдено». Дополнительно посчитайте общее количество листьев (конечных значений) во всём каталоге.

**Пример:** `{ a: { b: { c: 5 }, d: 7 } }`, путь "a/b/c" → 5; путь "a/x" → не найдено; листьев: c и d → 2

---

*База: переменные, условия, циклы, списки/массивы, операторы сравнения — плюс объекты/словари (см. страницу «Теория: объекты и словари»). Разрешены циклы, условия, списки/массивы, объекты/словари. Запрещены сторонние готовые структуры/методы, решающие задачу одной строкой без понимания темы. Данные задаются прямо в коде — ввод с клавиатуры не требуется. JS-группы решают на JavaScript с объектами, Python-группы — на Python со словарями.*
