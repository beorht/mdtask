# Задача 10. Старые и новые цены

Даны два объекта/словаря: старые цены («товар → цена») и новые цены. Для каждого товара, который есть в обоих словарях, выведите разницу (новая минус старая) со знаком. Отдельно выведите товары, чья цена не изменилась, и товары, у которых новой цены нет.

**Пример:** старые `{хлеб:40, молоко:70, сыр:350}`, новые `{хлеб:45, молоко:70, масло:200}` → хлеб: +5, молоко: 0 (не изменилась), цена сыра убрана из прайса

---

*База: переменные, условия, циклы, списки/массивы, операторы сравнения — плюс объекты/словари (см. страницу «Теория: объекты и словари»). Разрешены циклы, условия, списки/массивы, объекты/словари. Запрещены сторонние готовые структуры/методы, решающие задачу одной строкой без понимания темы. Данные задаются прямо в коде — ввод с клавиатуры не требуется. JS-группы решают на JavaScript с объектами, Python-группы — на Python со словарями.*
