# Задача 13. Самая длинная цепочка

Дан объект/словарь маршрута «пункт → следующий пункт» (например, `{"А":"Б", "Б":"В", "В":"Д", "Г":"А"}`). Найдите самую длинную цепочку переходов из каждого возможного старта. Цепочка заканчивается, когда следующий пункт отсутствует среди ключей или уже был в цепочке (зацикливание). Выведите длину самой длинной цепочки и саму цепочку. Дополнительно выведите, есть ли в маршруте зацикливание (цепочка, пришедшая в уже посещённый пункт).

**Пример:** `{"А":"Б", "Б":"В", "В":"Г", "Г":"Е"}` → самая длинная цепочка А → Б → В → Г → Е, длина 5, зацикливаний нет

---

*База: переменные, условия, циклы, списки/массивы, операторы сравнения — плюс объекты/словари (см. страницу «Теория: объекты и словари»). Разрешены циклы, условия, списки/массивы, объекты/словари. Запрещены сторонние готовые структуры/методы, решающие задачу одной строкой без понимания темы. Данные задаются прямо в коде — ввод с клавиатуры не требуется. JS-группы решают на JavaScript с объектами, Python-группы — на Python со словарями.*
