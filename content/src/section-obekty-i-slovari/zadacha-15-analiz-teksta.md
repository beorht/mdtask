# Задача 15. Анализ текста

Дана строка текста из нескольких предложений. Приведите текст к нижнему регистру, разбейте на слова по пробелам, отбрасывая знаки препинания. С помощью объекта/словаря подсчитайте частоту каждого слова. Выведите: количество уникальных слов, самое частое слово (при равенстве — которое встретилось раньше), топ-5 самых частых слов с числом вхождений (по убыванию частоты), среднюю длину слова (среднее арифметическое длин, округлённое до 2 знаков).

**Пример:** "Кот и пёс. Кот спит, а пёс гуляет." → слова по частоте: кот — 2, пёс — 2, и — 1, спит — 1, а — 1, гуляет — 1; уникальных 6; средняя длина слова ≈ 3.0

---

*База: переменные, условия, циклы, списки/массивы, операторы сравнения — плюс объекты/словари (см. страницу «Теория: объекты и словари»). Разрешены циклы, условия, списки/массивы, объекты/словари. Запрещены сторонние готовые структуры/методы, решающие задачу одной строкой без понимания темы. Данные задаются прямо в коде — ввод с клавиатуры не требуется. JS-группы решают на JavaScript с объектами, Python-группы — на Python со словарями.*
