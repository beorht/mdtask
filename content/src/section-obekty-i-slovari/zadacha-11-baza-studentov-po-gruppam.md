# Задача 11. База студентов по группам

## Сложный уровень

Дан массив/список записей «имя, группа, балл». Постройте объект/словарь «группа → список студентов (имя и балл)». Для каждой группы выведите: состав группы, средний балл группы и лучшего студента группы. Учитывайте, что групп может быть несколько.

**Пример:** `{name:"Аня", group:"ИС-21", score:90}`, `{name:"Боря", group:"ИС-21", score:75}`, `{name:"Витя", group:"ПКС-22", score:80}` → группа ИС-21: Аня(90), Боря(75), среднее 82.5, лучший — Аня; группа ПКС-22: Витя(80), среднее 80.0, лучший — Витя

---

*База: переменные, условия, циклы, списки/массивы, операторы сравнения — плюс объекты/словари (см. страницу «Теория: объекты и словари»). Разрешены циклы, условия, списки/массивы, объекты/словари. Запрещены сторонние готовые структуры/методы, решающие задачу одной строкой без понимания темы. Данные задаются прямо в коде — ввод с клавиатуры не требуется. JS-группы решают на JavaScript с объектами, Python-группы — на Python со словарями.*
