# Задача 9. Товары по категориям

Дан массив/список товаров: у каждого товара название, категория и цена. Сгруппируйте товары в объект/словарь «категория → список названий». Для каждой категории выведите: список товаров и суммарную стоимость товаров этой категории.

**Пример:** `{name:"яблоко", category:"фрукты", price:50}`, `{name:"морковь", category:"овощи", price:30}`, `{name:"банан", category:"фрукты", price:40}` → фрукты: яблоко, банан — сумма 90, овощи: морковь — сумма 30

---

*База: переменные, условия, циклы, списки/массивы, операторы сравнения — плюс объекты/словари (см. страницу «Теория: объекты и словари»). Разрешены циклы, условия, списки/массивы, объекты/словари. Запрещены сторонние готовые структуры/методы, решающие задачу одной строкой без понимания темы. Данные задаются прямо в коде — ввод с клавиатуры не требуется. JS-группы решают на JavaScript с объектами, Python-группы — на Python со словарями.*
