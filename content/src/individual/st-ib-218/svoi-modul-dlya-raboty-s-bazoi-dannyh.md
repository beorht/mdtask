# Свой модуль для работы с базой данных на Python

Напишите модуль `mydb.py` — небольшую «обёртку» над стандартным модулем `sqlite3`, чтобы работать с базой, не составляя SQL вручную при каждом действии. Затем покажите работу модуля в программе `main.py`.

Код пишется **прямо на этой странице** — в редакторе Python ниже. Кнопка «Запустить» выполняет `main.py` в браузере; при каждом запуске база создаётся заново. Код сохраняется автоматически, а когда всё готово — нажмите «Сдать на проверку».

## Что должно быть в модуле `mydb.py`

Класс `Database`:

| Метод | Что делает |
|---|---|
| `Database(path)` | открывает (или создаёт) файл базы SQLite |
| `create_table(name, columns)` | создаёт таблицу, если её нет; `columns` — словарь, например `{"id": "INTEGER PRIMARY KEY", "name": "TEXT NOT NULL"}` |
| `insert(table, data)` | добавляет строку из словаря `{"name": "Ali", "age": 19}`, возвращает `id` новой строки |
| `select(table, where=None)` | возвращает список словарей; `where` — словарь условий «равно», например `{"age": 19}`; без `where` — все строки |
| `update(table, data, where)` | изменяет строки, подходящие под `where`, возвращает число изменённых строк |
| `delete(table, where)` | удаляет строки, подходящие под `where`, возвращает число удалённых строк |
| `close()` | закрывает соединение |

## Обязательные требования

1. **Только стандартный модуль `sqlite3`** — сторонние библиотеки (SQLAlchemy, peewee и т. п.) запрещены.
2. **Защита от SQL-инъекций.** Значения передаются в запрос только через параметры `?`, а не через f-строки или `+`. Имена таблиц и столбцов параметрами передать нельзя — проверяйте их: только буквы, цифры и `_`, иначе модуль выбрасывает `ValueError`.
3. **`update` и `delete` без условия запрещены**: пустой или отсутствующий `where` → `ValueError` (чтобы случайно не стереть или не испортить всю таблицу).
4. **Изменения сохраняются** — после `insert`, `update`, `delete` выполняется `commit`.
5. **Работа через `with`**: `with Database("shop.db") as db: ...` — по выходу из блока соединение закрывается (методы `__enter__` и `__exit__`).

## Программа `main.py`

Используя **только ваш модуль** (без прямых вызовов `sqlite3`):

1. создайте таблицу `students` (id, имя, группа, возраст);
2. добавьте не меньше 5 студентов;
3. выведите всех студентов и отдельно — студентов одной группы;
4. измените возраст одного студента и удалите одного студента, выводя, сколько строк затронуто;
5. покажите, что защита работает: попытка `db.select("students; DROP TABLE students")` и попытка `delete` без условия должны выдать понятное сообщение об ошибке (перехватите `ValueError`), а таблица — остаться на месте.
