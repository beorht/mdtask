# Песочница анимаций

Отдельная страница для просмотра анимаций и назначения их событиям. Основной сайт (`index.js`, `src/`, `public/`) этой папкой не пользуется и не меняется.

## Запуск

```bash
node gif-lab/server.js           # http://127.0.0.1:42530
```

Порт: `GIF_LAB_PORT=42531 node gif-lab/server.js`. Сервер слушает только `127.0.0.1`.

## Структура

```
gif-lab/
  library/                 все анимации
    simba-jump.gif         гифка: любой .gif / .webp / .png / .jpg
    spider-booo/           HTML-анимация: папка с index.html и своими картинками
  assignments.json         какие анимации показываются для какого события
  events.json              список событий и их описания
```

## Как добавить анимацию

- **Гифка:** положите файл в `library/`. Имя без расширения — её id (`simba-jump.gif` → `simba-jump`).
- **HTML-анимация:** положите папку с `index.html` в `library/`. Картинки и скрипты держите внутри неё.

Обновите страницу — библиотека читается с диска на каждый запрос, перезапуск не нужен.

## Как назначить анимацию событию

1. Нажмите **«Назначения»** в шапке.
2. Для каждой анимации отметьте события, в которых она должна показываться.
3. Нажмите **«Сохранить»**. Назначения пишутся в `assignments.json`.

Одна анимация может быть у нескольких событий. У события может быть несколько анимаций: при показе выбирается случайная из назначенных. Событие без назначений показывает подсказку «анимации не назначены».

## События

Сейчас три события: «Проверка: сделано правильно», «Проверка: сделано неправильно» (только для заданий с автопроверкой) и «Случайное событие». Список и описания — в `events.json`. У каждого события:

| Поле | Значение |
|---|---|
| `id` | id события (ключ в `assignments.json`) |
| `title` | название в песочнице |
| `group` | раздел на странице |
| `when` | когда событие происходит |
| `where` | где на сайте его подключать |
| `random` | `true` — участвует в случайном режиме (появляется в случайный момент) |

## Случайный режим

Флажок «Случайный режим» через случайные промежутки (8–20 с) показывает анимацию из событий с `random: true` и назначениями. Сейчас это «Случайное событие», где назначен `spider-booo`. В режиме «Назначения» автопоказ не перебивает панель.

## Для будущей интеграции с сайтом

`window.GifLab.pick(eventId)` (в `app.js`) возвращает URL случайной назначенной анимации события или `null`. Когда подключим к сайту, понадобятся файлы из `library/` и вызов выбора в местах, где происходит событие.
