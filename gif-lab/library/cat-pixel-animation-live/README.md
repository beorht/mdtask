# Кошка: кадры, клипы и действия

Поведение кошки задаётся файлами, а не кодом.

```
cat-pixel-animation-live/
  source/_.jpeg          исходный лист спрайтов (4 × 8 кадров)
  source/extract.py      нарезка листа по группам (запуск: python3 source/extract.py)
  frames/<группа>/       кадры: sit, wash, walk, lie, sleep
  clips.json             клипы: группа кадров, скорость, повтор
  actions.json           действия: какие клипы и в каком порядке, вес, время
  index.html             проигрыватель (его не нужно менять ради нового поведения)
```

## Группы и клипы (`clips.json`)

Кадр — путь `группа/rСТРОКАcКОЛОНКА` без `.png`, например `sit/r1c1`. Клип — именованная последовательность кадров одной группы:

| Поле | Значение |
|---|---|
| `group` | группа, для удобства |
| `frames` | список кадров, по порядку |
| `fps` | кадров в секунду |
| `loop` | `true` — повторяется, пока действие его держит; `false` — один проход |

Чтобы добавить клип, допишите его в `clips.json`, а кадры положите в группу.

## Действия (`actions.json`)

Действие — список шагов, которые выполняются по порядку:

- `{ "clip": "sit_tail", "for": [6000, 12000] }` — держать клип с повтором случайное время в диапазоне, мс;
- `{ "clip": "lie_down" }` — проиграть клип один раз;
- `{ "move": "random" }` — пройти в случайное место экрана;
- `{ "move": "exit" }` — уйти за край.

`weight` — вес случайного выбора: больше значение, чаще действие. `pass.actionCount` — сколько действий за один проход, `pass.wanderAfterAction` — шанс пройтись между действиями. Поменяли файл — при следующем проходе изменения работают, код трогать не нужно. Если в файле ошибка (нет клипа, опечатка), страница покажет её на экране.

## Управление из кода

На открытой странице (консоль браузера или скрипт):

```js
window.Cat.actions()      // список действий: id, label, weight
window.Cat.clips()        // список клипов
window.Cat.play('sleep')  // поставить действие в очередь (выполнится после текущего)
window.Cat.queue()        // что стоит в очереди
```
