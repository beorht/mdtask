# План урока: Flexbox (CSS)

Предмет **«Web-разработка: CSS»** (`/subjects/css`), темы **10 «Flexbox: контейнер»** и **11 «Flexbox: элементы и
раскладки»**. План рассчитан на **две пары** (или одну двойную): урок 1 — контейнер, урок 2 — элементы и готовые
раскладки. После каждой части — практика прямо на сайте (у студентов открываются эти темы после прочтения теории).

**Цель:** научить раскладывать элементы в ряд/колонку, выравнивать их по двум осям и собирать типовые макеты
(шапка, боковая колонка, карточки, подвал).

**К концу студент умеет:** включать `display: flex`; управлять `justify-content`, `align-items`, `gap`,
`flex-direction`, `flex-wrap`; центрировать по обеим осям; задавать `flex`, `order`, `align-self`, `margin: auto`;
собрать шапку и карточки одинаковой высоты.

**Оборудование:** проектор; у каждого — браузер и страница `/subjects/css`. Код показывайте вживую и тут же меняйте
значения — flexbox нагляднее всего «крутить» на глазах.

## Урок 1 — Flexbox: контейнер (≈ 45 мин)

### 0. Мотивация (5 мин)
Покажите задачу «поставить три кнопки в ряд и прижать одну вправо» и спросите, как бы они сделали через `float`
или `margin`. Подведите к мысли: для раскладки в ряд/колонку есть специальный инструмент — **Flexbox**.

### 1. `display: flex` — контейнер и элементы (6 мин)
Главная идея: свойство пишется у **родителя**; его дети встают в ряд.

HTML:
```html
<div class="menu">
  <div>Главная</div>
  <div>Каталог</div>
  <div>Контакты</div>
</div>
```
CSS:
```css
.menu { display: flex; }
```
Покажите: без `display: flex` блоки идут друг под другом, с ним — встают в ряд. Родитель — **flex-контейнер**,
дети — **flex-элементы**.

### 2. Две оси (4 мин)
На доске нарисуйте:
```text
        главная ось (row) →
      ┌───────┬───────┬───────┐
попер.│ эл. 1 │ эл. 2 │ эл. 3 │
ось  ↓└───────┴───────┴───────┘
```
- **главная ось** — направление ряда (`flex-direction`: `row` по умолчанию, ещё `column`, `row-reverse`,
  `column-reverse`);
- **поперечная** — перпендикулярно.

Важный приём: `justify-content` выравнивает по **главной** оси, `align-items` — по **поперечной**. Это чаще всего
путают — проговорите дважды.

### 3. `justify-content` — по главной оси (7 мин)
CSS (меняйте значение вживую):
```css
.row { display: flex; gap: 8px; }
.row { justify-content: center; }        /* flex-start | center | flex-end */
.row { justify-content: space-between; } /* крайние — у краёв */
```
HTML:
```html
<div class="row"><div>1</div><div>2</div><div>3</div></div>
```
Покажите по очереди: `flex-start`, `center`, `flex-end`, `space-between`.
Распределения:
```text
space-between:  |▇▇      ▇▇      ▇▇|
space-around:   | ▇▇    ▇▇    ▇▇  |
space-evenly:   |  ▇▇   ▇▇   ▇▇   |
```

### 4. `align-items` и центр по обеим осям (7 мин)
`align-items` — по поперечной оси: `stretch` (по умолчанию растягивает на всю высоту), `flex-start`, `center`,
`flex-end`, `baseline`. Любимая задача — центр по обеим осям:

CSS:
```css
.screen {
  display: flex;
  justify-content: center;   /* по горизонтали */
  align-items: center;       /* по вертикали */
  height: 160px;
}
```
HTML:
```html
<div class="screen"><div class="box">Ровно по центру</div></div>
```

### 5. `gap`, колонка, перенос (6 мин)
CSS:
```css
.col  { display: flex; flex-direction: column; gap: 6px; }   /* сверху вниз */
.wrap { display: flex; flex-wrap: wrap; gap: 8px; }          /* перенос на новую строку */
```
HTML:
```html
<div class="wrap">
  <div>1</div><div>2</div><div>3</div><div>4</div><div>5</div>
</div>
```
Проговорите: `gap` — промежуток между элементами (можно `row-gap`/`column-gap` отдельно); `flex-wrap: wrap`
переносит, когда не влезает; `align-content` расставляет уже **строки** при переносе.

## Урок 2 — Flexbox: элементы и раскладки (≈ 45 мин)

### 7. Повторение (3 мин)
Быстрый опрос: какое свойство по главной оси? по поперечной? чем `gap` отличается от `margin`? В теме 10
настраивали **контейнер** — теперь свойства самих **элементов**.

### 8. `flex-grow / shrink / basis` и короткая запись `flex` (9 мин)
Таблица на доске:

| Свойство | Что значит | По умолчанию |
| --- | --- | --- |
| `flex-basis` | исходный размер по главной оси | `auto` |
| `flex-grow` | долю свободного места забрать (0 — нет) | `0` |
| `flex-shrink` | можно ли сжиматься (0 — нет) | `1` |

Короткая запись `flex: grow shrink basis`. Самые нужные:
- `flex: 1` — «занять свободное место поровну» (= `1 1 0`);
- `flex: 0 0 200px` — ровно 200px, не тянется и не сжимается;
- `flex: 2` и `flex: 1` — пропорция 2 : 1.

CSS (поле тянется, кнопка — своей ширины):
```css
.search { display: flex; gap: 8px; }
.search input  { flex: 1; }   /* забирает всё свободное место */
.search button { }            /* остаётся по содержимому */
```
HTML:
```html
<form class="search">
  <input placeholder="Поиск">
  <button>Найти</button>
</form>
```
Второй показ — колонки в пропорции:
```css
.cols { display: flex; gap: 8px; }
.a, .c { flex: 1; }
.b     { flex: 2; }   /* средняя вдвое шире */
```
```html
<div class="cols"><div class="a">1</div><div class="b">2</div><div class="c">1</div></div>
```

### 9. `order`, `align-self`, `margin: auto` (8 мин)
- `order: -1` — переставить элемент визуально, не трогая HTML (меньше число — раньше);
- `align-self` — выровнять **один** элемент по поперечной оси иначе остальных;
- `margin-left: auto` — забрать всё свободное место слева: элемент и всё после него уедет вправо (классическая
  шапка «логотип … меню»).

CSS:
```css
.header { display: flex; align-items: center; gap: 12px; }
.header .push { margin-left: auto; }   /* отжать вправо */
```
HTML:
```html
<header class="header">
  <b>Кафе</b>
  <span class="push">Меню</span>
  <span>Контакты</span>
  <span>Войти</span>
</header>
```

### 10. Типовые раскладки (12 мин) — главное практическое
Покажите 3–4 готовых приёма, которые встречаются в каждом макете.

**Боковая колонка + контент**
```css
.layout { display: flex; gap: 16px; }
.layout aside { flex: 0 0 220px; }  /* фиксированная ширина */
.layout main  { flex: 1; }          /* остальное место */
```
```html
<div class="layout"><aside>Меню</aside><main>Контент</main></div>
```

**Карточки одинаковой высоты, кнопка «Купить» внизу**
```css
.cards { display: flex; gap: 10px; }
.card  { flex: 1; display: flex; flex-direction: column; }
.card button { margin-top: auto; }  /* прижать кнопку к низу */
```
```html
<div class="cards">
  <div class="card"><b>Эспрессо</b><p>Коротко.</p><button>Купить</button></div>
  <div class="card"><b>Раф</b><p>Длинное описание в три строки.</p><button>Купить</button></div>
</div>
```

**Медиа-объект (фото слева, текст справа)**
```css
.media { display: flex; gap: 12px; }
.media img { flex-shrink: 0; }   /* фото не сжимается длинным текстом */
```
```html
<div class="media"><img src="photo.jpg" width="80"><p>Длинный текст рядом с фото…</p></div>
```

**Подвал прижат к низу короткой страницы**
```css
.page   { display: flex; flex-direction: column; min-height: 100vh; }
.page main   { flex: 1; }   /* растягивает середину, подвал уходит вниз */
```

## Частые ошибки (держите под рукой)
- Путают оси: `justify-content` — **главная** ось, `align-items` — **поперечная**. При `flex-direction: column`
  они меняются местами визуально.
- Пишут flex-свойства не тому элементу: `display/justify/align/gap/wrap` — у **контейнера**; `flex/order/align-self`
  — у **элемента**.
- Ждут от `flex: 1` фиксированную ширину — это «поделить свободное место», а не «33%».
- Забывают, что по умолчанию элементы **растягиваются** по высоте (`align-items: stretch`).
- `gap` против `margin`: `gap` — промежутки только между элементами, без крайних отступов.
