## Коротко

- **Фронтенд:** Vite 8, ванильный JavaScript (ES-модули, без фреймворков), CodeMirror 6, пакет `emmet` 2.4.
- **Бэкенд:** Node.js на встроенных модулях (`node:http`, `node:fs`), без Express и без БД. Данные хранятся в JSON-файлах.
- **Две страницы:** `index.html` (тетрадь студента) и `admin.html` (панель преподавателя).
- **Тесты:** Vitest + happy-dom, 48 тестов.
- **Среда:** локальная сеть класса, HTTP, Node.js 20.19+ или 22.12+.
