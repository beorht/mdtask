# 6. Проверка ответа и защита от списывания

## Проверка (`validate(source, exercise, { handwritten })`)

Шаги идут по порядку, проверка останавливается на первой проблеме. Результат —
`{ status, title, message, extra?, handwritten? }`.

| # | Шаг | Статус | Заголовок |
| --- | --- | --- | --- |
| 1 | Пустой ввод | `mismatch` | «Пока пусто» |
| 2 | Нет ни одного `<`: в html-режиме нет тегов, в emmet-режиме сокращение не развёрнуто | `mismatch` | «Пока нет ни одного тега» / «Сокращение не развёрнуто» |
| 3 | Только в режиме `emmet`: разметка набрана руками (`findHandwrittenMarkup`) | `error` | «HTML набран вручную» + фрагмент подсвечивается |
| 4 | Ошибки разметки (`findMarkupErrors`): лишний закрывающий тег, незакрытый тег, незакрытая кавычка, оборванный тег | `error` | «Ошибка в разметке» |
| 5 | Структура: «скелет» дерева `tag(children…)` не совпадает с эталоном | `mismatch` | «Структура пока другая» + первое расхождение |
| 6 | Детали: классы, значения атрибутов, текст | `partial` | «Почти получилось» + первое расхождение, «осталось ещё: N» |
| — | Всё совпало | `success` | «Решение принято» |

**Нормализация** (`parseTree`): HTML разбирается через `<template>`. Пробельные текстовые узлы
отбрасываются, текст схлопывается, классы сортируются. Поэтому отступы, переносы и порядок
атрибутов и классов не важны. Лишние классы или атрибуты у студента ошибкой не считаются:
сравнение идёт по тому, что есть в эталоне.

**Примеры сообщений:** «Внутри `<ul>` должно быть 3 × `<li>`, сейчас 2.», «2-й элемент внутри `<nav>` должен быть `<a>`, а сейчас `<p>`.», «У `<a>` атрибут href должен быть «#», а не «»».

## Emmet (`EmmetService`)

- `expandAbbreviation(abbr, { baseIndent, withCursor })`: опции `output.indent` (2 пробела) и `output.baseIndent`. Позиция курсора — первое поле (tabstop), его отмечает маркер `\u0001`.
- Запрещено прятать HTML в текст: `/\{[^}]*[<>]/` → «В тексте {…} нельзя писать HTML-теги».
- `extractAbbreviation(line, pos, { wholeLineOnly })`: сначала проверяется, является ли **вся строка до курсора** сокращением (экстрактор Emmet рвёт длинные цепочки). Пробелы вне `{}`, `[]` и кавычек означают «не одно сокращение». Если это не так и `wholeLineOnly` не задан, используется `emmet.extract`.
- Ошибки пакета переводятся на русский: «неожиданный символ (позиция N)», «сокращение оборвалось».

## Учёт ручного ввода (`HandwrittenTracker`, расширение CodeMirror)

- `StateField` хранит интервалы `[from, to)` с текстом, набранным вручную.
- **Чистыми** считаются только транзакции с userEvent `input.complete` (развёртывание Emmet), `undo` и `redo`. Всё остальное (набор, вставка, команды) помечается как ручной ввод. Поэтому новая команда редактора не может случайно «отмыть» HTML.
- `invertedEffects` восстанавливает пометки при отмене удаления, поэтому `Ctrl+Z` не отмывает набранный HTML.
- `findHandwrittenMarkup` классифицирует символы: текст, синтаксис тега, значение атрибута. Нарушение — если в ручном интервале есть `<`, `>` или символы синтаксиса тега (имена, `=`, кавычки). Текст между тегами и значения атрибутов вводить руками можно.
- Нарушающие участки подсвечиваются волнистой красной линией (`.cm-handwritten`) до следующей правки.

## Защита от списывания

| Способ | Защита | Где |
| --- | --- | --- |
| `Ctrl+V`, меню, средняя кнопка мыши | `paste`-обработчик + `transactionFilter` отменяет `input.paste`; событие `paste` | CodeEditorPanel |
| Перетаскивание | `drop`-обработчик + фильтр `input.drop` | CodeEditorPanel |
| Автонаборщик, ИИ-помощник браузера, диктовка | Больше 2 непробельных символов за одну транзакцию `input.type` → `bulk` (IME `input.type.compose` разрешён) | `blockedInput()` |
| HTML набран руками | В режиме `emmet` решение не засчитывается | ValidationService + HandwrittenTracker |
| HTML в `{…}` | Ошибка сокращения | EmmetService |
| Дублирование и перенос строк | Команды `moveLine*` и `copyLine*` убраны из keymap | CodeEditorPanel |
| Копирование образца | `copy`, `cut` и `dragstart` отменяются на всём документе; образец и превью с `user-select: none` | main.js, CSS |
| Уход на другую вкладку или в программу | `FocusMonitor`: blur, visibilitychange и опрос `hasFocus()` раз в секунду (фокус во вложенном iframe уходом не считается). Уходы ≥ 2 с отправляются и показываются тостом | FocusMonitor, main.js |
| Решение сразу после ухода | Флаг `solvedAfterAway` (уход ≥ 15 с, решение ≤ 2 мин после возвращения) | store.js |

В панели работы с признаками помечены **красным уголком** в ячейке матрицы, а в карточке
студента выводится строка «⚠ …».

**Ограничения (не ловится):** подсказка с телефона или от соседа, после которой код набран честно;
фото экрана; подделка статуса через DevTools (сервер не перепроверяет решение). Поэтому отметки —
повод посмотреть код, а не автоматический вердикт. Для экзамена нужна серверная перепроверка.
