# Дизайн-система «Тетрадь»

Визуальный стиль тренажёра, отделённый от кода, чтобы его можно было перенести в другой проект.

| Файл | Что внутри |
| --- | --- |
| [01-foundations.md](01-foundations.md) | Принципы, цвет, типографика, отступы, скругления, тени, фон в клетку, движение, иконки, сетка и адаптивность |
| [02-components.md](02-components.md) | Компоненты с размерами и состояниями: кнопки, панели, поля, обратная связь, навигация, тосты, диалоги, матрица, теория |
| [03-boxes-schema.md](03-boxes-schema.md) | Схема коробок для контейнеров HTML (header, nav, main, footer, div) |
| [tokens.css](tokens.css) | Готовые CSS-переменные: подключить первым файлом |
| [tokens.json](tokens.json) | Те же токены в JSON (для Figma Tokens / Style Dictionary / JS) |

Исходники стилей в проекте: `src/styles/main.css` (токены и все компоненты тетради),
`src/styles/boxes.css` (схема коробок), `src/admin/admin.css` (панель преподавателя).

## Характер

**Тёплая бумажная тетрадь.** Кремовые и песочные тона вместо белого и серого, «чернильный»
тёмно-коричневый вместо чёрного, акцент — дерево. Лист в клетку под кодом. Узкий
гротеск Oswald в заголовках, как на обложке тетради. Мягкое, «оседающее» появление панелей.
Спокойный интерфейс без ярких цветов: цвет появляется только в статусах и на схеме контейнеров.
