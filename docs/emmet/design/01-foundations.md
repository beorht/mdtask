# 1. Основы

## Принципы

1. **Бумага, а не экран.** Фоны — оттенки кремовой бумаги, текст — тёплый тёмно-коричневый. Чистый белый (`#FFF`) используется только в превью «как в браузере».
2. **Один акцент.** Дерево (`--accent-wood`) отмечает текущее и активное: фокус, текущую точку, маркеры списков. Тёмная «чернильная» заливка (`--ink`) — у главной кнопки.
3. **Цвет несёт смысл.** Зелёный — принято, охра — почти, терракота — ошибка. Синий, оранжевый, зелёный и фиолетовый есть только на схеме контейнеров (у каждого контейнера свой цвет).
4. **Всё в одном экране.** Рабочая область занимает `100dvh` без прокрутки страницы, прокручиваются только внутренности панелей.
5. **Мягкое движение.** Элементы поднимаются на 3–22 px и проявляются. Прозрачность набирается быстрее, чем идёт движение. Если включён `prefers-reduced-motion`, анимации отключаются.
6. **Подписи капсом.** Ярлыки секций (eyebrow, figcaption, label) — 10–10.5 px, 600, разрядка 0.12–0.16em, uppercase.

## Фон в клетку

Редактор: лист `--bg`, линии дерева 13% прозрачности, клетка 24px, фон прокручивается вместе с текстом.

```css
background-color: var(--bg);
background-image:
  linear-gradient(to right, rgb(184 138 90 / 0.13) 1px, transparent 1px),
  linear-gradient(to bottom, rgb(184 138 90 / 0.13) 1px, transparent 1px);
background-size: var(--grid-cell) var(--grid-cell);
background-attachment: local;
line-height: var(--grid-cell);          /* строки ложатся на клетки */
```

Поле нумерации строк отделено красноватой «полевой» линией: `border-right: 1px solid rgb(169 69 47 / .22)`.
Экран входа — та же клетка линиями `--border` по фону `--page`.

## Сетка и адаптивность

- Тетрадь: `grid-template-rows: auto 1fr`, высота `100dvh`, поля `max(--gap, env(safe-area-inset-*))`. Рабочая область — 2 колонки `minmax(0,1fr)` 50/50. Теория занимает обе колонки (`grid-column: 1 / -1`), колонка текста до 980px, абзацы до 760px.
- Образец: две половины `grid-template-rows: 1fr 1fr`, зазор 10px.
- Панель преподавателя: до 1480px по центру, обычная прокрутка страницы.
- Брейкпоинты: 1100 (точки уже) · 960 (одна колонка, прокрутка; мин. высоты: образец 440, редактор 600) · 760 (примеры теории в столбик) · 720 (скрыть имя и точки) · 480 (уменьшить pad и gap, скрыть подсказку по клавишам) · высота 640.
- Целевое разрешение — от 1280×720. Проверено на 1366×768 и 1440×900.

## Доступность

- Фокус: `outline: 2px solid var(--accent-wood); outline-offset: 2px` (только `:focus-visible`).
- Живые регионы: обратная связь `role=status aria-live=polite`, тост, ошибки входа `role=alert`.
- `.visually-hidden` для текста только для экранных чтецов (подсказки по клавишам, состояния ячеек).
- Цвет никогда не единственный носитель смысла: у ячеек есть число и `title`, у статусов — заголовок.
- `aria-pressed` у сегментированных переключателей, `aria-current="step"` у текущей точки.
