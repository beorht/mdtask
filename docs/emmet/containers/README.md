# Контейнеры HTML — отложено для отдельного предмета

26.10.2026 раздел «id, class и контейнеры» убран из тренажёра «Emmet · Тетрадь» (`/subjects/emmet`):
его сделаем отдельным предметом. Здесь — всё, что нужно, чтобы вернуть раздел, в том виде, в каком он
работал в тренажёре.

| Файл | Что это |
| --- | --- |
| `containers.json` | 10 заданий (`containers-01`…`containers-10`, `mode: "html"`, `section: "containers"`): условие и эталон `emmetExpression` (в браузер не уходит) |
| `expected.json` | ожидаемый HTML этих заданий (развёртывание эталона, как `src/lib/emmet/data/expected.json`) |
| `client/LessonView.js` | теория «id, class и контейнеры» (по презентации): id, class, div, вложенность, header/nav/main/footer, схемы-коробки |
| `client/TargetPanel.js` | образец: для заданий на контейнеры показывает не код, а вид страницы — «Ваш код» сверху, «Как должно выглядеть» снизу, переключатель «Браузер / Схема» |
| `client/PreviewFrame.js` | предпросмотр в `iframe`, вариант `boxes` — схема коробками с метками тегов, id и class |
| `client/boxes.css` | стили схемы-коробок |
| `client/containers.css` | стили из `main.css`: схема в образце, переключатель, отметки раздела в навигации, страница теории |
| `client/main.js`, `client/LessonNav.js` | как теория вставлялась перед первым заданием раздела (`buildPlan`) и как раздел отмечался в навигации |
| `client/validation.spec.js` | тесты клиента того времени, включая проверки заданий на контейнеры |

Особенности заданий: HTML можно писать руками (`mode: "html"`), Emmet тоже работает (сокращение — вся строка + Tab);
серверная проверка (`src/lib/emmet/validate.js`, `checkAttempt`) поддерживает их без изменений.
Прогресс студентов, успевших решать контейнеры, остался в таблице `emmet_progress` (строки `containers-*`).
