### План внедрения палитры

#### 1. Базовая палитра

```text
Background      #F3EDE3  — тёплый cream
Surface         #FBF8F2  — светлые карточки
Surface Dark    #191A1C  — тёмные панели
Text Primary    #202124  — почти чёрный
Text Secondary  #6F6B64  — muted gray

Purple          #665477
Olive           #85866A
Terracotta      #A94F36
Navy            #263B4A
Beige           #D8D0C3
```

---

#### 2. Общая стилистика

Перевести интерфейс из:

```text
Dark / Neon / Gradient
```

в:

```text
Warm / Editorial / Minimal / Creative
```

Основной фон:

```text
cream
   ↓
white/beige surfaces
   ↓
dark typography
   ↓
muted purple / olive / terracotta accents
```

---

#### 3. Header

Сделать светлым и минималистичным:

```text
┌──────────────────────────────────────────────┐
│ Logo     Курсы   Материалы   Практика    👤 │
└──────────────────────────────────────────────┘
```

* background: `#F3EDE3`
* border: `#DDD5C9`
* активный пункт: `#665477`
* кнопки — тёмные или terracotta.

---

#### 4. Sidebar

Вместо тёмной панели:

```text
cream / beige
```

Активный раздел выделять **приглушённым фиолетовым**:

```text
┌─────────────────────┐
│ DATABASES            │
│                     │
│ ✓ Введение           │
│                     │
│ CREATE TABLE         │
│   ✓ Теория           │
│   ● Практика         │
│   ○ Тест             │
│                     │
│ INSERT INTO          │
│   ○ Теория           │
└─────────────────────┘
```

Не использовать яркий purple — только muted `#665477`.

---

#### 5. Практический редактор

Здесь можно сделать интересный контраст:

```text
Светлый интерфейс
        ↓
Тёмный SQL Editor
        ↓
Тёплый Result Panel
```

Например:

```text
┌──────────────────────────────┐
│ Задание                       │
│                              │
│ ┌──────────────────────────┐ │
│ │ SQL EDITOR               │ │
│ │ #191A1C                  │ │
│ │                          │ │
│ │ CREATE TABLE products... │ │
│ └──────────────────────────┘ │
│                              │
│ [▶ Выполнить] [✓ Проверить] │
└──────────────────────────────┘
```

Это даст интерфейсу ощущение профессионального инструмента.

---

#### 6. CTA-кнопки

Основная кнопка:

```text
background: #665477
color: #FFFFFF
```

Альтернативная:

```text
background: #A94F36
color: #FFFFFF
```

Не использовать gradient — этот референс лучше работает с **плоскими, материальными цветами**.

---

#### 7. Progress

Для прогресса использовать терракотовый:

```text
████████████░░░░
```

```text
#A94F36
```

или комбинацию:

```text
Purple → Terracotta
```

Но без яркого свечения.

---

#### 8. Статусы

Сохранить семантические цвета:

```text
✓ Success       #667A55
✕ Error         #A94F36
⚠ Warning       #B38A45
ⓘ Info          #526878
● Current       #665477
○ Not started   #A9A39A
```

---

#### 9. Карточки

Использовать стиль референса:

```text
background: #FBF8F2
border: 1px solid #DED6C9
border-radius: 12–16px
```

Можно добавить очень лёгкую текстуру/шум на **фон**, но не на рабочие области.

---

#### 10. Иллюстративные элементы

Это важная особенность второго референса.

Можно добавить небольшие декоративные элементы:

* абстрактные purple shapes;
* olive-блоки;
* terracotta линии;
* точечные паттерны;
* рукописные/скетчевые элементы;
* тонкие геометрические схемы.

Но только в:

```text
Dashboard
Empty states
Onboarding
Course covers
Landing page
```

**Не добавлять их в SQL Editor и рабочую область задания.**

---

### Итоговая формула

```text
        CREAM
          │
    ┌─────┴─────┐
    │           │
 PURPLE       OLIVE
 #665477      #85866A
    │           │
    └─────┬─────┘
          │
      TERRACOTTA
        #A94F36
          │
       DARK NAVY
        #263B4A
```

Распределение я бы сделал примерно так:

```text
70% — cream / beige / white
15% — dark navy / charcoal
 7% — muted purple
 5% — olive
 3% — terracotta
```

**Ключевая идея:** первый референс можно использовать для ощущения *tech / futuristic*, а этот — для *educational / creative / premium*. Для самой учебной платформы второй вариант хорошо подходит как основа, особенно если хочется уйти от типичного «тёмный SaaS + neon gradient» и сделать интерфейс более спокойным и запоминающимся.
