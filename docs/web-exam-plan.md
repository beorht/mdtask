# Итоговая контрольная группы WEB: веб-приложение по техническому заданию

Запрошено и сделано 24.10.2026 (вариант **В**; остальные варианты — `docs/web-exam-variants.md`).
Проверяет преподаватель; код студента сохраняется, в админке все файлы скачиваются архивом.

## Для студента — `/exam/web-final-1`

- Одно задание на всю контрольную: приложение «по ТЗ» в трёх файлах `index.html`, `style.css`, `script.js`.
- **Тема у каждого своя** (по месту в группе, 6 тем: каталог библиотеки, магазин электроники, афиша
  кинотеатра, книга рецептов, задачи команды, спортивный клуб) и **свои данные и правила** (из seed варианта):
  8 исходных записей таблицей, порог «выделить запись», границы числа и минимальная длина названия в форме,
  какой итог считать (сумма / среднее / максимум), ключ `localStorage`.
- **Приложение одностраничное** (с 26.10.2026, требование 1): один index.html без перезагрузок, меню из трёх разделов
  «Список» / «Добавить» / «Избранное», виден один раздел, раздел в адресе после «#» (#list, #add, #favorites),
  «Назад»/«Вперёд» и адрес с «#» работают.
- **10 требований по 10 баллов** (0 / 5 / 10 ставит преподаватель): одностраничность и разметка, оформление и адаптив, данные из
  массива объектов через DOM, карточка с выделением, поиск, фильтр, сортировка, итог, форма добавления с
  проверкой, удаление и избранное через делегирование + сохранение в `localStorage`. В тексте требований нет кода.
- **Редактор**: три вкладки CodeMirror (режимы htmlmixed, css, javascript лежат в `public/vendor/`, интернет
  не нужен), «▶ Запустить» (Ctrl+Enter), «💾 Сохранить» (Ctrl+S). Вставка и перетаскивание текста в редактор
  отключены, попытка записывается.
- **Предпросмотр** (`public/js/web-runner.js`): три файла собираются в один документ (ссылки на `style.css` и
  `script.js` заменяются их содержимым) и открываются в `<iframe sandbox="allow-scripts allow-forms allow-modals">`
  **без** `allow-same-origin` — код студента не видит сайт, вход и cookie. Настоящий `localStorage` там
  недоступен — его заменяет своё хранилище, переживающее повторный «Запустить» (как перезагрузку страницы);
  кнопка «Очистить localStorage». `console.log`, ошибки и отправка формы без `preventDefault` — в панели «Консоль».
  Над окном — «◀ ▶» и строка адреса с «#» (Enter — открыть заново с этим адресом); в окно добавляется
  `<base href="about:srcdoc">`, иначе ссылка «#add» загрузила бы в окно страницу сайта, а `history.pushState` не работал бы.
  На каждый запуск создаётся новое окно, чтобы не засорять историю страницы контрольной.
- **Сохранение**: автосохранение через 3 с после изменения и при запуске; снимок кода раз в минуту и по
  «Сохранить» (`data/exam/web-final-1/snapshots/<id>/NNNNN-app.json`); после конца (+2 мин) сохранение отклоняется,
  страница — только для чтения. Результат (баллы, оценка, комментарий) виден после «Опубликовать результаты».

## Для преподавателя — `/admin/web-exam`

- Проведение: время (UTC+5), «Выдать варианты группе WEB», «Опубликовать результаты», закрыть/открыть
  практические задания группы, проверка устройства (список ПК — общий с IB; для WEB по умолчанию «Отмечать»).
- Таблица работ: тема, последнее сохранение, размеры файлов, снимков, события (вставки, уходы со страницы,
  вход не с ПК аудитории), баллы, оценка, zip студента; кнопка **«Все работы (zip)»** — папка на студента.
- Страница студента: его приложение в изолированном окне (последнее сохранение или любой снимок), файлы,
  оценка по 10 требованиям + комментарий, журнал действий. **«Файлы студента (zip)»**: `index.html`, `style.css`,
  `script.js`, `README.txt` (тема, ключ, баллы), `snapshots/NNNNN-app/*` (все снимки), `log.jsonl` (журнал).
- Оценка: 86+ — 5, 71+ — 4, 56+ — 3, иначе 2.

## Устройство

- `src/lib/web-exam/index.js` — определение контрольной, темы и варианты, требования, файлы и снимки, архивы.
- `src/routes/web-exam.js` — страница, `/save`, `/log`; смонтирован перед `src/routes/exam.js` и пропускает
  чужие id (`next('route')`).
- `src/routes/admin-web-exam.js`, `src/views/admin/web-exam*.ejs`, `public/js/admin-web-exam.js`.
- Общее с контрольной IB: таблицы `exams`, `exam_variants`, `exam_tasks` (задание `app`: файлы в `draft`,
  оценка в `result` и `teacher_score`), журнал `src/lib/exam/log.js`, проверка ПК `src/lib/exam/devices.js`,
  таймер и журнал браузера `public/js/exam.js`; блокировка практики (`examLockFor`) и карточка на главной
  учитывают обе контрольные.
- Время по умолчанию — 27.11.2026 9:00–11:50 (+05); ставится в админке.
- Тесты: `tests/routes/web-exam.test.js`.
