# Скрипт обновления: не обновлять код во время контрольной

Запрошено 26.10.2026. Пункт в `TODO.md`. **Применено 26.10.2026** (см. раздел «Выполнено» в `TODO.md`).

## Проблема

`scripts/deploy/update-server.sh` сейчас при идущей контрольной **копирует код, но не перезапускает** сервер.
Так нельзя: после копирования часть изменений начинает работать сразу, а часть — нет.

- Сразу (читаются с диска при каждом запросе): шаблоны `src/views/` (если сервер без `NODE_ENV=production`),
  `public/` (CSS, JS страниц), `content/`.
- Только после перезапуска: `src/routes`, `src/lib`, `src/db`, `index.js`, Python-процесс `ib/`.

Новый шаблон со старым кодом сервера (например, шаблон ждёт переменную, которую старый маршрут не передаёт)
или новый скрипт страницы со старым API → ошибка на странице посреди контрольной.

## Что сделать

1. Если сейчас идёт контрольная (окно `exams` + 2 минуты), скрипт **ничего не копирует** и выходит с сообщением:
   какая контрольная идёт и до скольких, «запустите после окончания».
2. `--force` — обновить и перезапустить всё равно (студентам придётся войти заново; работа сохранена).
3. `--no-restart` вне контрольной оставить: для серверов, которые запускаются через systemd/pm2.
4. `--dry-run` работает и во время контрольной (только показывает изменения).
5. Проверка: на копии кода сервера с тестовой базой, окно контрольной поставить на «сейчас» — скрипт отказывается,
   файлы не меняются; с `--force` — обновляет и перезапускает.

- `archive/update-server.sh` — копия для отправки на сервер, пересобрать архив.
