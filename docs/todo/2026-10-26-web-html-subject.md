# Предмет «Web-разработка: HTML» — план тем и структура

Запрошено 26.10.2026. Сделано 26.10.2026 (локально): основа и все 12 тем, 106 заданий.

## Идея

Отдельный предмет на главной (своя карточка, страница `/subjects/html`, боковое меню по темам, как у SQL).
Каждая тема состоит из двух шагов:

- **N.1. Теоретический материал** — страница теории с живыми примерами: код примера и рядом его вид в браузере (как теория «id, class и контейнеры» из Emmet, `docs/emmet/containers/client/LessonView.js`).
- **N.2. Практическая работа** — набор заданий в окне по образцу EmmetEmulator.

Темы открываются по порядку: практика темы — после теории, следующая тема — после практики предыдущей (TEST видит всё).

### Окно практической работы

```
┌───────────────────────────────┬───────────────────────────────┐
│ Ваш код (вид в браузере)      │ Условие задания               │
│ обновляется, пока вы печатаете│                               │
├───────────────────────────────┤ Редактор HTML                 │
│ Как должно выглядеть          │ (CodeMirror, лист в клетку)   │
│ (ожидаемый результат)         │                               │
│                               │ [Проверить]   сообщение       │
└───────────────────────────────┴───────────────────────────────┘
```

- Слева сверху — вид кода ученика, снизу — ожидаемый результат. **Код образца не показывается**, только вид, поэтому студент пишет весь код сам.
- Переключатель «Браузер / Схема»: схема рисует ту же страницу коробками с подписями `тег#id.class` (уже есть: `PreviewFrame` вариант `boxes` в `docs/emmet/containers/client/`). Специальные контейнеры на схеме — каждый своим цветом (`header`, `nav`, `main`, `footer` уже раскрашены; добавить `section`, `article`, `aside`, `figure`, `details`, `address`), обычный `div` — нейтральный.
- Справа — редактор HTML: разметку пишут руками, Emmet тоже работает (сокращение на всю строку + Tab). Вставка запрещена, как в тренажёре Emmet.
- Проверка — сравнение структуры: теги, вложенность, атрибуты и текст; отступы и порядок атрибутов не важны. Каждую попытку перепроверяет сервер (`src/lib/emmet/validate.js` уже это умеет).
- Основа — сохранённый раздел «Контейнеры HTML» (`docs/emmet/containers/`): `TargetPanel` с режимом показа и схемой, `PreviewFrame`, `boxes.css`, режим `html` редактора.

## Темы

Каждая тема: 1 — теория, 2 — практическая работа (8–10 заданий). Содержание практики — бытовые задачи
(страница кафе, карточка товара, расписание…), без уровней сложности в текстах.

| № | Тема | Теория (N.1) | Практика (N.2): что делают в заданиях |
| --- | --- | --- | --- |
| 1 | Как устроена веб-страница | Браузер и HTML; тег, элемент, атрибут; парные и одиночные теги; вложенность; каркас документа `<!doctype>`, `html`, `head`, `body`, `title`, `meta charset`; комментарии | Собрать каркас страницы, исправить неправильную вложенность, поставить заголовок вкладки |
| 2 | Текст | `h1`–`h6`, `p`, `br`, `hr`; `strong`, `em`, `mark`, `small`, `sub`, `sup`; `blockquote`, `q`, `cite`; `pre`, `code` | Статья с заголовками, формула со степенями, цитата с автором, фрагмент кода |
| 3 | Списки | `ul`, `ol`, `li`; вложенные списки; `type`, `start`, `reversed`; список определений `dl`, `dt`, `dd` | Список покупок, рецепт по шагам, оглавление с подпунктами, словарь терминов |

| 6 | Таблицы | `table`, `tr`, `td`, `th`, `caption`; `thead`, `tbody`, `tfoot`; `colspan`, `rowspan` | Расписание уроков, прайс-лист с итогом, табель с объединёнными ячейками |

| 10 | Специальные контейнеры | Контейнеры со смыслом вместо `div`: страница — `header`, `nav`, `main`, `footer`; содержимое — `section`, `article`, `aside`; отдельные блоки — `figure` + `figcaption`, `details` + `summary` (раскрывающийся блок), `address`, `blockquote`; какой выбрать (таблица «если это… — то…»), зачем (поисковики, экранные дикторы, читаемость кода); можно вкладывать друг в друга и в `div` | Блог, страница новостей, сайт кафе — каркас из специальных контейнеров; FAQ на `details`; карточка статьи с `aside`; «замените `div` на нужный специальный контейнер» |

## Устройство (кратко)

- Данные: `src/lib/html-course/data/topics.json` (темы, задания, эталонный HTML), теория — Markdown с живыми примерами в `content/html/theory/NN-<slug>.md`.
- Маршруты: `/subjects/html`, `/subjects/html/<тема>/theory`, `/subjects/html/<тема>/practice` (страница с клиентом из `emmet/`: вторая точка входа сборки), API как у Emmet: `me`, `events`.
- Таблицы: прогресс и попытки по заданиям (как `emmet_progress`/`emmet_events`), занятие «Завершить» по группе.
- Защита: вставка запрещена, уходы со страницы, сравнение браузер ≠ сервер; «Выбрать 4 студентов» в админке. Задания общие для всех (решение 2), без личных данных.
- Админка `/admin/html`: матрица «студент × задание» по темам, код решений, журнал.
- Тема 1, задания про `head`/`title`: в окне вид этого не показывает, поэтому в условии — текстом, а проверка — по структуре всего документа.
- Под закрытием контрольной (`examLockFor`) — как остальная практика.
