| Тип урока | Что на странице | Проверка |

| Практика | 5–8 задач: условие, редактор Python, ввод (`input`) и вывод | тесты «ввод → ожидаемый вывод»; программа выполняется в браузере, сервер сравнивает вывод; первые тесты открыты, остальные скрыты |

### Модуль 6. Сокеты (6) — всё ✍

62 эхо-сервер · 63 общение двух программ (с ПК одногруппника) · 64 JSON по сети · 65 сетевой регистратор (сокеты +
SQLite) · 66 сетевой справочник · 69 мини-проект «Сетевой мессенджер с историей».

В браузере настоящих сокетов нет. Предлагается **учебная сеть на сайте**:
- модуль `socket` в Pyodide подменяется своим с теми же функциями (`bind`, `listen`, `accept`, `connect`, `send`,
  `recv`);
- данные идут через сервер mdtask;
- программа-сервер открыта в одной вкладке, клиент — в другой или на ПК одногруппника (урок 63);
- проверка: сервер mdtask подключается к программе студента как клиент или сервер и сверяет обмен.

Это самая сложная часть — последним этапом.

## Что разработать

1. **Раздел курса в предмете Python:**
   - модули → уроки (теория / практика / мини-проект), порядок открытия;
   - контент в `content/python-course/<модуль>/<урок>/` (`theory.md`, `tasks.json` с тестами);
   - матрица «студент × урок» в админке. Основа — предмет HTML (`src/lib/html-course/`).
2. **Практика Python:**
   - редактор (CodeMirror 5, как в контрольной IB), запуск в Pyodide с `stdin`;
   - открытые и скрытые тесты, сравнение на сервере (`python-basics-check.js`);
   - несколько файлов, файлы-данные в песочнице, фиксированные `random.seed` и время;
   - запрещённые конструкции (`sorted`, `min`… — как в контрольной IB);
   - проверка функций и классов вызовами из скрытого кода; контрольные вопросы после решения.
3. **«▶ Запустить» у примеров теории.**
4. **Учебный REST API** + вендоринг `requests` / `pyodide-http` / `python-dotenv` (модуль 5).
5. **Учебная сеть** — подмена `socket` и сервер-посредник (модуль 6).
6. **Контент:**
   - теория по всем 54 урокам (из источника + дописать);
   - 5–8 задач на практику с тестами, задачи — по нарастающей;
   - эталонные решения в `scripts/python-course/solutions/`, тест проверяет, что они проходят все тесты;
   - контрольные вопросы.
