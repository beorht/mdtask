## Состав задания (для студента; без кода, только требования)

Рабочее название: **«Каталог на XML + DOM»** — двухстраничный сайт.

Студент собирает сайт из файлов и сдаёт **одним архивом** `site.zip`:

| Файл | Назначение |
|------|------------|
| `index.html` | Страница 1 — каталог (список) |
| `item.html`  | Страница 2 — карточка одного элемента |
| `style.css`  | Оформление обеих страниц |
| `script.js`  | Вся логика через DOM |
| `data.xml`   | Данные каталога (≥ 8 записей) |
| `schema.xsd` | XSD-схема, которой соответствует `data.xml` |

**Требования к работе** (формулируются в тексте словами и таблицами, без готового
кода — по правилу проекта):

1. **Данные в `data.xml`.** Студент сам проектирует структуру из описанных полей
   (таблица полей в тексте: напр. `id`, `название`, `категория`, `цена`/`год`,
   `описание`, `изображение`). Минимум 8 записей.
2. **`schema.xsd`.** XSD-схема описывает структуру `data.xml`: корневой элемент,
   повторяющийся элемент записи, типы полей (число/строка/дата), обязательность,
   хотя бы одно ограничение (`xs:restriction`: диапазон, перечисление или шаблон).
   Студент обязан убедиться, что `data.xml` проходит валидацию по `schema.xsd`
   (онлайн-валидатор или `xmllint --schema`). В тексте — что проверить.
3. **Страница 1 (каталог).** `script.js` загружает `data.xml` (`fetch` +
   `DOMParser` или `XMLHttpRequest`), разбирает его и **через DOM**
   (`createElement`/`append`/`textContent`/`dataset`) строит список карточек.
   Поиск/фильтр по полю (обработчик `input`/`change`), переход на страницу 2.
4. **Страница 2 (карточка).** По параметру (`?id=…` из `location.search`) находит
   запись в `data.xml` и отрисовывает её детально через DOM. Кнопка «назад» к
   каталогу. Навигация между страницами.
5. **Только DOM-средства** в JS (без сторонних библиотек, без фреймворков).
   Без difficulty-слов в тексте.

Чек-лист оценивания (видит учитель в админке): XML валиден по XSD; оба HTML
открываются; данные берутся из XML, а не зашиты в HTML; список строится через
DOM; поиск/фильтр работает; переход на карточку по id работает; есть ≥ 8 записей.
