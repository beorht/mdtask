# Защита от нагрузки залогиненных пользователей (rate-limit + лимиты загрузки)

Запрошено 29.10.2026 после разбора безопасности. Контекст: вход от брутфорса уже прикрыт
(`src/lib/login-throttle.js`), но залогиненный студент мог «простреливать» сервер частыми запросами
(общего ограничения частоты не было) и заливать файлы без лимита размера. Без npm-зависимостей.

## П.1 — Ограничение частоты запросов

`src/lib/rate-limit.js` — in-memory лимитер с фиксированным окном (счётчики в памяти процесса,
без БД: по запросу на каждый чих писать в SQLite дорого). Ключ — id пользователя из сессии, иначе IP.

- **Глобальный** лимитер (`globalLimiter`): ~600 запросов/мин на пользователя — режет только настоящий
  флуд (сотни-тысячи/сек), обычную работу не трогает. Монтируется в `src/server.js` после `/health`
  (статика раздаётся выше и под лимит не попадает) до роутеров.
- **Строгий** лимитер (`heavyLimiter`): ~120 запросов/мин на пользователя для тяжёлых эндпоинтов:
  SQL-тренажёр (`POST /trainer/:id/run|submit`), прокси IB-терминала (`POST /ib/:task/api/:action`,
  детектор `check`/`challenge`), предпросмотр Markdown (`POST /api/preview`).
- В тестах (`DB_PATH=:memory:`) лимитер выключен, чтобы не мешать прогонам; ядро (`hit`) покрыто
  отдельным unit-тестом.
- При превышении — `429` + заголовок `Retry-After` и короткое сообщение.

## П.2 — Лимиты загрузки файлов

`src/routes/student.js`:
- multer: `limits: { fileSize: 30 МБ, files: 10 }` — бьёт по диску независимо от прав.
- Проверка прав и срока **до записи** файла: middleware `canUploadGuard` перед `handleUpload` на
  `POST /assignment/:id/submit` — нет доступа → 403, приём закрыт/просрочено → редирект, файл не пишется.

## Не входит (отдельно)

- П.3 из разбора — очередь/лимит одновременных команд к единственному процессу `python3` IB-терминала
  (один студент не должен монополизировать его для всех). Нужна аккуратная очередь в `ib-bridge`.
- Заголовки безопасности (helmet вручную), `cookie.secure` за HTTPS, инвалидация сессий при смене
  пароля, лог успешных входов — обсуждалось, по отдельному «давай».
