# Предмет «Web-разработка: CSS» — план тем

Запрошено 27.10.2026: «надо добавить предмет по материалу CSS, для начала создай полноценный список тем».
Сделано 27.10.2026 (локально): 19 тем, 227 заданий; группа web-1 и TEST. Решения: студент пишет только CSS к готовой разметке; список тем — как ниже. Устройство — в CLAUDE.md («Предмет «Web-разработка: CSS»»).

## Идея

Продолжение предмета «Web-разработка: HTML» (`/subjects/html`), устроен так же: своя карточка, страница
`/subjects/css`, меню по темам. Каждая тема — **N.1 теория** (живые примеры: код и рядом его вид в браузере) и
**N.2 практика** (8–10 заданий, в темах 10–13, 16, 17 — 15–20, кнопки `.topic-btn` как у всех предметов). Темы открываются по порядку, TEST видит всё.
Без уровней сложности в текстах. Классы ПК без интернета: шрифты и картинки — только из `public/vendor/`.

## Расширенная практика: Flexbox, Grid, анимации, адаптивность

По просьбе преподавателя (27.10.2026) в темах 10–13, 16 и 17 практика больше — **15–20 заданий** (в остальных темах
8–10). Задания идут от простого к сложному, без слов об уровнях. Ниже — список заданий.

### Тема 10. Flexbox: контейнер — 16 заданий

1. Три кнопки в один ряд.
2. Пункты меню в ряд с промежутком `gap`.
3. Логотип слева, меню справа (`space-between`).
4. Меню по центру шапки.
5. Блок с надписью точно по центру экрана — по обеим осям.
6. Иконка и подпись на одной линии по вертикали (`align-items: center`).
7. Колонка карточек сверху вниз (`flex-direction: column`).
8. Обратный порядок без изменения HTML (`row-reverse`).
9. Карточки равномерно по ширине (`space-around` / `space-evenly`).
10. Ряд карточек с переносом на новую строку (`flex-wrap`).
11. Разный промежуток между строками и столбцами (`row-gap` / `column-gap`).
12. Кнопки, прижатые к низу блока (`align-items: flex-end`).
13. Теги-«пилюли» статьи с переносом.
14. Панель инструментов: группы кнопок слева и справа.
15. Шаги оформления заказа «1 → 2 → 3» в ряд со стрелками.
16. Подвал сайта: три колонки ссылок и строка копирайта ниже.

### Тема 11. Flexbox: элементы и раскладки — 18 заданий

1. Поле поиска растягивается, кнопка — своей ширины (`flex-grow`).
2. Две колонки 1:2.
3. Три колонки 1:2:1.
4. Боковая панель фиксированной ширины, контент — всё остальное.
5. Элемент, который не сжимается (`flex-shrink: 0`).
6. Базовая ширина карточек (`flex-basis`) с переносом.
7. Шапка «логотип — меню — кнопка входа» с `margin-left: auto`.
8. Последний пункт меню прижат вправо.
9. Порядок блоков без изменения HTML (`order`).
10. Один элемент выровнен иначе, чем остальные (`align-self`).
11. Карточки одинаковой высоты, кнопка «Купить» у всех внизу.
12. Медиа-объект: картинка слева, текст справа.
13. Чат: сообщения «моё» справа, «чужое» слева.
14. Подвал, прижатый к низу короткой страницы.
15. Карточка товара: фото, название, цена и кнопка в ряд.
16. Тарифы: три карточки, средняя выделена и чуть выше.
17. Форма в строку: подпись, поле, кнопка.
18. Страница целиком на flex: шапка, боковое меню, контент, подвал.

### Тема 12. Grid: сетка — 16 заданий

1. Сетка из трёх равных колонок.
2. Колонки разной ширины в `fr`.
3. `repeat()` для четырёх колонок.
4. Фиксированная колонка + гибкие (`200px 1fr`).
5. Строки заданной высоты.
6. Промежутки `gap` между ячейками.
7. Ячейка на две колонки (`span`).
8. Ячейка на две строки.
9. Шапка во всю ширину сетки (`grid-column: 1 / -1`).
10. Галерея 3×3, в которой одна картинка крупнее.
11. Расписание уроков на grid: дни × пары.
12. Календарь месяца 7×5.
13. Клавиатура калькулятора, где «0» и «=» шире.
14. Выравнивание содержимого ячеек (`justify-items` / `align-items`).
15. Блок по центру ячейки (`place-items: center`).
16. Плитки разного размера «bento».

### Тема 13. Grid: области и макеты страниц — 16 заданий

1. Каркас «шапка — контент — подвал» через `grid-template-areas`.
2. Тот же каркас с боковой колонкой слева.
3. Две боковые колонки.
4. Поменять местами области, не трогая HTML.
5. Пустая область (`.`) в макете.
6. `minmax()` — колонка не уже заданной ширины.
7. Галерея, которая сама подбирает число колонок (`auto-fill`).
8. То же через `auto-fit` — увидеть разницу.
9. Карточки товаров каталога на `auto-fill` + `minmax`.
10. Главная новостного сайта: большая новость и колонка мелких.
11. Профиль: аватар, имя, статистика, кнопки.
12. Панель управления: боковое меню, шапка, плитки показателей.
13. Карточка статьи: картинка, текст и автор внутри grid.
14. Форма на grid: подписи в одной колонке, поля — в другой.
15. Grid снаружи, flex внутри: сетка карточек с выровненным содержимым.
16. Лендинг целиком по образцу на grid.

### Тема 16. Переходы, трансформации и анимации — 18 заданий

1. Плавная смена цвета кнопки при наведении (`transition`).
2. Переход нескольких свойств с разной длительностью.
3. Задержка перехода (`transition-delay`).
4. Разные `timing-function`: `ease`, `linear`, `ease-in-out`.
5. Сдвиг карточки вверх при наведении (`translateY`).
6. Увеличение картинки при наведении (`scale`) внутри рамки.
7. Поворот значка (`rotate`).
8. Точка трансформации (`transform-origin`).
9. Несколько трансформаций сразу.
10. Подчёркивание ссылки, которое «вырастает» слева направо.
11. Кнопка, которая «нажимается» (`:active`).
12. Первая анимация `@keyframes`: появление блока.
13. Бесконечное вращение — индикатор загрузки.
14. «Пульс» значка уведомления.
15. Анимация с несколькими ключевыми кадрами (0%, 50%, 100%).
16. Задержка и число повторов (`animation-delay`, `iteration-count`).
17. Карточка, переворачивающаяся при наведении.
18. Отключение анимаций для `prefers-reduced-motion`.

### Тема 17. Адаптивная вёрстка — 18 заданий

1. `meta viewport` и что без него на телефоне.
2. Резиновый контейнер: `max-width` + отступы по бокам.
3. Картинки, не вылезающие за экран (`max-width: 100%`).
4. Размер шрифта в `rem` и `clamp()`.
5. Первый `@media`: другой фон на узком экране.
6. Две колонки на компьютере, одна на телефоне (flex).
7. То же на grid.
8. Сетка карточек: 4 → 2 → 1 колонки на точках перелома.
9. «Сначала телефон»: стили для узкого экрана, `min-width` для широкого.
10. Меню в строку на компьютере, в колонку на телефоне.
11. Скрыть второстепенный блок на телефоне.
12. Меню-«бургер» без JavaScript (`:checked` + `label`).
13. Адаптивная таблица: горизонтальная прокрутка на телефоне.
14. Адаптивная форма: поля в две колонки → в одну.
15. Шапка: логотип и кнопка остаются, меню прячется.
16. Подвал: колонки складываются в столбик.
17. Галерея без `@media` — только `auto-fit` + `minmax`.
18. Лендинг, корректный на трёх ширинах: телефон, планшет, компьютер.

Проверка адаптивных заданий: вид студента и образец показываются на нескольких ширинах (переключатель
«Телефон / Планшет / Компьютер»), сравнение стилей — на каждой ширине.
