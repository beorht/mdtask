Сделано по просьбе преподавателя после того, как курс «Python'da oddiy dasturlash» убран с сайта
(архив `docs/archive/pybasics/`). Данные — из рабочей копии базы `data/mdtask.db` на 26.10.2026.
Это анализ и предложения; изменения — только после «давай».

## Как предмет устроен сейчас

- Карточки **Python** и **JavaScript** на главной показываются **каждому студенту** (`LANGUAGE_SUBJECTS` в
  `src/lib/subjects.js`), независимо от группы.
- У обеих карточек **один и тот же набор заданий со сдачей**: все задания без `assignments.subject`
  (43 из 46). Язык задания нигде не хранится — в тексте написано «JS-группы решают на JavaScript, Python-группы — на
  Python». Отличаются только банки задач.
- Задание = Markdown-файл (`content/src/…`, `content/SUMMARY.md`) + загрузка архива .zip/.rar; преподаватель ставит
  статус вручную. Исключение — 6 личных заданий с редактором на сайте (`code_files`, запуск в Pyodide).
- **Банк задач** Python: 12 задач, одна тема «Переменные»; страница — только текст условия, без редактора, без
  проверки и без сдачи (у JavaScript — те же 12 задач).

## Проблемы

1. **Python и JavaScript не разделены.** Студент WEB видит 21 задание по DOM (это только JavaScript) и в карточке
   «Python». Студент IB видит задачи «Объекты и словари» в карточке «JavaScript». Прогресс в обеих карточках
   одинаковый — по сути это одна карточка, показанная дважды.
2. **Карточки видят все группы, даже те, кто язык не изучает.** PRAK после удаления курса видит пустые «Python» и
   «JavaScript» (общие задания им скрыты) — у PRAK на сайте остался только SQL-тренажёр.
3. **Теория оформлена как задание со сдачей.** «Теория: объекты и словари», «Теория: DOM и объект document» и 8 частей
   «Теория DOM» — это страницы для чтения, но у них есть срок и кнопка загрузки архива; студенты WEB по ним уже
   прислали 39 + 4 файла. Теорию правильнее показывать отдельно (как у предмета «Проектирование ИС» —
   `/subjects/<key>/theory/<slug>`).
4. **Блок «Объекты и словари» не работает:** срок 07.10 прошёл, не сдано ни одной работы; у каждого студента IB, WEB и
   GRAPH эти 16 заданий висят как просроченные и портят прогресс.
5. **Ни одна работа не проверена:** все 195 сдач (из них 160 в Python/JS) в статусе «на проверке», вердиктов и
   комментариев нет. Студенты не получают обратной связи; очередь в админке растёт.
6. **Python почти нечем практиковать с автопроверкой:** банк — 12 задач по одной теме и без редактора; автопроверка
   Python на сайте была только в убранном курсе для PRAK. При этом инструменты есть: запуск Python в браузере
   (Pyodide, `python-worker.js`), сравнение вывода (`python-basics-check.js`), редактор и проверка как в предмете HTML.

## Предложения (на выбор)

1. **Разделить языки.** Добавить заданию язык (например, `assignments.subject = 'python' | 'javascript'` или
   отдельное поле) и показывать в карточке Python только Python-задания, в JavaScript — только JavaScript.
   DOM → JavaScript; «Объекты и словари» — в оба (или разделить тексты); личные задания IB → Python.
2. **Показывать карточку только тем, кто изучает язык:** Python — IB (и TEST), JavaScript — WEB (и TEST); список групп
   у предмета, как `HTML_GROUPS`.
3. **Вынести теорию из заданий** в раздел «Теория» предмета (страницы для чтения без срока и сдачи); уже присланные
   файлы по теории не удалять.
4. **«Объекты и словари»:** продлить срок, назначить конкретным группам или убрать в архив — решает преподаватель.
5. **Проверка работ:** разобрать очередь 195 сдач; для однотипных задач — автопроверка (см. п. 6), чтобы ручная
   проверка оставалась только для проектов.
6. **Python по образцу предмета HTML** (развёрнуто в плане курса «Начальный Python»: [`2026-10-26-python-beginner-course.md`](2026-10-26-python-beginner-course.md)): темы «N.1 теория → N.2 практика» с редактором на сайте и автопроверкой по
   тестам (ввод → ожидаемый вывод; закрытые тесты не видны студенту). Темы: ввод-вывод и переменные, условия, циклы,
   строки, списки, словари, функции, файлы и модули, SQLite. Банк задач заменить этими практическими работами.
7. **PRAK:** решить, что группа изучает вместо убранного курса.
