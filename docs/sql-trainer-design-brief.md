# SQL-тренажёр mdtask — краткая структура дизайна

Веб-тренажёр SQL (SQLite) для студентов колледжа. Язык интерфейса — русский.
Стиль: спокойный, «книжный», минималистичный, как mdBook.

## Каркас страницы
- **Шапка** (56 px, на всю ширину): логотип «📚 mdtask», имя студента + метка «Студент», переключатель темы 🌓, кнопки «Сменить пароль» и «Выйти».
- **Левое меню** (280 px): навигация только по SQL. На телефоне выезжает по кнопке ☰.
- **Контент** по центру (макс. 1300 px, отступ 32 px). Сверху «хлебные крошки»: Главная / Базы данных (SQL) / … / Текущая страница.

## Левое меню (своё у каждого предмета)
- Сверху: ссылка «← Все предметы», затем карточка предмета с иконкой, названием, подписью «Обзор предмета» и полосой прогресса «12 из 118 задач решено».
- Поле «Найти тему…» фильтрует темы по мере ввода.
- Темы — раскрывающиеся группы (аккордеон). В строке темы: кружок статуса (✓ решено, номер текущей темы с подсветкой, 🔒 закрыта), название, счётчик «2/10» и стрелка-шеврон.
- Внутри темы два пункта: «📖 Теория» и «🧪 Практика 2/10»; у закрытой темы практика неактивна (🔒).
- По умолчанию раскрыта только тема, в которой сейчас находится студент, либо его текущая тема; активный пункт подсвечен заливкой.
- Темы: CREATE TABLE, INSERT, SELECT, WHERE, UPDATE, DELETE, DROP TABLE, SELECT+WHERE, DISTINCT, операторы фильтрации, ORDER BY, LIMIT, агрегатные функции, группировка, PRIMARY KEY, FOREIGN KEY, связи между таблицами, JOIN.
- Меню сворачивается кнопкой ☰ с анимацией; на телефоне выезжает поверх страницы с затемнением.

## Страницы
1. **Обзор предмета**. Заголовок, «Решено X / 118», полоса прогресса. Кнопки «Продолжить: <следующая задача> →» и «Вся теория». Список тем строками: кружок с номером (✓ — решено, 🔒 — закрыто), название темы, справа ссылки «Теория» и «Практика x / y».
2. **Теория темы**. Конспект: заголовки, абзацы, таблицы, SQL-блоки с подсветкой на тёмном фоне. Внизу карточка «🧪 Практика по теме»: число заданий, «Решено x / y», кнопка «Перейти к практике →» или «🔒 откроется после предыдущих тем».
3. **Список заданий темы**. Ссылка «📖 Теория по этой теме». Карточки заданий: название + значок статуса; закрытые бледные, с 🔒.
4. **Страница задания** — фиксированная раскладка:
   - Сверху: название задания и метки «✓ Решено / ○ Не решено», «Оператор: SELECT», «📖 Теория темы». Под ними панель «Задание» с условием на всю ширину.
   - Ниже рабочая область из двух колонок, расположение строгое и не меняется:
     - **Справа — SQL-редактор.** Закреплён (sticky) и не уезжает при прокрутке. Тёмное поле, моноширинный шрифт. Кнопки «▶ Выполнить» (контурная, только предпросмотр) и «✓ Отправить на проверку» (залитая, засчитывает решение). Горячие клавиши: Ctrl+Enter, Ctrl+Shift+Enter, Tab — отступ.
     - **Слева — «Результат».** Есть всегда: до запуска там подсказка-заглушка, после — плашка «✓ Верно» или «✕ Не совпадает», число строк, таблица результата и кнопка «Следующее задание →». Под результатом раскрывающийся блок «Ожидаемый результат», чтобы сразу сравнить.
     - **Слева под результатом — справка во вкладках:** «Структура БД», «Данные», «История попыток (N)». Выбранная вкладка запоминается.
   - Широкие таблицы прокручиваются внутри своей рамки, шапка таблицы закреплена.
   - На экранах уже 1100 px всё идёт в одну колонку: задание → редактор → результат → справка.

## Логика, видимая в UI
- Задания открываются строго по порядку: следующее — после верного решения текущего.
- Статус никогда не передаётся только цветом: всегда есть иконка или текст (✓, ✕, ⏳, 🔒).

## Визуальный стиль
- **Шрифты:** Open Sans (текст, +10% к базовому размеру), Fira Code (код).
- **Светлая тема:** фон #F3EDE3 (бумага), карточки #FBF8F2, рамки #DDD5C9, текст #202124 / вторичный #6F6B64, акцент сливовый #665477, терракота #A94F36.
- **Кнопки:** плоские, ярко-красные #E83D2F, заглавными буквами, с тёмной нижней кромкой, которая «нажимается».
- **Статусы:** решено #667A55 (оливковый), ошибка #A94F36, на проверке #B38A45, инфо #526878.
- **Тёмная тема:** фон #212121, меню #0C0C0C, карточки — полупрозрачный белый 4%, текст #F5F5F7, акцент фиолетовый #6D2BFF, кнопки синие #2093D6.
- **Карточки:** скругление 6–8 px, тонкая рамка, лёгкая тень; при наведении поднимаются на 2–3 px.
- **Анимации:** короткие, 150–220 мс, кривая ease-standard.
- **Адаптивность:** до 700 px меню скрыто (открывается по ☰). Рабочая область задания до 1100 px — в одну колонку.
