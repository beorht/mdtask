### Палитра Marple (страницы студента, с 21.10.2026)

Источник — образцы преподавателя: палитра Marple, карточки задач с заливкой и «пилюлями», тёмный фон со свечением.
Переменные — в `public/css/theme.css`, компоненты — блок «Marple» в конце `public/css/components.css`.
Админка (`admin.css`) не меняется.

#### 1. Цвета

| Цвет | Код | Где |
|---|---|---|
| Малиновый | `#CA2851` | акцент светлой темы, карточка ИБ, контрольная |
| Коралловый | `#FF6766` | акцент тёмной темы, кнопки, карточка SQL |
| Абрикосовый | `#FFB173` | наведение на кнопку, карточка Python |
| Кремовый | `#FFE3B3` | карточка JavaScript, текст на тёмных «пилюлях» |
| Градиент | `#CA2851 → #FF6766 → #FFB173 → #FFE3B3` | полосы прогресса, главные кнопки |

Текст на цветных карточках — почти чёрный `#1C1A1B` (на малиновой — белый): контраст не ниже 4.5:1.

#### 2. Темы

- **Тёмная — основная** (ставится по умолчанию, пока студент не выбрал другую): фон `#161515`, меню `#101010`,
  текст `#F5F1EC`, второстепенный `#ABA29B`.
- **Светлая** — с 26.10.2026 палитра «Тетрадь» из тренажёра Emmet: `docs/color-tetrad.md` (прежняя светлая
  палитра 21.10.2026 — в истории git).

#### 3. Фон

Три неподвижных размытых пятна (`radial-gradient` на `body`): коралловое и абрикосовое справа сверху,
малиновое слева снизу. В светлой теме — слабее.

#### 4. Карточки

- скругление 24px (в списках 20px), заливка цветом палитры, без рамки;
- предметы — по предмету: Python абрикосовый, JavaScript кремовый, SQL коралловый, ИБ малиновый,
  «Проектирование ИС» и «Python: первые шаги» — промежуточные оттенки;
- списки заданий и задач ИБ — по очереди: абрикосовый, кремовый, коралловый, светло-серый;
- значок — в тёмном круге, срок/статус/«Открыть» — тёмные «пилюли» с кремовым текстом.

#### 5. Кнопки

«Пилюли» (`border-radius: 999px`): тёмная тема — коралловые с тёмным текстом, светлая — малиновые с белым;
второстепенная — тёмная «пилюля».

#### 6. Клетки под кодом

Во всех местах, где пишут код (CodeMirror, поле SQL, терминал ИБ), — «тетрадная» сетка: клетка равна высоте
строки (24px, в терминале 30px; высота строки редактора равна клетке), линии белые с прозрачностью 8–9%, сетка прокручивается вместе с текстом. Пятна свечения фона — на неподвижном слое `body::before` (не `background-attachment: fixed`: он тормозил прокрутку и набор).

#### 7. Панель с редактором

В курсе Python, контрольной, детекторе №8 и заданиях с редактором панель с кодом не прилипает к экрану,
страница прокручивается одна. Редактор — фиксированной высоты (`--cm-h`: 58% окна, от 380 до 820px) со своей
прокруткой; поле ввода для «Запустить» — от 150px, вывод — от 220 до 480px. В контрольной колонка с кодом шире
условия (0,8 : 1,2), шапка `exam-bar` тоже не прилипает.

#### 8. Плавная смена цветов

- Наведение и фокус: цвета кнопок, ссылок, карточек, меню меняются за 0,45 с (`--duration-color`); движение
  (подъём карточки, нажатие кнопки) остаётся быстрым — 0,15 с.
- Переключение темы: на время перехода (`.theme-switching`, 1 с) все цвета страницы, включая пятна свечения
  (`@property --glow-*`), меняются за 0,9 с (`--duration-theme`). То же в админке (`admin.css`, `admin.js`).
- При «уменьшить движение» в системе переходы отключаются.
