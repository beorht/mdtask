# Системная архитектура mdtask

Этот каталог описывает архитектуру платформы **mdtask** — как устроено приложение, как
работает админ-панель преподавателя, как построен интерфейс и как компоненты
взаимодействуют с данными.

Документы описывают код по состоянию на 2026-11-02. Исходные верхнеуровневые заметки —
в `CLAUDE.md` (корень репозитория) и `docs/plan.md`; здесь — подробный разбор для
понимания и сопровождения системы.

## Как читать

- Новому разработчику: `01` → `03` → `04`, затем `02` для глубокого погружения в админку.
- Для задач по админ-панели: сразу `02` (там есть ссылки на `04` по таблицам).
- Для задач по данным/БД: `04`.

## Ключевые принципы (кратко)

- Server-rendered: Express 5 + EJS, **без** сборки, фронт-фреймворка, ORM и линтера.
- Весь пользовательский текст — на русском.
- `data/`, `uploads/`, `backups/` — **реальные данные студентов**, их нельзя сбрасывать.
  Тесты всегда идут на `DB_PATH=:memory:` и временных каталогах.
- `ib/` — отдельный Python-подпроект (предмет «Информационная безопасность»),
  со своим `ib/CLAUDE.md`.
