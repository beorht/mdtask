# План урока: Grid (CSS)

Предмет **«Web-разработка: CSS»** (`/subjects/css`), темы **12 «Grid: сетка»** и **13 «Grid: области и макеты
страниц»**. План на **две пары**: урок 1 — сетка (колонки/строки/ячейки), урок 2 — именованные области и адаптивная
галерея. После каждой части — практика на сайте (темы открываются после прочтения теории; Grid идёт после Flexbox).

**Цель:** научить строить двумерную сетку (колонки и строки сразу), растягивать элементы на несколько ячеек,
«рисовать» каркас страницы именованными областями и делать галерею, которая сама перестраивается без `@media`.

**К концу студент умеет:** включать `display: grid`; задавать `grid-template-columns/rows`, `fr`, `repeat()`, `gap`;
растягивать ячейку (`span`, `1 / -1`); выравнивать содержимое (`place-items`); описывать макет `grid-template-areas`;
применять `minmax()` и `repeat(auto-fill/auto-fit, …)`.

**Оборудование:** проектор; у каждого — браузер и `/subjects/css`. Меняйте значения вживую — сетка перестраивается
на глазах, это главный приём наглядности.

## Урок 1 — Grid: сетка (≈ 45 мин)

### 0. Мотивация: flex или grid? (4 мин)
Напомните: **Flexbox** раскладывает по **одной** оси (ряд или колонка). А если нужна **сетка** с ровными колонками
**и** строками (галерея, расписание, каркас страницы)? Для этого — **Grid**, двумерная раскладка.
- в ряд, число/размеры заранее не известны (меню, метки) → **flex**;
- выровненные колонки и строки (галерея, каркас) → **grid**.

### 1. `display: grid` и колонки (7 мин)
Свойство — у **родителя**; дети сами заполняют ячейки слева направо, сверху вниз.

CSS:
```css
.gallery {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* три равные колонки */
  gap: 12px;
}
```
HTML:
```html
<div class="gallery">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
</div>
```
Проговорите: число значений в `grid-template-columns` = число колонок.

### 2. Единица `fr` и `repeat()` (8 мин)
`fr` (fraction, доля) — единица свободного места: сначала вычитаются фиксированные колонки и промежутки, остаток
делится по долям.

CSS (меняйте значения вживую):
```css
.grid { display: grid; gap: 8px; }
.grid { grid-template-columns: 200px 1fr; }      /* фикс + остальное */
.grid { grid-template-columns: 1fr 2fr; }        /* делим 1 : 2 */
.grid { grid-template-columns: repeat(4, 1fr); } /* четыре равные */
```
Строки — по аналогии: `grid-template-rows: 80px auto 60px`; высота авто-появляющихся строк — `grid-auto-rows: 120px`.

HTML:
```html
<div class="grid"><div>1</div><div>2</div><div>3</div><div>4</div></div>
```

### 3. Ячейка на несколько колонок и строк (9 мин)
Линии сетки нумеруются с 1.

CSS:
```css
.grid { display: grid; grid-template-columns: repeat(3, 1fr); grid-auto-rows: 60px; gap: 8px; }
.wide { grid-column: span 2; }   /* на две колонки */
.tall { grid-row: span 2; }      /* на две строки */
.full { grid-column: 1 / -1; }   /* от первой до последней линии — на всю ширину */
```
HTML:
```html
<div class="grid">
  <div class="full">на всю ширину</div>
  <div class="wide">span 2</div>
  <div class="tall">span 2 строки</div>
  <div>4</div><div>5</div>
</div>
```
Запомнить: `1 / 3` — от линии 1 до линии 3; `1 / -1` — на всю ширину.

### 4. Выравнивание внутри ячеек (6 мин)
CSS:
```css
.grid { display: grid; }
.grid { justify-items: center; }   /* содержимое ячеек по горизонтали: start|center|end|stretch */
.grid { align-items: center; }     /* по вертикали */
.stage { display: grid; place-items: center; }  /* оба сразу — центр в каждой ячейке */
```
Для одного элемента — `justify-self` / `align-self`.

HTML:
```html
<div class="stage"><div>В центре одной строкой</div></div>
```

## Урок 2 — Grid: области и макеты страниц (≈ 45 мин)

### 6. Повторение (3 мин)
Опрос: что такое `fr`? как растянуть элемент на всю ширину? чем grid отличается от flex? В теме 12 строили сетку
числами — теперь «нарисуем» макет **именами**.

### 7. Именованные области `grid-template-areas` (12 мин) — главное
Каркас страницы можно нарисовать прямо в CSS: каждой строке сетки — строка в кавычках, каждой ячейке — имя области.

CSS:
```css
.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header header"
    "nav    main"
    "footer footer";
  gap: 8px;
}
.top     { grid-area: header; }
.menu    { grid-area: nav; }
.content { grid-area: main; }
.bottom  { grid-area: footer; }
```
HTML:
```html
<div class="page">
  <header class="top">Шапка</header>
  <nav class="menu">Меню</nav>
  <main class="content">Контент</main>
  <footer class="bottom">Подвал</footer>
</div>
```
Правила (проговорите): в каждой строке одинаковое число ячеек; область — **прямоугольник**; точка `.` — пустая
ячейка. **Чтобы переставить блоки, меняем только «рисунок» — HTML не трогаем** (покажите на `areas-04`).

### 8. `minmax()` — колонка не схлопывается (6 мин)
CSS:
```css
.cols { display: grid; grid-template-columns: minmax(250px, 1fr) 2fr; gap: 12px; }
```
`minmax(250px, 1fr)` — не уже 250px и не шире доли свободного места. Спасает боковую колонку на узком экране.

### 9. Галерея без `@media`: `auto-fill` / `auto-fit` (10 мин) — эффектное
CSS:
```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
  gap: 12px;
}
```
Браузер вставит столько колонок шириной **от 150px**, сколько влезет, и растянет поровну — **без единого
`@media`**. Потяните окно на проекторе — число колонок меняется само.
- `auto-fill` — если элементов мало, остаются **пустые** колонки;
- `auto-fit` — пустые колонки схлопываются, элементы **растягиваются** на всю ширину.

HTML:
```html
<div class="gallery"><div>1</div><div>2</div><div>3</div><div>4</div><div>5</div></div>
```

### 10. Grid снаружи, flex внутри (5 мин)
Типичная страница: каркас и сетка карточек — на **grid**, а содержимое карточки (иконка с подписью, кнопка внизу)
— на **flex**. Элемент сетки может быть flex-контейнером.

CSS:
```css
.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 12px; }
.card  { display: flex; flex-direction: column; }  /* внутри — flex */
.card button { margin-top: auto; }                 /* кнопка внизу */
```
```html
<div class="cards">
  <div class="card"><b>Товар</b><p>Описание.</p><button>В корзину</button></div>
</div>
```

## Частые ошибки (держите под рукой)
- В `grid-template-areas` **разное число ячеек** в строках или область — не прямоугольник → правило не работает.
- Путают, где свойство: `grid-template-*`, `gap`, `justify/align-items`, `grid-area` в областях — у **контейнера**;
  `grid-column/row`, `justify/align-self` — у **элемента**.
- Ждут от `fr` фиксированную ширину — это доля **свободного** места после фиксированных колонок и `gap`.
- Для адаптива лепят `@media`, хотя `repeat(auto-fit, minmax(…, 1fr))` часто решает без него.
- `span 2` считают «до 2-й линии» — это «на 2 ячейки»; с линиями — `1 / 3`.
