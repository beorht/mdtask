# №5. Основы работы в терминале Linux (тренажёр)

## Цель

Научить студентов основным командам терминала. Задание проходится пошагово, по порядку:
навигация, просмотр и чтение файлов, создание, копирование, перемещение и удаление, права
доступа и запуск скриптов, ссылки, поиск, конвейеры и перенаправления, `sudo`, история
команд, итоговое задание. Выполняется в веб-терминале mdtask: «Информационная безопасность» →
«Задание №5». Перед практикой студент читает теорию (`ib/ctf/terminal/THEORY.md`), где
описаны все этапы, команды и их ключи.

## Что получает студент

Каждому студенту генерируется своя небольшая система (`data/ctf/terminal/<student_id>/`). В
терминале она выглядит как `/`:

| Где | Что |
|---|---|
| `~/documents` | заметки, отчёт, `private.txt` (644 → нужно 600), `mystery.txt` (личные права), письма и протоколы встреч (в одном из них — личное слово) |
| `~/downloads` | `config/` (копировать целиком), `data.csv` (переместить), картинка и архив (для `file`), `releases/` и ссылка `current` на личную версию |
| `~/logs` | `app.log` (личное число строк, ERROR и WARN), `access.log` (личный самый частый IP) |
| `~/archive` | десятки файлов по годам и месяцам и ровно один PDF в личном месте |
| `~/trash` | `*.tmp`, `keep.txt` (оставить), `empty_dir/`, `old_project/` |
| `~/scripts/backup.sh` | скрипт без права `x` |
| `~/.secret` и другие скрытые файлы | личное кодовое слово; число скрытых файлов у студентов разное |
| `/etc`, `/var/log/auth.log` (640), `/var/log/private` (700), `/root` (700) | системные файлы для `ls`, `cd`, `sudo`, `2>/dev/null` |

Условие со всеми этапами и личными значениями лежит в `~/TASK.md` (генерируется из
`server/terminal_task.py`). Терминал показывает текущий этап командой `task` и прогресс
командой `check`.

## Этапы (14) и проверка

| № | Этап | Что проверяется |
|---|---|---|
| 1 | Знакомство: `pwd`, `whoami`, `date`, `man` | команды из журнала |
| 2 | `ls -l`, `ls -a`, `ls -l /etc` | команды + вопрос 2.1 (число скрытых файлов) |
| 3 | `cd` абсолютный, `..`, домой, относительный, `cd -` | команды (каталог до и после `cd`) |
| 4 | `cat`, `head -n`, `tail -n`, `wc -l` | команды + вопросы 4.1 (строк в логе), 4.2 (кодовое слово) |
| 5 | `mkdir`, `mkdir -p`, `echo >`, `echo >>`, `touch` | файлы: каталоги проекта, README из двух строк, пустые файлы |
| 6 | `cp`, `cp -r`, `mv`, переименование | файлы: копии совпадают по SHA-256, исходник перемещён |
| 7 | `rm *.tmp`, `rmdir`, `rm -r` | файлы: `.tmp` нет, `keep.txt` на месте, каталоги удалены |
| 8 | `chmod +x`, запуск `./backup.sh`, `chmod 600` | файлы (права) + команда (запуск по пути) + вопрос 8.1 (права числом) |
| 9 | `ln -s`, `readlink` | файлы (ссылки ведут куда нужно) + команда + вопрос 9.1 |
| 10 | `find -name`, `grep -c`, `grep -rl` | команда + вопросы 10.1 (путь PDF), 10.2 (число ERROR), 10.3 (файл со словом) |
| 11 | `cut \| sort \| uniq -c \| sort -rn`, `sort -u >`, `grep >`, `2>/dev/null` | вопрос 11.1 (IP) + файлы `ips.txt`, `errors.txt` + команда |
| 12 | `sudo whoami`, `sudo cat`, `\| sudo tee -a` | команда + вопрос 12.1 (имя из auth.log) + строка в `/etc/motd` |
| 13 | `history`, `!!`, `history \| grep` | команды (журнал хранит и набранное, и раскрытое `!!`) |
| 14 | итоговое: `~/final/{bin,conf,logs}`, `app.conf`, `start.sh` (750), ссылка, `warnings.txt`, удалить `~/trash` | файлы |

**Алгоритм проверки** (`server/terminal_task.py`, один и тот же в терминале и в чекере):
- Этапы засчитываются только по порядку. Очередной этап засчитывается, когда выполнены все его
  пункты. Пройденный этап остаётся пройденным: следующие этапы меняют файлы, например этап 14
  удаляет `~/trash`.
- **Файлы** проверяются по песочнице. При этом видно, куда на самом деле ведёт ссылка, а
  содержимое копий сверяется по SHA-256.
- **Команды** проверяются по журналу `ib_terminal_log`. Терминал записывает каждую строку:
  набранную, раскрытую (`!!`) и список выполненных команд с аргументами, каталогом до и после,
  кодом возврата и `sudo`. Засчитываются только команды, выполненные **после открытия этапа**
  и без ошибки, поэтому выполнить всё заранее не получится.
- **Вопросы** проверяются по ответам `answer N.M ОТВЕТ`. Ответ принимается только на текущем
  этапе. Число попыток записывается, и преподаватель видит неверные ответы.

Автопроверка запускается после каждой команды. Задание засчитывается, когда пройдены все
14 этапов (`ib_terminal_tasks.solved`).

## Терминал

Кроме команд заданий №3–4, в эмуляторе есть:
- **Работа с файлами:** `mkdir [-p -v -m]`, `rmdir [-p]`, `rm [-r -f -v -d]`, `mv [-n -v -t]`,
  `cp [-r -a -p -n -v -t]`, `chmod [-R -v]` (числом и буквами: `u+x`, `go-rwx`, `a=r`),
  `ln [-s -f -v]`, `readlink [-f]`.
- **Сведения о файлах и путях:** `file`, `basename`, `dirname`, `tree [-a -d -L]`,
  `ls -R -t -S -r -F`, `less`/`more` (выводят файл целиком).
- **Вывод и система:** `printf`, `hostname`, `uname`, `printenv`.
- **История:** `history`, `!!`, `!N`, `!-N`, `!строка`.
- **Скрипты:** запуск `./script.sh` (нужен бит `x`), `bash script.sh`.
- **Клавиши:** дополнение по Tab.

Защита: удалить или переместить `/`, домашний каталог и каталоги над ним нельзя даже с `sudo`.
В остальном права работают как в Linux: всё вне домашнего каталога принадлежит root.

## Команды преподавателя

```bash
# выдать задание группе / одному студенту (повторный запуск пропускает тех, у кого уже есть)
python3 ib/ctf/terminal/generate_terminal.py --group IB
python3 ib/ctf/terminal/generate_terminal.py --student st-test-001
# выдать заново (новые значения, песочница с нуля, прогресс обнуляется; журнал сохраняется)
python3 ib/ctf/terminal/generate_terminal.py --student st-ib-472 --force
# восстановить песочницу с прежними значениями и прогрессом: удалить data/ctf/terminal/<id> и запустить без --force
# вернуть потерянные исходные файлы этапа 6 (data.csv, report.txt, downloads/config) тем, кто его не прошёл;
# оригинал, найденный в другом месте, возвращается в ~/downloads, потерянный — заменяется новым (хеш обновляется);
# прогресс, ответы и журнал сохраняются
python3 ib/ctf/terminal/generate_terminal.py --group IB --repair
# после правки этапов в server/terminal_task.py — обновить ~/TASK.md у всех
python3 ib/ctf/terminal/generate_terminal.py --group IB --refresh-task

# проверить всех и записать прогресс в БД
python3 ib/checks/task5_check.py --group IB --update-db
# подробно по одному студенту: этапы, пункты текущего этапа, неверные ответы
python3 ib/checks/task5_check.py st-ib-472 --text
```

Результаты — в админке mdtask: `/admin/ib`. Там есть прогресс по этапам, текущий этап, число
команд, неверные ответы и последняя активность. По кнопке «Подробнее»
(`/admin/ib/terminal/<id>`) открываются этапы с датами прохождения, ответы на вопросы и журнал
команд студента.

Эталонное прохождение со значениями конкретного студента (значения есть в
`ib_terminal_tasks.params`) — в тесте `ib/tests/test_terminal.py` (`REFERENCE`).
