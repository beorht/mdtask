# №4. Поиск и правка конфигурационных файлов (find, grep, sed)

## Цель

Научить студентов **находить** нужные файлы в терминале (`find`, `grep`) и **изменять** значения
внутри них без редактора (`sed -i`, `tee`), с правами root через `sudo`. Задание выполняется в
веб-терминале mdtask, раздел «Информационная безопасность» → «Задание №4». Перед практикой
студент читает теорию (страница «Теория» задания, источник — `ib/ctf/configs/THEORY.md`).

## Что получает студент

Каждому студенту генерируется своя файловая система учебного сервера Debian 12
(`data/ctf/configs/<student_id>/`). В терминале она выглядит как `/`:

| Где | Что |
|---|---|
| `/etc/ssh/` | `sshd_config`, `ssh_config` (клиент — ловушка), `sshd_config.d/50-cloud-init.conf` с `PasswordAuthentication yes`, ключи хоста (600) |
| `/etc/apache2/` | `apache2.conf`, `ports.conf`, `sites-available/` + `sites-enabled/` (ссылка), `conf-available/` + `conf-enabled/` (ссылки), `mods-*` |
| `/etc/mysql/` | `mariadb.cnf` (+ ссылка `my.cnf`), `my.cnf.fallback`, `debian.cnf` (600), `mariadb.conf.d/50-server.cnf` с `bind-address = 0.0.0.0` |
| `/etc/php/8.2/` | `apache2/php.ini` и `cli/php.ini` (ловушка), `conf.d` — ссылки на `mods-available` |
| `/usr/share/openssh/sshd_config`, `/usr/lib/php/8.2/php.ini-*` | шаблоны (ловушки) |
| `/var/backups/*.bak`, `~/backup/*.old` | резервные копии (ловушки) |
| `/var/log`, `/var/lib/mysql`, `/root`, `/etc/ssl/private` | закрытые каталоги: `find`/`grep` без `sudo` получают «Отказано в доступе» |
| `/usr/bin` | пустые «исполняемые файлы», `sudo`/`passwd`/`su`/`mount` с SUID — для `find -perm` |

Даты изменения правдоподобные (рабочие конфиги правились позже установки), поэтому работают
`-mtime` и `-newer`. Условие с личными значениями и подсказками по `find` — `~/TASK.md`.

## Что нужно сделать (8 пунктов + 1 необязательный)

| № | Пункт | Где на самом деле | Ловушка |
|---|---|---|---|
| 1 | SSH на личном порту | `/etc/ssh/sshd_config`: `#Port 22` → `Port N` | `ssh_config`, шаблон в `/usr/share` |
| 2 | `PermitRootLogin no` | там же | — |
| 3 | `PasswordAuthentication no` | `/etc/ssh/sshd_config.d/50-cloud-init.conf` | sshd берёт **первое** значение, а `Include` стоит в начале `sshd_config` |
| 4 | `Listen` личный порт | `/etc/apache2/ports.conf` | `Listen 443` внутри `<IfModule>` не трогать |
| 5 | `<VirtualHost *:порт>` | `sites-available/000-default.conf` (через ссылку в `sites-enabled`) | `sed -i` по ссылке заменяет её файлом — засчитывается, но это повод поговорить о `--follow-symlinks` |
| 6 | `ServerTokens Prod`, `ServerSignature Off` | `conf-available/security.conf` | несколько закомментированных вариантов в файле |
| 7 | `bind-address = 127.0.0.1` | `/etc/mysql/mariadb.conf.d/50-server.cnf` | `my.cnf.fallback` (не подключается); выравнивание пробелами |
| 8 | `upload_max_filesize` личное значение | `/etc/php/8.2/apache2/php.ini` | `cli/php.ini` и `php.ini-*` в `/usr/lib` |
| 9 | Посторонние файлы не изменены | хеши ловушек из генератора | необязательный: показывает, если студент правил копии/шаблоны «на всякий случай» |

Проверяется **действующее** значение — так, как его прочитает сам сервис (`server/config_task.py`).
Задание засчитывается автоматически после любой записи в файлы, как только выполнены пункты 1–8;
статус не сбрасывается. Команда `check` в терминале показывает прогресс по пунктам.

## Терминал

Эмулятор bash (`server/shell.py`): кавычки, `$VAR`, `$(...)`, маски, `| ; && ||`,
`> >> < 2> 2>&1 &>`. Команды: `find` (почти все проверки и действия GNU find, включая `-exec ... {} \;`/`+`,
`-printf`, `-perm`, `-mtime`, `-regex`), `grep` (BRE/ERE/`-F`/`-P`, `-r -n -i -v -w -x -c -l -L -o -A -B -C`,
`--include/--exclude`), `sed` (адреса, диапазоны, `s///` с флагами, `a/i/c/d/p/y/=`, hold space,
метки, `-n -e -f -i[SUF] -E -s --follow-symlinks`), а также `xargs`, `tee`, `sudo`, `cp`, `diff`, `stat`,
`head/tail/wc/sort/uniq/cut`, `man`. Редакторов нет: `nano`/`vim` подсказывают использовать `sed -i`.

Права эмулируются: всё вне домашнего каталога принадлежит root, писать туда можно только через
`sudo`; перенаправление `>` выполняется без прав root (`sudo echo x > /etc/f` → «Отказано в доступе»,
правильно — `echo x | sudo tee /etc/f`).

## Команды преподавателя

```bash
# выдать задание группе / одному студенту (повторный запуск пропускает тех, у кого уже есть)
python3 ib/ctf/configs/generate_configs.py --group IB
python3 ib/ctf/configs/generate_configs.py --student st-test-001
# выдать заново (новые значения, песочница с нуля, прогресс обнуляется)
python3 ib/ctf/configs/generate_configs.py --group IB --force
# после правки ib/ctf/configs/TASK.md — обновить ~/TASK.md у всех (значения и прогресс сохраняются)
python3 ib/ctf/configs/generate_configs.py --group IB --refresh-task

# проверить всех и записать прогресс в БД
python3 ib/checks/task4_check.py --group IB --update-db
# подробно по одному студенту
python3 ib/checks/task4_check.py st-ib-472 --text
```

Результаты, прогресс и личные значения каждого студента — в админке mdtask: `/admin/ib`.
Эталонное решение — в конце `ib/ctf/configs/TASK.md` (раздел «Для преподавателя»).
