# Задание №3. Доступ к защищённой базе данных

В твоём домашнем каталоге лежит резервная копия базы данных компании — `~/Documents/backup/company_data.db`. База защищена паролем. Бывший администратор спрятал пароль в одном из файлов системы и зашифровал его шифром Цезаря.

## Что нужно сделать

1. Найти спрятанный файл с зашифрованной записью.
2. Подобрать ключ и расшифровать запись. Если после расшифровки получился путь к файлу — пароль лежит в этом файле.
3. Открыть базу командой `sqlite3 Documents/backup/company_data.db` и ввести найденный пароль.
4. Изучить данные в базе:
   - сотрудники ИТ-отдела;
   - учётные записи со слабыми паролями и их владельцы;
   - документы с грифом `secret`, отсортированные по дате.

Задание засчитывается автоматически, когда база открыта с верным паролем.

Все данные в базе вымышлены и созданы в учебных целях. Список команд терминала — `help`.

## Для преподавателя

Раздел не копируется студентам (генератор отрезает всё начиная с этого заголовка).

```bash
python3 ctf/caesar-secret/generate_challenge.py --group IB                          # выдать задание группе
python3 ctf/caesar-secret/generate_challenge.py --group IB --variant path --force   # усложнённый вариант
```

Проверка и ответы — в базе mdtask:

```sql
SELECT student_id, variant, solved, solved_at, caesar_shift, plain_password,
       hidden_file_path, password_file_path
FROM ctf_caesar_secrets
ORDER BY solved DESC, solved_at;
```
