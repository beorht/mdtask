# Перенос базы mdtask из SQLite в PostgreSQL

Скрипты только копируют данные: приложение по-прежнему работает на SQLite (`data/mdtask.db`),
код и исходная база не меняются. Всё, что создают скрипты, кладётся в `data/migration/`
(каталог `data/` не попадает в git).

| Скрипт | Что делает |
|---|---|
| `export_dump.py` | снимок SQLite → SQL-дамп для PostgreSQL → шифр Цезаря → `data/migration/mdtask-<время>.pgsql.caesar` (+ `caesar.key`, если ключ не задан) |
| `decrypt_dump.py` | расшифровывает дамп, проверяет SHA-256 (неверный ключ → ошибка) |
| `create_pg_user.py` | создаёт в PostgreSQL пользователя и базу с паролем, сохраняет подключение в `data/migration/pg-connection.env` (права 600) |
| `caesar.py` | шифр: сдвиг каждого байта на ключ 1–255 |

## Порядок

1. Зашифрованная копия базы:

       python3 scripts/pg-migration/export_dump.py

2. Подключиться к VPN, затем создать пользователя и базу (пароль администратора спросит psql):

       python3 scripts/pg-migration/create_pg_user.py --host <адрес сервера в VPN> --admin-user postgres

3. Загрузить дамп под новым пользователем:

       set -a; . data/migration/pg-connection.env; set +a
       python3 scripts/pg-migration/decrypt_dump.py --key-file data/migration/caesar.key \
         data/migration/mdtask-<время>.pgsql.caesar | psql -X -v ON_ERROR_STOP=1 -q

   Дамп загружается одной транзакцией в **пустую** базу. В конце он сверяет число строк каждой
   таблицы и при расхождении откатывает всё.

## Важно

- Шифр Цезаря — не защита: 255 вариантов ключа перебираются мгновенно. Дамп содержит ФИО,
  хеши паролей, пароли задания №3. Не выкладывайте дамп, ключ и `pg-connection.env` в git,
  в чаты и в открытый доступ; передавайте дамп и ключ раздельно.
- Снимок — на момент запуска `export_dump.py`. Пока сервер работает, студенты добавляют
  новые попытки и команды терминала. Для окончательного переноса сделайте свежий дамп, когда
  никто не работает (или после остановки сервера).
- Файлы на диске (`uploads/`, `data/trainer/`, `data/ctf/`, `content/`) в базе не хранятся
  и этим дампом не переносятся.
- Пароли пользователей mdtask (scrypt) переносятся как есть.
