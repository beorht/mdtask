# Перебор массивов

Три способа пройти по массиву:

```js run
const marks = [5, 3, 4];
for (let i = 0; i < marks.length; i++) console.log(i, marks[i]);   // нужен номер
for (const m of marks) console.log(m);                            // нужны только значения
marks.forEach((m, i) => console.log(i + 1 + ')', m));             // колбэк с номером
```

- `for` с индексом — когда нужен номер, соседние элементы (`a[i - 1]`, `a[i + 1]`) или шаг не 1;
- `for…of` — самый читаемый, когда нужны только значения; работает и со строками;
- `forEach` — метод с колбэком; из него нельзя выйти `break`.

## Перебор с «окном»

Иногда нужно смотреть на несколько элементов сразу: пары соседей, отрезок из k элементов. Окно не пересчитывают с
нуля, а **сдвигают**: прибавляют вошедший элемент и вычитают вышедший.

```js run
const t = [2, 4, 6, 8];
let window = t[0] + t[1];
console.log(window);
for (let i = 2; i < t.length; i++) {
  window += t[i] - t[i - 2];
  console.log(window);
}
```

## Префиксные суммы

`pre[i]` — сумма первых i элементов. Тогда сумма с позиции l по r — это `pre[r + 1] − pre[l]`: любой отрезок за
одно вычитание.

## Массив-счётчик

Если значения — небольшие целые числа (цифры, оценки), их удобно считать в массиве: `count[value]++`.

## Решето Эратосфена

Чтобы найти все простые до N, заводят массив флагов «простое?», а потом для каждого простого p вычёркивают его
кратные: 2p, 3p, … Это намного быстрее, чем проверять каждое число отдельно.
