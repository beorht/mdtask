# Область видимости и замыкания

## Где видна переменная

`let` и `const` видны только внутри **блока** `{ … }`, где объявлены. Переменная, объявленная вне функций, —
**глобальная**: её видно везде, и любая функция может её случайно испортить.

```js run
const greeting = 'Привет';
function hello(name) {
  const text = greeting + ', ' + name;
  return text;
}
console.log(hello('Аня'));
// console.log(text);  — ошибка: text живёт только внутри hello
```

## Замыкание

Функция **помнит** переменные того места, где она создана, даже когда то место уже «закончилось». Это и есть
замыкание:

```js run
function makeGreeter(prefix) {
  return (name) => prefix + ', ' + name + '!';
}
const hi = makeGreeter('Привет');
const bye = makeGreeter('Пока');
console.log(hi('Бек'), bye('Бек'));
```

Каждый вызов `makeGreeter` создаёт **своё** окружение: у `hi` и `bye` разные `prefix`.

## Скрытое состояние

Замыкание позволяет хранить данные, которые нельзя изменить снаружи, — только через выданные функции:

```js run
function makeLamp() {
  let on = false;
  return {
    toggle: () => { on = !on; },
    state: () => (on ? 'горит' : 'не горит'),
  };
}
const lamp = makeLamp();
lamp.toggle();
console.log(lamp.state());
```

## Запоминание результатов (кэш)

Если функция долго считает, а её зовут с одними и теми же аргументами, результат можно запомнить в объекте внутри
замыкания и при повторном вызове отдать сразу. Этот приём называют **мемоизацией**.

## Цикл и замыкание

В цикле `for (let i …)` у каждого шага — своя `i`, поэтому функции, созданные в цикле, помнят «свой» номер. Со
старым `var` переменная одна на весь цикл — частая ошибка в старом коде.
