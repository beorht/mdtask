# map, filter, reduce, find, some, every

Методы массивов принимают **колбэк** и сами делают цикл. Код становится короче и говорит, *что* нужно сделать.

| Метод | Возвращает | Пример |
| --- | --- | --- |
| `map(fn)` | новый массив из результатов `fn` | `[1, 2].map((x) => x * 10)` → `[10, 20]` |
| `filter(fn)` | новый массив из элементов, где `fn` — истина | `[1, 2, 3].filter((x) => x > 1)` → `[2, 3]` |
| `reduce(fn, start)` | одно значение — «свёртка» | `[1, 2, 3].reduce((acc, x) => acc + x, 0)` → `6` |
| `find(fn)` / `findIndex(fn)` | первый подходящий элемент / его номер | `undefined` / `-1`, если нет |
| `some(fn)` / `every(fn)` | есть ли хоть один / все ли | `true` или `false` |

Колбэк получает элемент, его номер и сам массив: `(x, i, arr) => …`.

## Цепочки

Методы, которые возвращают массив, можно ставить друг за другом:

```js run
const prices = [1200, 450, 3000, 800];
const total = prices
  .filter((p) => p >= 800)
  .map((p) => p * 0.9)
  .reduce((sum, p) => sum + p, 0);
console.log(total);
```

## reduce подробнее

`acc` — накопленное значение, `start` — с чего начать. В `reduce` можно копить не только число, но и строку, массив
или объект:

```js run
const words = ['кот', 'кит', 'ёж'];
const lengths = words.reduce((acc, w) => {
  acc[w] = w.length;
  return acc;
}, {});
console.log(lengths);
```

## Array.from

`Array.from({ length: n }, (_, i) => …)` создаёт массив из n элементов по правилу — удобно для диапазонов:

```js run
const tens = Array.from({ length: 4 }, (_, i) => (i + 1) * 10);
console.log(tens);
```

## Когда метод, а когда цикл

Методы удобны для преобразований «массив → массив / значение». Если нужно остановиться посередине или сделать
сложный алгоритм с несколькими индексами, обычный цикл понятнее.
