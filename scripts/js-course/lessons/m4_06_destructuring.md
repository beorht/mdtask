# Деструктуризация и spread

## Деструктуризация

Достать части массива или объекта сразу в переменные:

```js run
const point = [3, 7];
const [x, y] = point;
const user = { name: 'Аня', group: 'web-2', age: 17 };
const { name, group: team, city = 'Ташкент' } = user;
console.log(x, y, name, team, city);
```

- в массиве — по **позиции**, в объекте — по **имени** ключа;
- `group: team` — взять ключ `group` в переменную `team`;
- `city = 'Ташкент'` — значение по умолчанию, если ключа нет;
- `const [first, ...others] = arr` — первый элемент и массив остальных.

Обмен значений без третьей переменной: `[a, b] = [b, a]`.

## В параметрах функции

```js run
function card({ title, price, currency = 'сум' }) {
  return title + ': ' + price + ' ' + currency;
}
console.log(card({ title: 'Чай', price: 12000 }));
```

## В цикле по парам

```js run
const stock = { хлеб: 4, сыр: 1 };
for (const [item, qty] of Object.entries(stock)) console.log(item, qty);
```

## Spread `...`

Разложить массив или объект **внутри** нового:

```js run
const base = { color: 'серый', size: 'M' };
const red = { ...base, color: 'красный' };   // копия с изменением
const all = [...[1, 2], 3, ...[4]];
console.log(base, red, all);
```

Поля, записанные **позже**, перекрывают ранние. Spread делает **поверхностную** копию: вложенные объекты и массивы
остаются общими.

## Не менять исходные данные

Хорошая привычка — не изменять данные, которые пришли «снаружи», а возвращать новые: `{ ...obj, поле: новое }`,
`[...arr, новый]`. Тогда никакая другая часть программы не увидит неожиданных изменений.
