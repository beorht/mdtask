# Рекурсия

**Рекурсия** — функция вызывает саму себя для задачи поменьше. У рекурсии всегда две части:

1. **база** — самый простой случай, ответ известен сразу;
2. **шаг** — свести задачу к такой же, но меньшей.

```js run
function countdown(n) {
  if (n === 0) {
    console.log('Пуск!');
    return;
  }
  console.log(n);
  countdown(n - 1);
}
countdown(3);
```

Без базы функция вызывает себя бесконечно — получится ошибка «Maximum call stack size exceeded» (стек вызовов
переполнен).

## Стек вызовов

Каждый вызов ждёт, пока закончатся вызовы, которые он сделал. Вот как считается сумма чисел от 1 до n:

```js run
function total(n) {
  if (n === 1) return 1;
  return n + total(n - 1);
}
console.log(total(4)); // 4 + (3 + (2 + 1))
```

## Когда рекурсия удобна

- данные **вложены** сами в себя: папки в папках, массивы в массивах, объекты в объектах;
- задача делится на **такие же части**: сортировка слиянием, ханойские башни, перебор вариантов.

Если задача — простой счёт по порядку, цикл обычно проще и быстрее.

## Повторные вычисления

Наивная рекурсия иногда считает одно и то же много раз (Фибоначчи: `fib(n-1)` и `fib(n-2)` снова считают одни и те
же числа). Запоминайте ответы в объекте — получится **рекурсия с запоминанием**, и время станет линейным.

## Проверка типа

Для вложенных данных пригодится проверка, массив ли перед нами — `Array.isArray(x)`, — и объект ли: `typeof x === 'object'
&& x !== null`. Такие данные удобно давать строкой в формате JSON и разбирать `JSON.parse(строка)` (подробно — в 4.7).
