# Объекты

**Объект** — набор пар «ключ → значение». Ключи — строки, значения — что угодно, в том числе функции (тогда это
**методы**).

```js run
const book = {
  title: 'Мастер и Маргарита',
  year: 1967,
  tags: ['роман', 'классика'],
  info() {
    return this.title + ' (' + this.year + ')';
  },
};
console.log(book.title, book['year'], book.tags.length);
console.log(book.info());
```

- через точку — когда имя ключа известно заранее: `book.year`;
- через скобки — когда ключ в переменной или с пробелами: `book[key]`;
- `this` внутри метода — объект, у которого метод вызвали.

## Добавить, изменить, удалить, проверить

```js run
const stock = { хлеб: 10 };
stock.молоко = 5;
stock['хлеб'] -= 3;
delete stock.молоко;
console.log(stock, 'хлеб' in stock, 'сыр' in stock);
```

## Объект как словарь

Объект — удобная **таблица поиска**: «имя → телефон», «товар → цена», «слово → сколько раз». Классический приём
подсчёта:

```js run
const votes = ['за', 'против', 'за'];
const result = {};
for (const v of votes) result[v] = (result[v] || 0) + 1;
console.log(result);
```

## Перебор

| Способ | Что даёт |
| --- | --- |
| `for (const key in obj)` | ключи |
| `Object.keys(obj)` | массив ключей |
| `Object.values(obj)` | массив значений |
| `Object.entries(obj)` | массив пар `[ключ, значение]` |

Порядок ключей — порядок добавления (кроме ключей-чисел: они идут первыми по возрастанию).

## Необязательная цепочка `?.`

`user.address?.city` вернёт `undefined`, а не упадёт с ошибкой, если `address` нет.

## Объекты тоже по ссылке

Как и массивы: `const b = a` не копирует объект. Копия — `{ ...a }` (урок 4.6).
