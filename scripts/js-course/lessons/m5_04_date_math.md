# Дата, время и Math

## Date

`Date` хранит момент времени — число миллисекунд от 1 января 1970 года (UTC).

```js run
const d = new Date('2026-10-27');           // строка ГГГГ-ММ-ДД читается как полночь по UTC
console.log(d.getUTCFullYear(), d.getUTCMonth() + 1, d.getUTCDate(), d.getUTCDay());
console.log(d.getTime());
```

- месяцы считаются **с нуля** (январь — 0), поэтому `+ 1` при выводе;
- `getUTCDay()` — день недели: 0 — воскресенье, 1 — понедельник … 6 — суббота;
- есть пары методов: `getDate()` — по часовому поясу компьютера, `getUTCDate()` — по UTC. В задачах курса используйте
  **UTC-методы** — тогда ответ не зависит от того, где стоит компьютер;
- `Date.UTC(год, месяц, день)` — миллисекунды для даты (месяц тоже с нуля); `Date.now()` — «сейчас».

## Разница дат

Вычитание дат даёт миллисекунды. В сутках `24 * 60 * 60 * 1000` мс:

```js run
const MS_PER_DAY = 86400000;
const from = new Date('2026-09-01');
const to = new Date('2026-12-31');
console.log((to - from) / MS_PER_DAY);
```

Прибавить дни: `new Date(d.getTime() + n * MS_PER_DAY)` или `d.setUTCDate(d.getUTCDate() + n)` — переход через месяц и год
посчитается сам.

## Форматирование

`String(n).padStart(2, '0')` превращает 7 в `'07'` — так собирают «ДД.ММ.ГГГГ». `d.toISOString()` — стандартная
запись `2026-10-27T00:00:00.000Z`, `slice(0, 10)` из неё — дата.

## Случайные числа

`Math.random()` — случайное число от 0 до 1 (не включая 1). Целое от `a` до `b`:
`a + Math.floor(Math.random() * (b - a + 1))`.

Проверять программу со случайностью трудно — ответ каждый раз другой. Поэтому в играх, тестах и симуляциях
используют **генератор с зерном**: из числа-зерна по формуле получается следующее, и из одного зерна всегда выходит
одна и та же последовательность. Простой генератор Парка — Миллера:

```js run
let state = 42;
function next() {
  state = (state * 16807) % 2147483647;
  return state / 2147483647;
}
console.log(next().toFixed(4), next().toFixed(4));
```

В задачах урока вместо `Math.random()` используйте такой генератор с зерном из ввода.

## Перемешивание

Честно перемешать массив — алгоритм **Фишера — Йейтса**: идём с конца, и для каждой позиции `i` меняем элемент с
элементом на случайной позиции от 0 до `i`.
