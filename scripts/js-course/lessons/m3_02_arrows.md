# Функциональные выражения и стрелки

Функция в JavaScript — такое же **значение**, как число или строка: её можно положить в переменную, передать,
вернуть.

```js run
const half = function (x) {
  return x / 2;
};
console.log(half(9));
```

## Стрелочные функции

Короткая запись: `(параметры) => результат`. Если тело — одно выражение, `return` и фигурные скобки не нужны:

```js run
const cube = (x) => x * x * x;
const hello = () => 'привет';
const between = (x, lo, hi) => x >= lo && x <= hi;
console.log(cube(3), hello(), between(5, 1, 10));
```

Если нужно несколько строк — фигурные скобки и `return`:

```js run
const describeAge = (age) => {
  if (age < 14) return 'ребёнок';
  return age < 18 ? 'подросток' : 'взрослый';
};
console.log(describeAge(16));
```

## Функции в объекте

Функции удобно хранить в объекте «имя → функция» и выбирать по имени — вместо длинного `switch`:

```js run
const units = {
  km: (m) => m / 1000,
  cm: (m) => m * 100,
};
console.log(units.km(2500), units['cm'](3));
```

## Таблица значений

Функция из математики `f(x)` легко записывается стрелкой, а дальше её можно вызывать в цикле:

```js run
const g = (x) => 2 * x + 1;
for (let x = 0; x <= 3; x++) console.log(x, g(x));
```

## Численные методы

Стрелки удобны для алгоритмов, которые работают с **любой** функцией. Например, **деление пополам** находит корень
уравнения `f(x) = 0` на отрезке `[a, b]`, где у `f(a)` и `f(b)` разные знаки: берём середину, смотрим знак и
оставляем ту половину, где знак меняется. Каждый шаг вдвое сужает отрезок.
